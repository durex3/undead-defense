# 敌人战术与站位修复 0.40.0

本地实现，未推送远程或上传微信后台。承接 0.39.0 结构整理，当前仍为16关、14武器系列。

## 决策分层

- 普通近战：约四分之一按稳定实体编号选择有限侧翼接近，最多2.5秒，进入4.5距离后交回原控制器；玩家移动超过3单位才允许重新选择侧翼。其他普通敌人继续追击。远程与特殊敌人保留自己的射程、预警和招式控制器。
- 精英：已有两个危险实体且另一精英正在发布危险时，等待者可以向另一侧移动；不开额外危险槽，不在自身招式中途移动。槽位空出后仍由原关卡调度决定出招。
- Boss：玩家停留同一区域且连续10秒未受到实际伤害，才考虑改进站位；利用原地图寻路和碰撞逐步移动。30秒持续无效时进一步贴近，尝试原有近身压迫。玩家离开观察范围或实际受伤会重置观察；不在已有危险链、冻结、埋地、蓄力或收招中改位。
- 第十六关：根据距离与有效旧骨痕选择A/B/C，使用三招袋保证轮换；候选发布方向须真正覆盖玩家当前位置，同时保留原合法性与逃生检查。两命40%/60%、复活时间、快照锁定与伤害不变。

## 修复的执行漏洞

几何拒绝导致的同一招无限重试会切换下一招；第四关同样处理空槽几何失败。第十二关完整分叉无法放入窄通道时尝试已有直线走焰，保留26伤害、2.2秒预警、速度和逃生检查，不压缩招式强塞。第七关Boss近身判定统一为1单位，普通敌人保持0.65；第十一、十三关寻路换位不再跳过原有近身碰撞判定。第十三关冲刺完成后不再用旧冲刺快照覆盖新的寻路位置。

站位决策、地图移动和关卡招式分别由 `BossTactics` / `EnemyTactics`、`TacticalMovement` 和原关卡策略负责。武器伤害、敌人血量曲线、经济与存档协议未调整。

## 验证与边界

`tools/check-boss-stationary.mjs` 使用真实敌人更新、判伤、摄像机与障碍物，禁用武器和杂兵，固定玩家位置，高生命只用于记录实际命中，不自动扣血。

- `artifacts/ai-0.40.0/all-states.json`：各关阶段、中央/四边/四角、四个Boss来向，60秒观察；另含三个第十六关第二形态45秒样本。
- `artifacts/ai-0.40.0/terrain-close.json`：障碍物邻近位置与1.2/2.8/4.8三档起始距离，四来向，各阶段60秒观察。
- 专项回归覆盖战术移动的冻结/蓄力/危险链约束、精英危险预算、特殊敌人保留原控制器、旧骨痕选招及关键死角。
- 实际Cocos浏览器验证第四、五、十一、十二、十三、十六关关键站位的真实伤害和最多两个危险实体；完整检查报告在 `artifacts/verification/full.json`，浏览器报告在 `artifacts/architecture-refactor/browser/browser-report.json`。

本轮两份扫描共4,566组记录，均出现实际判伤。中央/边角扫描最晚首次受击约30.37秒，障碍物/贴身扫描约45.37秒。686项回归中685通过、1项历史跳过；类型、内容接入、武器数值对照和实际Cocos检查通过，本地Web/微信构建通过。

这些是固定样本压力诊断，不代表遍历所有站位、实际通关率或真人胜率；后续继续记录朋友提供的具体站位、配装与版本。允许短暂安全窗口与看懂机制后躲避，长期固定位置不能让敌人反复空转。

## 后续设计规则

新增关卡必须检查边缘、四角、障碍物背后、Boss贴身和招式间隙；覆盖各阶段/复活形态与不同来向。先验证伤害和可达性，再调整血量。预警后不能追踪改向或直接生成必中伤害。失败的选招应有换招或合法换位路径，且仍满足危险预算、预警可见和至少一条可行逃生路径。普通敌人、精英与Boss的职责分开，避免全体同时包围发布技能。新机制与战术要写入内容接入和专项回归。
