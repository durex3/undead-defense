# 0.23.0：十武器与专属改造补齐

现行参考；规则、存档与验收状态见[当前项目基线](current-baseline.md)。


## 成长规则

- 武器池为飞刀、烈焰火球、圣水瓶、寒霜脉环、连锁闪电、幽灵伙伴、贯阵骨矛、符印地雷、坍缩黑洞、裁决圣剑。
- 开局从十把武器等概率无放回抽取三把，玩家选其中一把；升级中可学习其余武器，最多持有六把。
- 每把1—8级，4级、8级各自动选择一次专属改造。每把4个选项，其中1对互斥，故有5种合法双改造；十把合计50种单武器双改造配置。
- 普通升级保留原有分类权重：已持有武器55、新武器20、已有被动15、新被动10，不存在上次选择必出的规则。
- 四种被动槽、等级上限64、Boss战继续升级、三次重抽不变。当前第1关360秒、其他关480秒进入Boss战。
- 不恢复旧超武、配方、分支联动或成就。存档与编号以当前项目基线为准。

## 控制、命中与容量约束

- 冰环不冻结或减速 Boss，不冻结/减速正在冲锋的敌人；普通怪冻结0.5秒、精英0.25秒，共享3秒控制间隔，不因多次脉冲绕过。碎冰改造完全取消冻结，仅保留减速；复震不控制。
- 闪电每轮主链同目标一次、余电同目标一次；连桥每轮同目标一次，允许链节命中与桥上伤害分别结算，不继续跳跃或生成新雷击。
- 幽灵盘魂围绕锁定点三次伤害；回收点只锁定一次，不会追着移动中的角色无限往返。每只归途对同目标一次，不递归召唤。
- 骨矛使用线段碰撞，避免高速穿过敌人；贯骨加速最多3层，骨棘与主矛分别独立命中一次。骨棘有有限寿命。
- 地雷只在敌人触发后爆炸，未触发到期无伤害；延时追爆最多一次。绊线可引爆两端，不递归产生新地雷。
- 黑洞只牵引普通、正在追击的小怪，不牵引精英、Boss、冲锋、潜沙与静态目标；牵引后处理地图碰撞。同源重叠持续伤害同拍只取最高，首次跳伤对齐统一0.4秒节拍；同帧终结爆发也只取最高。反冲终结为空心环，中心无终结伤害。
- 圣剑落点锁定后不跟随目标；十字交叉处仅结算一次，重落最多一次，不追加第三剑。数量被动增加本轮总落剑数，不再次复制整轮剑雨。
- 新增武器采用192个复用攻击槽，每槽负责整次攻击、复击和结束效果。容量不足延迟整次施放，冷却不被消耗，不覆盖在场攻击。原飞刀/火球/圣水池仍保持256弹体、64地面区、64延迟任务上限。
- 敌人危险预警在所有武器绘制之后显示；静态圈、符雷、黑洞与落剑预示在角色下方，幽灵、骨矛、雷弧和落剑动画单独绘制。

## 界面与地图定位

- 升级界面显示六把已持有武器，采用两行三列；下方显示最多四件被动。升级卡只显示实际数值变化及改造节点。
- 暂停界面六把武器均可点开详情，显示各自攻击规则、已选改造、取舍和属性适用方式；被动与操作按钮不重叠。
- 六行结算表压缩间距，保留死因、关卡提示、保存结果和返回按钮；底部战斗装备分为两行显示。
- Boss固定顶部血条修复一并保留，不受离屏或底部危险提示替换影响。
- 围城可用追猎幽灵、直线骨矛、连桥闪电处理侧后排；虫巢可用地雷布防、冰环解围、黑洞聚群、剑雨清散兵。各流派提供优势，不要求唯一指定配装。
