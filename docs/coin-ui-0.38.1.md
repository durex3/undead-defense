# 0.38.1 · 账户金币显示

2026-10-21，修复主菜单及战斗HUD缺少金币数量。按用户指定，战斗顶部在生命右侧显示「生命 100 · 金币 400」，使用ProgressStore账户余额，与商店、升级和结算共用数据；不使用战斗击杀累计的world.gold代替账户货币。

主菜单显示独立的金色账户金币；选关与暂停页也显示余额。图鉴、交易确认和结算原有余额保留。运行中的HUD沿用现有刷新入口，余额变化及时反映，0金币仍显示；不修改经济、奖励、消费或存档字段。

TypeScript、5项既有HUD/报告检查及本地Web/微信构建通过。实际Cocos独立临时Chrome检查844×390与740×390：生命旁400金币、余额400→40→0及10000000大额数字、主菜单余额正常，无运行异常。见[报告及截图](../artifacts/coin-ui-0.38.1/browser-report.json)。
