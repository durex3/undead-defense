# 第9关：白骨军械库

设计日期：2026-10-13；原设计基线0.13.0。状态：0.14.0已完成可玩实现及本地验证，真人难度与微信真机待验收。下文保留设计目标，实际落地与验证边界见文末。通关第8关解锁，遵守[后续关卡设计规则](level-design-rules.md)。

## 核心体验与递进

本关的问题是“什么时候继续收割，什么时候切进去拆掉支援？”第8关教玩家在障碍间清路，第9关让前排、支援和后排形成可拆解的阵形。玩家观察军旗连线与弩箭方向，选择绕侧清掉支援，或先用范围伤害打穿前排。

主题确定为军械库，避免复用第4关钟声教堂的表现和内外圈招式。不增加抗性、武器免疫、钥匙、限时拆旗任务或场外成长系统。保留八分钟、60级、六武器位、随机三选一与成型后密集尸潮。旗手不会让敌人回血或无敌，未带追踪武器也能打过去。

第8关目前的模拟未证明难度高于第7关，圣水路线较宽容。因此第9关先检验“支援目标使走位决策更丰富”，不把增加关卡编号视为难度递进已经成立，也不为了克制圣水而添加地面伤害免疫。

## 地图原型

沿用玩家中心活动区x∈[-22,22]、y∈[-26,26]，出生(0,0)，玩家半径0.3，基础速度4.2单位/秒。四组短兵器架位于(±9,±7)，每组半宽2.5、半高1.5，均为静态矩形。

```text
                  北侧开阔区
           [兵器架]       [兵器架]
    西侧绕行       中央通道       东侧绕行
           ←──── 出生 ────→
           [兵器架]       [兵器架]
                  南侧开阔区
```

扣除玩家半径后，中央纵路宽12.4，中央横路宽10.4，侧路各宽9.9单位。兵器架比港湾货堆短，适合快速换侧；每架四周都能走通，无闭合口袋。中央保持至少半径5单位的完整战斗空间。常用路线为中央收割→沿短架绕侧接近旗手→清掉支援→回到开阔区拾取，左右均可反向进行。

兵器架阻挡实体移动，不阻挡双方投射物；选关提示必须说明。地图绘制、碰撞、出生、寻路与逃生检查共享矩形数据。复用港湾可见拐角算法前，将几何参数提取为通用接口，保留第8关回归测试，不直接复制一套导航。先用矩形验证，再制作兵器架装饰。

## 三种专属敌人

普通骷髅仍是主要收割量，新怪替换部分普通波次。下表生命相对本关普通骷髅，速度为单位/秒；所有数字为初始试验值。

| 敌人 | 生命/经验/速度 | 行为和反制 | 限制 |
|---|---|---|---|
| 护旗骨卫 | 1.15倍/1份/1.35 | 最多4只从同侧进场；若有旗手，向旗手与玩家之间的固定集合点行进，2秒后正常追击。可穿阵清群或绕侧；没有盾牌免伤 | 活跃上限16；集合点在进场时锁定，不能随玩家绕圈无限堵路 |
| 枯骨旗手 | 1.1倍/2份/1.2 | 首次可见1秒后停步举旗；光环半径4，仅使范围内普通骷髅、骨卫移速提高15%。连线显示受影响目标；离开光环或击杀旗手立即失效 | 威胁2、上限2；光环不叠加，不加伤害/生命，不影响精英/Boss/弩手/其他旗手。举旗4秒→落旗移动2秒，玩家接近1.5时提前落旗并恢复1.2秒 |
| 裂甲弩手 | 0.85倍/2份/1.2 | 距玩家约7单位停步，首次可见1秒后锁定玩家位置，预警1.35秒，射出窄直线弩矢。横移或绕侧近身处理 | 威胁2、上限2；射程9、半宽0.4、固定伤害10，一发最多命中一次；恢复1.6秒，攻击间隔至少5秒；近身1.5内取消未发射攻击 |

旗手是移动节奏支援，不是每次出现都必须立刻击杀的硬门槛。它停步举旗，范围构筑可以把敌人引进伤害区；旗手落旗移动时也可追击。光环不占伤害危险槽，但最多两只且没有伤害判定。弩箭从预警到飞行结束占一个危险槽，不能用“弹丸”绕过全场两危险上限。

新特殊怪合计威胁预算6，即两旗一弩或一旗两弩；不能两旗两弩同时存在。旗手与弩手出生需在当前可见区域边缘且至少距玩家6单位，无法找到合法点则延后，不从屏外开火。骨卫使用现有至少1秒进场提示。冻结暂停举旗/射击状态计时，减速只影响移动；旗手死亡立即解除光环，弩手死亡取消未发射弩箭，已发射弹丸正常结束。

## 八分钟节奏

| 时间（秒） | 编排与目的 |
|---|---|
| 0–30 | 普通尸潮，熟悉短兵器架和开局武器 |
| 30–60 | 单侧骨卫，每批最多4只；教学绕侧和打穿前排，无光环或远程 |
| 60–90 | 1只旗手，降低近战补充；提示“旗手加速附近骨兵，绕侧可拆” |
| 90–120 | 骨卫与单旗手配合，不加入弩手 |
| 120–150 | 1只弩手，不补旗手，教学锁线后横移；存活旗手允许落旗后保留，但不得额外补齐组合 |
| 150–164 | 普通怪/骨卫收割段，停止新的支援和远程补充 |
| 164–172 | 8秒停补、拾取；存活敌人不清除 |
| 172–210 | 精英准备及180秒精英，停止新增旗手/弩手，普通怪降频 |
| 210–250 | 支援阵：骨卫＋最多2旗手，侧路切入；不补弩手 |
| 250–260 | 10秒拾取窗口 |
| 260–300 | 火力阵：骨卫＋最多2弩手；不补旗手，鼓励先锁线再侧移 |
| 300–330 | 成型收割段，普通怪/骨卫高密度，停止新特殊怪 |
| 330–340 | 10秒拾取窗口 |
| 340–380 | 精英准备及350秒精英，普通怪降频，不补旗手/弩手 |
| 380–420 | 综合段：一旗一弩先行，稳定后允许威胁预算6；同批只新增一种特殊怪，至少间隔8秒 |
| 420–460 | 最后收割潮，最多保留1旗1弩，不继续补齐；普通怪充足 |
| 460–468 | 只补普通骷髅；468–480停补，拾取迎接Boss |
| 480起 | 清理旧专属怪、精英及其危险，保留预算内普通尸潮，军械统领登场 |

各段上限只限制补充，不因时间跨段静默删除存活者；全局威胁预算始终生效。精英存活与精英死亡休息优先于专属编排，事件跳过不补播。第9关使用独立节奏表，不能与通用停刷重复叠加。Boss尸潮保留9秒补怪/5秒停刷、全场100只与进场安全缺口，不再生成旗手或弩手。

## Boss：军械统领

Boss检验“侧移避线、识别前方扫击、把握恢复”。不复用船长撞堆冲锋，不要求背板安全色。登场2秒、半血转阶段1.5秒，均停止补怪；转阶段清除旧危险与旗标，不回血、不无敌。追击速度1.75/1.9，沿用Boss控制规则。

1. **破阵横扫**：距玩家不超过4.5时可用。锁定朝向，前方扇形半径3.6、总角度100°，预警1.3秒，单次固定伤害18，判定0.2秒；随后原地恢复2.6秒。玩家可退出距离或绕侧，近身配装能在侧后持续打。扫击期间接触伤害与招式共享受伤保护，不双算。
2. **贯阵弩击**：锁定玩家位置发射单条射程9、半宽0.55的直线弩矢，预警1.4秒，固定伤害18，每发最多命中一次；恢复2.4秒。两阶段均不旋转追踪。半血后追加第二发：第一发结束，再重新锁定并完整预警1.4秒，之后恢复2.8秒；两发不能交叠。
3. **插旗整军**：提示1.2秒后在Boss当前位置留下1枚可攻击旗标，旗标半径0.45、生命暂为本关普通骷髅3倍、存在最多6秒。其半径4内普通援军移速提高15%，规则与旗手一致；不强化Boss。Boss原地恢复3秒。玩家可以打旗、引怪离旗、或趁统领停步集中输出。旗标不召怪、不回血、不掉经验药水，计入100实体预算，最多1枚；旧旗到期/死亡/转阶段即移除。无空余预算时跳过插旗并保留恢复窗口。

循环为横扫→弩击→插旗；远距离无法横扫时，向玩家靠近最多2秒，再改为单发弩击。危险检查找不到可逃路线时延迟0.35秒，不积压连招。旗标落点不得位于障碍内；已有两危险槽时等待，不额外增加判定。第二阶段只增加已教学的重新锁定二连，不缩短提示、扩大扫击并同时加速尸潮。

Boss周围危险必须提供不穿障碍的可达出口；直线攻击不以兵器架为遮挡，预警显示完整经过路径。恢复期间Boss不追击，近身路线应能稳定利用至少2秒实际输出。弩击以弹丸连续扫掠判定防穿透，预警线本身不再造成另一份伤害。

## 配装优势与代价

| 路线 | 有利局面 | 需要补足的判断 |
|---|---|---|
| 贯穿/弹射清群 | 打穿骨卫与旗旁密集怪，迅速打开切入路 | 需调整角度接触后排，不能永远正面后退 |
| 幽灵/雷电及集中分支 | 追踪或集中处理支援、精英和Boss | 自动索敌不保证选中旗手，仍需靠近或改变目标距离；配清路手段 |
| 圣水/毒雾/地雷 | 旗手驻足与加速小怪进入伤害区时高效收割 | 分散远程需要换区，Boss恢复时主动贴近；不用免疫规则削掉路线 |
| 飞刀/镰刀/战斧近身 | 绕短架切后排，扫击侧后与插旗恢复窗口输出 | 看锁定方向再切入，保留横移空间；不要求顶着伤害换血 |

推荐配装只提示方向，不保证发牌。至少验证两种不同组合能通关，并覆盖清群、追踪单体、近身持续三种策略；没有旗标优先索敌能力的武器也必须能正常破局。

## 初始数值与验收目标

第8关倍率为普通生命1.48、精英1.66、Boss2.14、伤害1.28、经验0.85、药水40击杀。第9关试验值为1.50/1.68/2.18/1.30/0.85/40；Boss耐久只增加约1.9%，不额外叠乘全局血量。新怪和Boss招式的固定伤害不再乘关卡伤害倍率。

预期更难之处是先后目标与切入选择，而非更长磨血。对照第8关，记录首次支援击杀时间、光环影响时间、每次受伤来源、成型时间与Boss恢复期有效输出；若Boss拖时，优先修正接近机会与行为，不直接加伤害催玩家。

## 开发顺序与验收

1. 几何原型和通用矩形导航：验证三条纵路、中央横路、各架四周连通，回归港湾。
2. StageId扩展到9，接入八关通关解锁、旧存档、最佳成绩、九关选关布局与指南。现有两行四列菜单必须重新排版，检查窄屏与安全区。
3. 单独实现骨卫、旗手、弩手状态；光环按距离即时计算且不叠加，禁止逐帧重复乘速度；检查冻结、死亡、暂停、离场和实体池复用的清理。
4. 接入独立教学/收割/休息编排、威胁预算、可见出生和精英优先级。
5. Boss独立状态机与可受击旗标；旗标明确为召唤物，复用受击流程但不能继承药水/经验/成就刷取。导航、目标选择、危险来源必须识别它的生命周期。
6. 原型标识先行：骨卫长柄武器、旗手旗帜与作用连线、弩手瞄准动作；不能仅靠换色区分。美术完成后再检查预警遮挡。
7. 自动测试与第8/9关同策略至少五种子成对模拟；保留未成型、失败和超时。站定满级组合不能无脑获胜，移动通关不能依赖唯一武器。模拟不代替真人难度结论。
8. 真人检查死因是否清楚、支援是否值得切入而非必须追杀、近身Boss窗口是否可用；微信真机检查百怪/六武器/旗标/弩箭场景的帧耗时与触摸操作。

关键反例：两旗光环不叠加；旗手死亡当帧解除加速；边缘与障碍后弩手不开屏外枪；冻结不让预警先结束后瞬发；一发不多次受伤；半血二连完整提示；旗标不能卡路径或无限刷资源；Boss登场不遗留旧加速；全场100实体/2危险槽始终成立。

## 0.14.0实现记录

已接入九关解锁、最佳成绩、旧存档和上五下四选关布局。四组短兵器架使用共享绘制坐标、矩形碰撞、出生/逃生检查与拐角绕行；港湾导航提取为RectArena共用模块，原港湾地图与冲锋回归测试通过。兵器架仍不挡投射物。

骨卫集结点锁定后正常追击，旗手四秒举旗/两秒移动重组，弩手完整锁线预警后发射。新怪首次入场至少一秒；特殊怪只在可见区域且距离玩家六单位以上出生，无合法点则跳过。编排每14秒尝试补一只特殊怪，最多两旗/两弩、合计威胁6；收割段停止新增特殊怪，旧敌人自然保留。旗手举旗期间冻结会暂时解除加速，恢复后继续；冻结推迟未发射弩箭的预警，已发射弩箭正常飞行，来源死亡也不让已发射弩箭消失。屏外或近身取消未发射弩箭。

军械统领具备三招循环、原地恢复及半血二连。弩箭连续扫掠、单发单次伤害；旗标最多一个、六秒到期，占实体预算，可受击但不参与移动分离与武器击退/牵引，不提供金币、经验、药水、击杀或成就进度。实体满额时跳过插旗并保留恢复窗口。半血清理旧危险与旗标，不强化Boss或额外提高尸潮上限。

角色视觉暂复用已有像素素材：骨卫长柄武器、旗手/旗标旗帜和作用连线、弩手弩形标识、统领旗帜。敌人的碰撞与行为已独立，完整专属角色美术尚未制作。
