# 第八关设计：蚀根温室

日期：2026-10-20。状态：已接入0.30.1工作区，八关十二武器；ID8、240金币与旧存档兼容已接入。验证边界见[实现记录](stage-08-implementation.md)，三轮精英见[现行编排](elite-rounds.md)。沿用[当前基线](current-baseline.md)、[关卡规则](level-design-rules.md)及[统一美术](art-direction.md)。下列数值均为开发起点，仍需真人平衡验收。

## 1. 核心判断与成长

**看清支点、摆向与终点，绕藤臂端部换侧；花床启动前，再判断留在空心内侧还是退出实心范围。**

主机制是有固定支点、有限角度、持续单向移动的实体藤臂。不是第三关锯刃沿直线行走、第四关瞬时扇形扫击，也不沿用第七关反射、临时镜或可拆晶核。花床补充内外站位，不能把第一关已有的内外圈交替当作全关唯一创新。

- ID8，入口只要求通关7。保持随机开局、随机升级、四武器四被动、武器8级及4/8改造、玩家64级、360秒Boss。不指定武器、不保底，也不读取当局DPS或站定时长生成克制机制。
- 胜利240账户金币，失败/退出不给，重复结算去重。本批不增加第13把武器，不新增只为凑数的通关成就；通关进度本身记录第八关完成。现有金币购买和成就解锁照常加入随机池。
- 远程清群可先处理远端花囊；持续近身可利用藤根内侧与收招期；阵地配装可在预定换侧后反击。三者都必须以实际随机成长验证，不能用某一把裂甲武器作为默认答案。
- 第七关基础池三个正常生命机器人样本均在600秒未结束，不能在此基础上继续默认加厚Boss。本关先沿用第七关生命/甲档，以新站位和时间决策增加压力，再做同条件对照。

固定盆床挡玩家、敌人及实体藤臂；友方攻击穿盆。花床是从已标记的地面萌发，不由发射线传播，盆不能遮挡花床；危险范围不穿过盆体判伤，但盆后可通行地面仍可能属于已画出的同一花床，不能把盆当花床掩体。

藤臂的完整摆动扇区只要与固定盆床相交便拒绝起招，施法者先移动到合法空地；不把藤切短后临时改半径，也不让藤穿盆。起招前共用计划几何寻找可行站位，真实移动过去再完整预警；无法发布时收招并推进序列，不积压补播。

## 3. 持续摆藤：预警整个行程，伤害只在当前实体

普通藤臂固定支点、内端1.5、外端5.2、半宽0.22。完整预警1.6秒后，单向摆过100°、用时2.6秒，末端线速度约3.49，低于基础移速4.2；最终伤害22，每臂最多命中一次。

- 开招锁定支点、初始角、终止角、方向、内外长度和全部时钟。以玩家当时方位为扇区中轴，两侧各50°；左右起手按招式序号交替，不读取玩家即时移动方向修正。
- 预警画整个扫过区域的淡纹、明确起止藤臂、单向弧箭头及支点。激活后只有当前厚藤臂带实线亮边，扫过处迅速变暗、无伤；淡色扇面不是整个区域持续判伤。没有隐藏返程、横贯端点的连接线或全屏藤网。
- 藤臂以径向线段的胶囊体判伤，不是以整个扇形判伤。考虑玩家半径后，支点内侧可停留的中心半径为1.5−0.22−0.3=0.98；近身有真实空间，但不能保证该处没有其他怪或花床。
- 施法者从预警开始扎根，本体位置固定、接触关闭，始终可攻击；活动期不被挤走或黑洞拖走。攻击完恢复2.2秒，再恢复导航和接触，不能贴玩家脚下突然启用接触伤害。
- 杀死施法者取消其未发和活动藤臂，允许以输出换空间；冻结未发阶段延后整段预警，冻结活动施法者立即使该条藤臂收束失效，解冻后进入恢复，不能原角度瞬间恢复判伤。花床冻结规则另述。
- 完整扇区、端点与至少一条可行退路须落在当前镜头可用区域，剔除HUD、触控按钮和屏幕外区域；看不全则换位或取消，不能只检查支点可见。

精英藤臂：内端1.7、外端5.6、半宽0.24、110°/3秒、预警1.8秒、伤害24。Boss：内端1.8、外端5.8、半宽0.25、110°/3.2秒、预警1.8秒、伤害26。二阶段不增加角速度，也不悄悄扩大半径。每条只占一槽；双臂绝不能包装为一条。

## 4. 花床：空心环刺与实心花爆

两种形状在发布时就确定，不能临近生效才把空心填实，也不用同一个红圈只换颜色。

|形态|普通参数|预警与读法|
|---|---|---|
|环刺|内半径2.2、外半径3.5，预警1.8秒，生效0.6秒，伤害22|两圈边界与环带三角刺纹，中心留空、清楚显示内圈；可进中心或退出外圈|
|花爆|半径2.2，预警1.6秒，生效0.35秒，伤害24|实心斜排花瓣纹、向外箭头；中心不安全，完整退出边界|

环刺落点在玩家快照向施法者方向偏移2.85处（精英2.95、Boss3.1），使玩家初始接近环带，而不是每次正好站在安全中心；零距离、落点非法或没有安全路则取消。花爆锁定玩家当时脚下。两者均不追踪，不附加中毒、减速、致盲或屏幕雾。

预警地花只是投影，不是可攻击装置，无HP、不阻挡走位、不加入敌人目标池；不虚构“可拆”。生效花床不是额外怪物，独立占危险槽，每床最多命中一次，无后续伤害残留。场上100实体不包括纯投影，但危险仍严格最多两槽，不能用投影规避容量。

施法者死前未生效花床取消；已生效花床独立走完0.6/0.35秒，花瓣碎屑无伤。冻结施法者延后未生效花床与完整时钟，已生效花床照常结束。暂停/升级停止二者，结束不得补播积压。

判伤与预警共享圆心、内外半径及开始/结束时刻：环刺与玩家圆相交条件为距离区间碰到[2.2,3.5]，安全中心需d<1.9，安全外侧需d>3.8；不把玩家中心在内圈误当整个人安全。花爆需d>2.5才能完全退出。连续移动跨过生效窗时须扫掠检查，不能只采样帧末坐标。

精英环刺内2.3/外3.6、花爆半径2.3，均完整预警1.8秒；Boss环刺内2.4/外3.8、花爆半径2.4，均预警1.8秒。生效时长不变，最终伤害分别精英24/26、Boss26/28；不再乘远程、精英或关卡伤害倍率。

## 6. 三名精英

### 135秒：双节绞藤 / biforktangler

两条高低错位的卷枝肩、一条粗扭茎、四根撑地板根；轮廓竖向分叉，明显区别于普通细茎和第四关双镰兽。基础生命系数10，移速1.2、最终接触20，再应用一次共享精英生命强化及本关精英倍率。

顺序放两条精英藤臂，各完整1.8秒预警；第一结束0.8秒后才开始第二次新锁向及完整预警，不突然反扫。预约两槽，前条提前被控制取消后，第二条也必须重新完整提示。死亡取消两段，冻结活动段则取消剩余序列并在解冻后恢复。结束恢复3.4秒，关闭接触、护皮开缝。

### 225秒：迁萼巡守 / migratorycorolla

单侧展开的螺旋花萼、偏心空蕊、六根短根足；区别于双节绞藤的高分叉和育花母的对生空实双器官。基础生命系数8、移速1.25、最终接触20，生命强化只叠一次。

「错植双环」：玩家快照向施法者方向偏移2.95处先种一床精英环刺，另一床在玩家快照另一侧2.95处，两圆心相距5.9。开招即展示I/II和固定圆心，第一床结束0.6秒后才开始第二床完整1.8秒预警；每床生效0.6秒、最终伤害24。预约两槽，不追瞄、不填实中心、不补第三床。恢复3.6秒，击杀取消未生效床，已生效床正常结束。

### 305秒：对生育花母 / pairedcalyx

横向对生的空心花萼与闭口果囊、短粗腹茎、四根低垂悬根；一侧镂空、一侧实心，不能仅放大两个普通花怪拼在一起。基础生命系数10、移速1.1、最终接触22，生命强化只应用一次。

同一固定落点先环刺、后花爆；首条发布时预告两种形状和顺序，环刺结束后才开始第二床完整1.8秒预警，期间没有地面伤害。两槽预约、全程不改落点；不能让玩家刚进入内圈就被无提示实心爆命中。恢复3.6秒；只配普通芽团，首次不叠摆藤。

## 7. Boss：垂冠根母 / pendantbloom

高拱弯曲的主茎托起倒垂的四裂花冠，中央长水滴形蕊柱，五根长短不一的弧根撑地；上宽下细、重心悬垂，与第七关低宽裂洞三石足区分。不采用鹿角、船身、虫腹、铜钟、机械臂或石晶冠。花冠、蕊与根均属同一本体，不分出多个自动索敌目标。

寻敌移速1.3、正常接触22；预警/技能/恢复/转阶段关闭接触，藤招期间固定位置、可受伤。55%生命转阶段1.5秒，不回血、不锁血；取消未生效花床、活动藤臂与未用预约，已经生效的花床正常结束并继续占槽。

- **A「垂藤划庭」**：一条Boss藤臂，结束0.6秒后再锁另一条、完整1.8秒预警；预约两槽，恢复3.4秒。允许从藤臂内侧输出，但不保证无小怪干扰。非法第二段取消并正常恢复。
- **B「环萼开合」**：固定同一圆心，先Boss环刺，再给完整1.8秒无地伤间隔后放Boss花爆；预先显示I空心、II实心。每床独立一次伤害，两槽预约，恢复3.6秒。圆心按环刺落点规则选择，绝不只把落在安全中心的玩家判为必伤。
- **C大招「绞蕊合奏」**：一条Boss藤臂加一床Boss环刺，两者从最初就发布锁定计划和顺序。藤臂预警1.8秒、活动3.2秒；环刺圆心为固定支点，最初显示延时轮廓，开招1.6秒时进入完整1.8秒花床预警，3.4秒时生效0.6秒，与摆藤后半程重叠。两危险各占一槽，近侧内庭与远端外绕都纳入联合逃生检查，恢复4.0秒。

一阶段A→B→C。二阶段C→A→B，C的环刺改为一床实心花爆，圆心为预定藤臂终止方向上距支点3.6处；开招前已显示实心花纹及该固定圆心，时间同上，不临时追瞄，不在支点额外补第三床。玩家不能每次都靠同一条外绕路线，但仍有避让路线才准起招。其余招式不整体加速、不减少恢复、不缩短预警。

A/B/C取消都推进循环并进入恢复，不因地形不合法无限蓄力，也不临时替换为未教学直射。死亡清除所有本体未发/藤臂，已生效花床正常结束；胜利后停止玩家判伤。

## 9. 数值与难度递增边界
