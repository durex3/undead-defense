# 远程站位与群体移动 0.40.1

本轮承接0.40.0敌人战术优化，范围为远程怪移动、小怪拥挤与缓存路径受阻；精英配合和逐关Boss选招继续沿用0.40.0实现。本地开发，未推送远程或上传微信后台。

## 远程怪

18种普通远程怪在 `EnemyConfig.tacticalRange` 显式声明最小、偏好和最大距离，由 `RangedTactics` 处理寻敌阶段的移动：

| 类型 | 最小 / 偏好 / 最大距离 |
| --- | --- |
| 第一关弩手 | 3 / 8 / 12 |
| 第三关织锚、弧灯和第四关月刃怪 | 3.2 / 4.2 / 5 |
| 其余已接入的普通远程怪 | 2.8 / 3.8 / 4.8 |

处于合适距离且直线无遮挡时，冷却期间保持站位，准备好后由原关卡控制器决定出招。太远、太近或受阻时，在玩家周围选择可用位置，通过原地图导航逐步移动。每次搜索最多16个候选，搜索间隔至少0.6秒；目标移动超过1单位或原路线无效时清理缓存。

连续撤退最长1.25秒，连续换位最长2.5秒，随后至少0.8秒交回原控制器，避免怪物只顾逃跑、不再出招。找不到清晰射击点时回落为寻路接近。原有伤害、预警、攻击冷却和危险槽位不改；冻结、埋地、蓄力、冲刺、收招及自己的活动危险链不由战术移动接管。

第七关晶面腹足依赖真实反射路径，继续使用专用控制器；放置机关、跳扑、冲锋等特殊角色也不套用普通远程射程模板。新增远程需先确认实际攻击的射程、直线/反射/地面目标特性，再决定是否接入。内容审计拒绝无序、非有限、非正射程以及精英或静止机关的误配置。

## 群体移动

`CrowdMovement` 延续空间网格邻域检查，并修复完全重叠实体无法分开的情况。先累加邻居的分离方向，再统一施加位移，避免逐对处理的顺序偏差；完全重叠时用实体编号确定非重复方向。每个实体每秒最多接受1.2单位分离位移；多个邻居共享同一帧预算。所有分离位移检查地图线段、实体半径和世界边界，不通过穿墙纠正挤压。冻结、静止机关、已发布招式的实体及非寻敌状态不被挤动。

寻敌时1.2秒位移不足0.15单位且仍远离玩家的实体，会清理已有导航点，让原路径系统重新计算。它不是新攻击，不重置招式或额外加速。

## 验证

- `tests/ranged-crowd-tactics.test.mjs`：冷却保持距离与就绪交接、有限撤退、真实障碍绕行、冻结/预警快照、缓存失效、完全重叠分离、每帧位移预算及防穿墙。
- `tools/check-enemy-movement.mjs`：18种远程×绕圈/逼近/障碍物附近移动，共54组60秒真实世界诊断。使用实际玩家移动、敌人更新和攻击控制器，关闭武器与增援；所有样本均有攻击发布，无寻敌实体进入障碍、无超过两个危险实体。报告：`artifacts/ai-0.40.1/movement.json`。
- `tools/check-crowd-movement.mjs`：100只近战从同一点起步，运行10秒后100个不同位置、无进入障碍；单帧最大位移约0.102，未超过原移动速度加分离速度的预算。报告：`artifacts/ai-0.40.1/crowd.json`。
- 实际Cocos浏览器额外检查第一、三、十六关远程追逐及冻结群体位置，报告：`artifacts/architecture-refactor/browser/browser-report.json`。
- 完整回归、类型、内容审计、架构/武器对照与本地双平台构建：`npm run verify -- --full`，报告：`artifacts/verification/full.json`。

本轮692项回归中691通过、1项历史跳过；完整检查九步通过。单独重跑移动/百怪诊断前先执行 `node tools/test-build.mjs`。

移动诊断不是通关测试或真人胜率。专用反射怪不在54组通用远程诊断内，沿用现有第七关专项回归。未对手机帧率作性能结论；继续保留空间网格、候选搜索间隔和路径缓存，真机体验仍需试玩反馈。
