# 第二分支：独立进化规则（2026-10-13）

本规则覆盖此前“所有分支保留配方联动”的设计。十八种武器均提供两条路线：

- 第一分支（◇）：保留原有武器组合路线。
- 第二分支（◆）：独立进化，依靠自身攻击完成输出，不产生配方标记、额外组合伤害、组合追击、净化法阵或噬魂弹。
- 任一配方成员选择第二分支，该配方整体不再激活。不得出现一方独立进化、另一方仍借其触发组合的情况。
- 两件武器均保留装备与正常攻击，仍占两个槽。已有的通用武器标签加成继续适用，它不属于配方联动。
- 组合宣布等待分支选择结束。旧存档的第二分支 ID 保留，加载后适用独立路线规则。

## 界面与验证

分支卡明确显示“组合路线”或“独立进化”；升级装备清单、暂停、战斗栏、结算使用◆表示独立进化。已选独立路线的配方提示不再声称能够形成超武，也不能锁定为推荐组合。

新增回归覆盖全部18种第二分支单独输出、伙伴满级但不释放攻击时不增加配方伤害、全部9个配方任一侧独立时禁用组合、分支选完前不误报超武。伤害对比隔离了通用标签加成，不把通用加成误当配方联动。冻结首领免疫、实体池上限、击杀转锁不刷新寿命、无递归爆破等约束继续保留。

本地开发版本，未提交或上传微信后台。数值与构建验证不能代替真机长期体验。
