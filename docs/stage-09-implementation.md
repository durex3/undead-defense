# 第九关实现与验证

2026-10-20，工作区开发版0.31.0。第九关「断羽风廊」已接入。本次为本地开发与Web构建，未提交、推送、上传或发布微信包。

## 已实现

- WindMap、WindGeometry、WindSystem经StageStrategy接入。中央风庭、双内庭与外廊使用设计障碍；风柱挡角色、敌弹与滑翔本体，不挡友方攻击。
- 风带预警1.8秒、持续2.6秒、推力0.8、零直接伤害。玩家与未扎根地面敌人使用同一套小步移动/碰撞滑动，逃生预测也调用该函数；包括反应期已有风推、顺逆风与无输入漂移。全场最多一条风带，预警与延迟计划均占槽。
- 曲羽按自适应二次Bezier折线的弧长推进，控制点对弦误差上限0.001单位；绘制、柱检查、弹头与连续相对扫掠共用数据。发布后固定，不追踪、不随风改变。当前弹头最多命中一次，预警与旧尾无伤；保留跨结束时刻的最后扫掠。
- 折翼踏卫和Boss使用锁定的两段实体折步，折点停0.35秒；本体与判伤共用路线，普通接触关闭。寒霜可打断普通折步并就地恢复；锁定本体不被风、黑洞或挤压推离预警。
- 四主力、两精英和悬翼风枭均有独立骨白空心陶鸟轮廓、暗面、暗铜接缝及收招开缝。风、羽弹、折步使用不同几何和独立编号，省电模式保留判读信息。
- 精英135/225秒单独教学，305/311秒第三批错峰返场。前两批结束并休整后才可开始第三批；延后时至少隔6秒，首名最晚328、次名最晚334秒，不补播积压。两名共享两槽；可用时原子发布配对，有界3.2秒会合窗口协调独立恢复时钟，组合非法则回到已教学单招。
- Boss360秒登场，等待最后一名精英死亡至少3秒再进攻与增援。A两次曲羽各自完整预警，中间0.6秒；B风与实体折步；C风与曲羽。55%进入第二阶段，不回血、不锁血、不整体加速；已释放风/羽弹独立有限存活，未发部分和自身折步按规则取消。
- 通关8解锁9，胜利260账户金币、结算去重，沿用原存档键并接受旧1～8合法进度。保持十二武器与四项成就，不强制或保底抽取武器。

用户追加：全部关卡精英初登场和返场均为同时间正常生成生命的100%。第一、二关90%/110%轮次修正、前七关85%返场折扣均已移除；第九关也不使用原设计65%折扣。保留精英自身基础生命、共享精英强化及关卡生命倍率，各应用一次。

## 成长与限制

[模拟数据](../artifacts/wind-stage/simulation.json)包含16次同种子第8/9关对照：四种合法满级四武器、站定/移动各一组，高生命仅用于观察输出窗口。第九关八组均击败Boss，基础配装121.5/126.9秒，阵地204.0/218.3秒，召唤210.8/220.9秒，含重锤/飞轮65.7/63.3秒。Boss生命倍率3.60与第八关相同，没有靠加血或预警加速制造递增。

十二次随机开局/升级成长诊断使用三种子、基础/已解锁武器池、巨大/正常生命各一组。均实际生成并击杀四名精英，最高100实体、两槽；巨大生命六局为2胜、4局600秒仍战斗，正常生命六局为1胜、5局约600秒仍战斗，基础池三局均未结束。双精英联合招在部分高生命样本实际出现；正常生命机器人样本多在组合前先击杀一名，单敌击杀确实减压。

正常生命机器人采用有限0.6秒贪心预测，不等同真人；部分基础配装Boss时间偏长，真人难度、成长收益与微信真机性能仍待试玩验收。当前功能完成不等于这些平衡指标已通过。

第十关起Boss按用户新增规则使用三阶段；本关保留两阶段。
