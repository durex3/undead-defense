# 0.22 武器重制：实现与验证

2026-10-15。按已确认的 [v3设计](weapon-system-redesign-v3.md) 实现首批可玩样本。旧18把武器的攻击、双分支、超武融合、联动、配方图鉴和商店成长均已退出游戏运行目录，源代码及对应旧测试放在 `archive/weapon-system-0.21/`。当前可玩的是飞刀、火球、圣水，另外7把仍为候选，没有冒充已经实现。

## 成长规则

三种武器均1—8级，4级和8级免费选择一次改造，自动进入选择，不增加经验成本、不重置冷却、不额外触发攻击。每把4个专属改造、1组互斥，每把5种合法双改造，共15种。已选不重复；互斥灰显，第二次选择至少2项可选。现有攻击按施放时参数结束。

四个被动槽，八种被动候选。角色统一加成：游侠伤害/移动各+10%；炼金范围/持续各+15%；亡灵冷却−8%、拾取+20%。不新增角色，也没有隐藏配方。

升级按已持有武器55、新武器20、已持有被动15、新被动10的类别权重抽取，再在类别内等概率选择，三选一不重复、无重复技能保底，共3次重抽。完全成型后受伤提供20生命，满血提供继续战斗。当前只有3把样本，成长完成早于未来6武器完整池；不通过隐藏池子或假六武器解决。

飞刀射程7、速度11；追猎有限转向2.2弧度/秒，每段最多穿2个不同目标。普通飞刀命中1人终结，往返在终结时锁定玩家位置。环绕原持续1.1秒，受持续加成但上限为攻击周期90%，保证空档；每刀每段对同目标只命中一次。碎刃每轮共2枚，伤害为改造后的主刀50%，射程2.4，不继承追猎/往返/散射。

火球飞行速度7，接触仅触发一次爆炸。重爆蓄能0.35秒、周期×1.3、半径×1.5；内圈55%半径伤害×1.8，外圈×1.25，互斥结算。连珠总数量+2，三段间隔0.12秒，每球伤害×0.52、半径×0.85，数量被动增加一轮总数。碎焰主伤害×0.8，每主球2枚碎片，碎片伤害为主球35%、爆炸半径60%，向左右散射，不递归。火海即时伤害×0.75，持续2.6秒并受持续属性影响，每0.4秒主球伤害12%。

圣水瓶飞行0.45秒后落地；水区每0.4秒一跳。圣泉由45%长到165%半径，前半段完成扩张；奔流速度2.5、每跳伤害×0.8。回涌持续×0.85，后半程锁定一次玩家位置，以3.8速度回流，终点固定，到期消失。水爆改为每秒全局同步爆发、伤害×2.5，间隔不伤害。圣泉回涌后停止扩张。同一武器地面重叠取最高伤害，火水各自独立，无额外联动。

## 界面与性能边界

升级上方展示三把样本的持有状态、等级和改造，以及四个被动槽；选择卡只显示本次增量。改造卡显示行为、收益、代价和互斥原因。暂停点击武器查看实际参数、两个改造和数量特例。底部基础名+等级+改造图标/短名，结算按基础武器合并全部子弹和地面伤害。

飞刀为细长刀迹，追猎/返程有独立标记；重火球蓄能和爆炸双圈、碎片更小；水瓶有抛物线，水区有边界、推进弧、回流线或同步水爆。敌人预警最后绘制，不被地面效果覆盖。视觉粒子上限省电64/普通120，不影响真实伤害。

复用弹体池上限256、地面池64、待发队列64，按整轮攻击及后代预留；满池延后整轮，不覆盖旧对象。穿透按敌人ID去重，子对象不递归。3倍速沿用固定模拟步长。尚未完成真机发热验收，不能用桌面表现宣称手机性能通过。
