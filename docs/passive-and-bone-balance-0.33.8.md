# 0.33.8：指环、烛台与骨矛裂骨重做

2026-10-21。依据玩家反馈：骨矛终点骨棘很少被踩中；复刻指环与广域烛台满级后多种范围武器接近清屏。本轮保留两个被动，调整它们的叠加收益，重做骨矛的实用性。关卡、成就、金币、购买/进阶路线和存档键保持兼容。

## 广域烛台

仍为4级，每级+10%覆盖面积预算；圆形攻击半径乘 `sqrt(1+0.1×等级+角色面积加成)`，取代把该系数直接乘半径。

满级从原来半径×1.4、面积×1.96，变为半径约×1.183、面积×1.4；炼金术士15%同类加成并入预算后，满级半径约×1.245，取代×1.55。线宽、环绕距离等继续使用同一半径倍率，不声称不规则图形的面积严格按圆面积变化。圣泉、重爆等专属改造自己的形态倍率保留，烛台负责收紧通用乘区。

角色介绍、升级卡、暂停属性和武器说明同步标为覆盖面积。攻击宽度、实际判伤与绘制仍共享stats.radius。

## 复刻指环

仍为2级，每级追加一次攻击。原有等级/改造增加的攻击不减伤；只给指环追加的攻击独立快照，伤害为本轮原攻击的40%。火球、圣水、冰环、落雷、地雷、黑洞、圣剑的复制攻击半径为80%（覆盖面积为64%）。飞刀、骨矛和幽灵保留原宽度/爪击范围，收紧的是追加伤害；引魂灯和缚影缝针原本不受数量影响，继续不复制。

以基础1发武器为例，满指环同目标理论伤害从3发全伤的300%变为100%+40%+40%=180%；原有攻击不是一并摊薄。多发武器只对末尾的指环新增部分折减，不能把等级或专属齐射也当成指环复制。

重锤/飞轮沿用0.33.6已有「首击100%，所有追加40%」规则，不再叠乘一次40%。骨矛裂骨、火球碎焰/火海、水区、幽灵返程等派生继承各自父攻击快照；复制落雷的雷暴、回击和连桥也继承折减，雷暴圈按真实复制半径绘制。同源水区/火海/黑洞仍保留既有最大值合并，不能靠多区域重叠刷多份同源伤害。

实现入口在`ArmoryConfig.replicaStats`及三个施法家族，按攻击索引区分原有/复制。数量增长依然提供覆盖和稳定性，伤害/控制收益均需看实际落点，不能预设每次升级都必然打到更多敌人。

## 骨矛：骨棘留阵 → 裂骨爆发

保留内部改造ID `ridge`，兼容存档和已有改造组合，只替换显示名称与行为。

- 主矛实际穿过敌人时，在该敌人的真实命中位置炸出碎骨；不再等飞到最大射程、落地后等待踩陷阱。
- 每次裂骨造成主矛最终快照35%的小范围伤害，主矛继续贯穿。
- 每根矛最多触发3次；每根矛对同一敌人的裂骨最多命中一次，不因多个爆点重叠重复计伤。
- 保留主矛伤害−15%的代价；单敌实际命中时可获得主击+一次裂骨，理论合计为未改造主矛的114.75%。
- 初始碎骨半径0.9，跟随骨矛宽度的等级/范围倍率；身体半径沿用现有0.35碰撞余量。
- 破阵重矛与扇骨齐射保留各自射程/数量形态；贯骨加速只按真正的主矛贯穿计层，碎骨不再叠层、不递归生成矛或更多碎骨。
- 删除旧终点骨棘的地面图形，改为命中处短促骨片爆裂。持续属性不再延长不存在的陷阱；武器说明不再展示骨矛持续时间。

## 后续规则

后续新增武器/被动不能只测无被动单武器。必须覆盖数量、范围、持续、冷却的组合收益，包含合法改造、派生继承、重叠合并和控制覆盖；按职责允许差异，不用统一提高敌人血量来掩盖某个通用被动过强。修改任何快照乘区时同步检查原有攻击是否被误削、追加是否重复折减、视觉范围是否与判伤一致。
