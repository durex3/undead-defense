# 第十五关设计 · 沉铅铸庭

2026-10-21。**已在本地0.37.0实现并开放，未上传微信后台。** 最终行为与验证边界见[开发记录](stage-15-implementation.md)，下文保留原设计候选供对照。沿用[统一规则](level-design-rules.md)：肉鸽生存、随机构筑、四武器四被动、360秒Boss及三个阶段不变，仅改变敌人尤其精英/Boss的战斗机制。

## 1. 核心判断：穿空丸，看下一次落点

第十四关判断光束旋向和柱影；本关判断**弹丸当前在空中还是落地，以及下一次落点的时序**。

铅丸沿公开的抛物线接力弹跳。空中的丸体、地面投影和虚线轨迹均无伤，只有落地时短暂的实心冲击区有伤。玩家可以从高飞铅丸的地面投影下穿过，提前走出下一落点，或绕开整条有限落点链。不能用整条飞行轨迹、整片预警区或投影当伤害。

它不要求玩家跳跃、格挡、踩机关或新增按键；也不增加护送、守点、运输、场外追逐等通关任务。穿空丸是可选高手路线，普通通关只需避开实际落点。

- 候选ID15，通关14解锁，无指定武器、品阶、移速或成就门槛。
- 四类主力、两精英、三轮精英；返场均为同时间正常生成精英HP100%。
- 实体上限100、特殊威胁6、全场两危险预约槽，含预警、飞行、驻丸和未到时的后续落点。
- Boss按70%/35%三阶段，不回血、不锁血、允许跳阶段。
- 建议新增2成就（24→26），补火球精良/稀有两档；不增加新系列，随机池仍十四系列。
- 候选通关380金币，失败或退出不发通关金币，同一局去重。

美术为冷铅灰、旧铜褐、少量骨白与暗青，采用既有Cocos Graphics墨线。阵营由分节铅屑爬俑、悬臂投架、折膝三足架、侧斗轮车组成。精英分别是双臂投架与三节压铸体。Boss「抛铅铸主」是低重心三足配重架、两只倾斜丸斗和可展开投臂，不采用第12关烟囱/陶炉、第13关持刃傀臂或第14关浑仪环。阶段II展开第二斗，III张开配重翼，不能只换色。

铅丸悬空时丸体与投影分离，投影用灰色空心小椭圆，始终无伤；下一落点用编号、环形倒计时与明确危险色，后续落点稍淡但可读。落地仅在真实0.16秒内显示实心压地/短碎铅；视觉余尘不伤人。禁用满屏白闪、长尾光柱或持续火海遮挡下一落点。

## 3. 弹跳链的几何、预警与撤招

### 3.1 固定落点，空中无伤

单颗铅丸包含完整只读计划：实际出丸口S、落点P1/P2/P3、每程发射/到达时刻、落地结束时刻、投影半径、飞行高度与所属组/阶段。发布后不追踪玩家、不改落点、不临时延长地面停留。

- 普通完整落点预警2.2秒，精英/Boss2.4秒；**全组所有落点与编号从发布时可见**，各自到达时距发布均不小于完整预警。
- 每程飞行0.8秒，落地冲击0.16秒，实际冲击半径0.80；玩家相交判断加0.3，中心距大于1.10安全。精确正切按共用圆边界处理。
- 第一程在P1到达前0.8秒从真实出丸口发射。下一程在前一落地冲击结束后起跳，所以相邻落地启动间隔0.96秒。没有未公布的加速弹跳。
- 后续飞行的地面位置为`Q(u)=(1-u)A+uB`，`u=(t-launch)/0.8`；高度`z(u)=4×1.4×u×(1-u)`。首程从0.8高的实际丸斗出发，使用`z(u)=0.8(1-u)+4×1.4×u(1-u)`，高度上限约1.83。
- 丸体画在`(48Q.x,48(Q.y+z))`，投影画在地面Q；渲染高度不改变地面坐标。整个飞行期间均无伤，包括接近地面的最后一小段；进入公布的落地窗口才判圆形冲击。
- 每个落点每名玩家最多一次命中尝试；同一颗丸的不同落点分别计次。两颗丸独立，但联合逃生验证不能利用受伤无敌帧。

三落点的精英/Boss样例：发布t0；落地窗口依次为`t0+[2.40,2.56)`、`[3.36,3.52)`、`[4.32,4.48)`。第一程于t0+1.60发射。未来落点虽早已预告，在其到时前仍无伤。

### 3.2 与前关不同的安全判断

地面投影可穿，配重台不提供空中挡弹能力；落点危险只持续0.16秒。玩家不用追着铅丸跑，只需观察编号和下一次到时；同时存在两条链时看分开的组号与倒计时。丸体本身不能受击，也不是必须优先击杀的新设备，避免自动攻击被假目标分走。

可选穿空例：一程从(-1.2,0)飞往(1.2,0)，飞行t=1.0～1.8。玩家在x=0以基础4.2速度沿y从-0.462走到+0.462，用时0.22秒、时段1.29～1.51；地面投影与玩家在中途交叉，丸体最低仍高1.294。若继续同方向走，到下一落地时与(1.2,0)相距2.065，大于1.10。静态工具已采样这个单程，说明穿行不需要移速升级；**不是所有双链组合的可解证明**。

### 3.3 连续判伤及计划合法性

只对每个半开落地窗口检查玩家扫掠线段与真实冲击圆的连续相交。低帧必须按发射、到达、落地结束及下一程发射时刻拆分；不能因为一次更新跨过0.16秒而漏判，也不能把该帧空中移动整段补成伤害。暂停不推进时钟。角色被墙滑行时使用实际分段轨迹，不能只拿帧末坐标或原输入方向判定。

计划发布前需检查：所有落地圆完整不碰障碍/地图边界；所有落点标记、实际飞行高度与丸体投影在手机可用视区内，避开HUD；最多两颗丸、两条预约链；基于基础4.2移速、0.35秒反应、当前人群和实体配重台，整组有无伤路径。不能只验证两条链各自能躲。

候选可围绕实际出丸口旋转或改选预先定义的左右手方案；不能把整组平移到与丸斗无关的位置。原地没有合法组则真实导航换位后重新给完整预警，不强行投丸、不瞬移、不补播积压动作。接近目标距离≤5.2再尝试，远距追近与边缘脱困需和14关同样验证，不能让Boss一直追不上。

### 3.4 预约与取消

一颗丸从预告、初飞、落地、再飞到最后落地结束占一槽；不是每个落点另占一槽。双丸整组原子预约两槽，禁止附送第三次身体冲撞、震地或地雷。投丸组中本体固定、持续可被所有武器伤害，关闭额外普通接触扣血。

|发生时机|冻结/死亡/转阶段的处理|
|---|---|
|第一程尚未发射|整颗丸与未来落点取消|
|已经在某程空中|只完成这程与其原定0.16秒落地；后续再跳全部取消|
|当前已经在落地窗口|当前冲击按原时刻结束，取消以后各程|
|驻丸待回跳|驻丸无伤，尚未发射的回跳取消|
|Boss死亡|胜利清场，所有丸与未来伤害结束|

撤招当帧记录生效，不等下一帧再判断是否已经起飞。转阶段至少1.5秒且等待当前已发飞行及落地完成，不回血、不锁血；结束后才恢复、暴露甲缝和接下一组。死亡普通/精英的已发丸继续可见，来源丸斗留下淡色标记直到该程结束，不能有看不见的落地伤害。

## 5. 三阶段抛铅铸主

定义投射基准：O为实际本体，u为发布时朝向，v为其垂线，`d=clamp(本体至玩家距离,2.8,4.4)`，T=O+d·u。基础折跳点A=O+0.65u−0.25v、B=T+0.9v、C=T+0.9u−0.7v。A是固定近斗落点，距本体约0.697，会覆盖贴身站位；B/C为中距落点。直跳用T±0.9u。整套方向只能发布前调整，发布后锁定。侧斗出丸必须从实际可见丸斗，最大偏置1.1；后续每程从前一真实落点出发。

近斗点始终按招式模板存在，不因玩家站定、DPS或持有近身武器才出现；它和其他点一样给完整预警，不增加额外攻击槽。不能让所有招都只砸远处，使贴住Boss永久免受威胁。

两条链可用围绕O的±25°左右模板，不能临时把第二条链追到玩家脚下。下表是候选动作表，开发时逐项做联合退路与投影可视验证，不合格则调整候选相对角或落点间距，不能靠额外无敌帧放行。

|阶段/动作|内容|预约|最后已发落地后基础恢复|
|---|---|---:|---:|
|I A 跃丸试步|本体单丸，T−0.9u→T+0.9u两跳|1|4.2秒|
|I B 折膝三跳|本体单丸，A→B→C三跳|1|4.4秒|
|I C 双斗错投|左右斗各一丸，各两跳，第二丸晚0.8秒|2|4.8秒|
|II B 回斗折跳|可见侧斗单丸，C→B→A反序三跳|1|4.6秒|
|II A 驻丸回跳|直跳两落点，第二落地结束后驻丸，另给2.4秒预警，再从驻点飞回首点|1|4.8秒|
|II C 双斗错阶|两丸各三跳，左右模板反序，第二丸晚0.8秒|2|5.0秒|
|III C 大招沉铅交铸|两丸各三跳，第二丸晚0.48秒，落地相互穿插；伤害28|2|5.4秒|
|III B 错折回铸|A→B后驻丸，另给2.4秒预警，从B飞回A；不偷偷追加第四跳|1|5.2秒|
|III A 并斗逆阶|两丸各三跳，一正一反，第二丸晚0.8秒|2|5.0秒|

I依A/B/C，II依B/A/C，III依C/B/A循环。所有常规飞行0.8秒、落地0.16秒、半径0.80保持；后续阶段不整体缩短预警或加大落地圆。III的0.48秒是两条**从发布时同时预告**的链交错，不是新锁定后只给0.48秒反应。

驻丸回跳示例：原两落点2.40、3.36秒，第二落地3.52秒结束；新回落点5.92秒启动，5.12秒起飞、6.08秒结束。驻丸期间无伤，原点及回跳箭头可见；仍预约同一槽，不释放后再抢槽，也不把驻丸变成地雷。

恢复统一乘关卡0.35下限一次，作用于恢复而非预警/飞行。Boss仍按75%/50%/25%血线给既有补给，敌群/破甲/控制规则保持，不额外设永久免疫某类武器。

## 7. 配套成长：两成就、火球两档，无新系列

### 通关章与高难挑战

1. `leadfoundry_clear`「铸庭卸铅」：通关15；仅图鉴标记，通关380金币只发一次结算，不重复叠成就金币。
2. `lead_twelve_paths`「十二途踏空」：**12种不同实际起手，每种4组不同合法双改**；每局起手8级且双改保留，Boss三阶段各完成一次有效“穿空丸”，Boss来源实际扣血0；III的穿越必须来自C双丸大招组。至少48次合格胜利，比14关36次增加组合深度，不能直接把旧胜利补算。
