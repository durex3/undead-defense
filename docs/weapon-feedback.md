# 武器与升级反馈修复（2026-10-13，本地待发布）

## 已实现

- 镰刀与战斧自动寻找射程内的首领、精英或最近敌人；修正弧线瞄准偏移，不再按移动反方向投掷。没有可达目标时不消耗冷却。
- 飞刀环绕分支扩大末级覆盖并向近敌偏移；回返分支的发射扇面朝向目标。碰撞与绘制使用相同位置。
- 烈焰火球的陨火末级可攻击三名不同敌人；雷电集火分支最多覆盖五名敌人。次级攻击不反复叠加到孤立首领。
- 裁决光矛最多三个不同落点；灭星重陨保留主陨重击，增加两处较弱碎陨。孤立首领仍只获得一个落点。
- 焚魂烙印与蚀魂独缚在目标死亡后转锁，继承剩余持续时间和原有伤害节拍，不延长持续时间。烙印增加小范围灼烧。
- 幽灵弹目标死亡后重新索敌，不刷新弹体寿命。
- 升级界面展示六槽装备及等级；新武器卡提示已拥有的配方伙伴、伙伴等级、组合名称及双10级条件。
- 分支界面显示清群、集火、射程及续航取舍。◇表示单武器分支，∞表示组合联动。
- 组合列表明确：当前超武保留双方分支攻击，并增加专属组合效果。并非所有组合都完全替换为独立攻击系统；不得把当前实现描述成“超武后只释放全新技能”。战斗栏仍合并显示组合名称。
- 经验附近合并采用数值相加，无过期、数量淘汰或覆盖。增加合并100次、全收经验及重复拾取防护测试；大额经验晶体适度放大，最大1.65倍，不增加绘制数量。

## 验证与边界

TypeScript检查通过，291项测试通过。网页与微信目标构建验证通过。844×390触屏横屏检查升级卡与分支界面，装备清单及组合提示无重叠。

`tools/weapon-balance.mjs` 为30秒静止高血量靶诊断，结果存于 `artifacts/weapon-feedback-balance.jsonl`。例如光矛群体总伤害22453，高于9级17185；灭星重陨群体11124，高于9级7944。该数据只验证攻击覆盖和伤害执行，不代表移动怪物环境的通关率；集中分支仍允许牺牲部分群攻换首领输出。

本轮保持已有实体池与上限，没有为补强增加无界残留特效。手机发热需真机长时间测试，构建与桌面测试不能证明温度改善。本轮未上传微信后台。
