# 精英与远程压力强化（2026-10-14）

目标：针对试玩持续一次通关的反馈，提高精英与远程威胁，要求更充分的配装与走位。强化幅度按反馈直接落实，不因机器人模拟失败而降低难度。

- 精英：双刃刽子手、铁蹄统领，血量与所有伤害均为此前2倍，包括碰撞、扇形技能和冲锋。攻击频率维持原值。
- 远程小怪：骸骨术士、骨弓猎手、投锚手、裂甲弩手、刻痕师、熔线工、落锤匠、棱光射手、分镜祭徒、引潮者、回响摆渡人。血量与所有伤害为此前2倍；完整攻击周期（前摇、恢复、冷却）缩短至一半。激光、落点等远程施法一并覆盖。
- 箭弹速度4.5→9，飞行存续时间相应减半，射程保持原值。实际碰撞、箭弹绘制和避险判定共用 projectileSpeed；高速跨帧仍使用线段碰撞。
- 首领、普通近战怪、召唤支援角色的属性不变；移动速度、掉落、怪物预算与危险槽位不变。召唤出的远程单位也适用对应类型强化。

此次明确覆盖旧关卡规则里远程小怪的前摇最低时长；例如骨弓0.65→0.325秒、术士1.1→0.55秒、后期远程1.5→0.75秒。首领的预警时长保留。冻结、暂停、源死亡取消及组合预警只伤害一次的规则仍保留。

验证：340项测试与TypeScript检查通过。覆盖精英实际技能伤害、11种远程类型属性、攻速与移动速度分离、9速箭弹跨帧命中、前摇与冻结一致性、远程落点翻倍与首领参数保持。旧测试的固定血量、伤害、时长断言按新规则更新。本轮不以机器人胜负作为降难度依据。
