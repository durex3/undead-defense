## 第六、七关同条件诊断

`node tools/check-prism-stage.mjs`记录12种合法四武器×3种子×站定/移动×两关，共144次高生命固定配装Boss输出诊断。参照是已加入厚蜡甲的第六关；高生命结果不算正常胜率。[当前数据](../artifacts/prism-stage/simulation.json)保留全部失败、超时和路线取消，初始3.20倍率快照另存于`simulation-initial-3.20.json`。

|固定配装|第六关平均Boss秒数|第七关平均Boss秒数|
|---|---:|---:|
|基础配装|114|117|
|控制配装|122|130|
|含重锤|55|57|
|含飞轮|52|55|
|重锤阵地|115|123|
|重锤与飞轮|58|63|

以上各项每关6次均在180秒内完成，其他配置的超时仍记录为未结束。第七关Boss生命倍率由初始3.20调为3.60，保留原预警、恢复和危险上限；没有用缩短反应时间制造递增。

另外24次真实随机成长包括12次高生命诊断与12次正常生命机器人。高生命12局均在360秒前击杀两名精英；正常生命12局为6胜、5局到600秒仍在战斗、1局失败（双解锁、种子19、524.1秒）。纯基础池3局均存活但600秒未结束，说明随机成型及输出效率仍需试玩调优。机器人采用固定0.9秒贪心避险/拾取策略，不代表真人胜率，不能据此宣称所有随机配装都能通关。
