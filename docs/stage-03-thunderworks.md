# 第三关设计：雷铸机庭

现行设计基线更新：2026-10-19。编号、成长、存档与验收状态以[当前项目基线](current-baseline.md)为准；美术遵循[四关统一美术规范](art-direction.md)。本文招式参数属于设计参考，实际行为以当前代码为准。

## 1. 核心体验

**看懂锁线顺序，换道穿过电墙缺口，拆掉关键机械后反击。**

第一关考验拆盾弩阵、绕侧切后排；第二关考验分裂清群、折返和出土追击；第三关考验路线判断与进攻顺序。新阵营为雷铸机械构造体：低矮多足行机、落锚蛛机、导弧浮灯、滑轨切割机，两种精英和大型多臂机械Boss。全部使用新轮廓与动作，不沿用骨兵、沙虫或军团角色换色。

难度高于第二关，但不给怪物全属性大幅翻倍。配装成型可以更快拆阵、打掉关键装置、缩短Boss战；仍需主动避开锁线与推进墙。没有挂机检测、按配装反制、动态加血、伤害反射、临时技能失效或强制武器配方。

沿用8分钟进入Boss战、等级上限64、最多六武器、四被动、武器4/8级各一次专属改造。Boss战继续获得经验。此次不改局长与全局经验曲线，不新增角色或成就。

## 2. 地图：中央交汇场与四条绕行侧路

活动范围x±22、y±26，玩家出生(0,-8)。四座矩形绝缘机座中心(-11,-12)、(11,-12)、(-11,12)、(11,12)，各半宽1.2、半高2.2。中央半径6保持净空；机座不移动，不制造死路。中央东西/南北十字轨道连接四侧回路，外圈可从每座机座两侧绕过。

```text
               北侧回路
       [机座]             [机座]
              \    |    /
 西侧回路 ─── 中央交汇场 ─── 东侧回路
              /    |    \
       [机座]             [机座]
               南侧回路
                  出生
```

轨道是方向地标，平时不造成伤害。只有出现明确的敌方预警后，相应轨段才带电；不额外叠一个独立的环境陷阱计时器。机座阻挡角色、怪物与地面移动机构；与前两关一致，不挡飞刀、圣剑、雷击等攻击，也不充当挡弹安全墙，选关说明明确显示。

基础移速4.2、角色半径0.3作为躲避基准，不能假设玩家持有鞋子或游侠移速。主要换道口净宽至少3.6；推进墙缺口净宽至少3.6，另计碰撞半径与0.35秒反应余量。所有普通路线、Boss体型路线、出生点和机座两侧都需验证连通。

场地不要求从中心跑到地图另一端才能躲技能。可产生伤害的墙体/电弧必须先在屏幕内完整展示；屏幕外尚未看到的电墙不得直接撞进玩家。找不到合规投放位置则延迟或取消该轮，不把预警强塞进屏幕边缘。

## 3. 数值与统一威胁预算

以下为开发起始值，不代表已证明平衡：

|普通怪血量倍率|1.72|1.82|
|精英血量倍率|1.95|2.08|
|Boss血量倍率|2.65|2.86|
|接触伤害关卡倍率|1.46|1.50|
|经验倍率|0.85|0.85|
|有效普通击杀掉药间隔|42|42|

沿用当前普通怪随时间成长的上限，不额外延长成长时间。新普通怪参数以共享普通基线相乘；两名精英沿用一次精英×2基线，不能再次叠加。下文技能伤害均为最终值，**不再乘关卡倍率或远程×2**。若接入共享远程列表，须拆开配置避免重复倍增。

全场最多100个敌人，包括装置与Boss援兵；普通行机仍为多数。总威胁上限6，精英最多1名，危险槽最多2个。落锚蛛机最多2、导弧浮灯最多2、滑轨切割机最多2；装置最多4，全都计入100实体上限。装置不是额外攻击发射者，不另开隐藏危险池。

两个同时生效的电弧算两个危险槽，不能将多条独立伤害线包装成一个“技能组”绕开限制。连招提前预约槽位，每段再次检查出口；小怪已发出的攻击保留至正常结束。Boss等待现有危险结束后再发布需要两槽的技能，不能强行覆盖。

## 4. 四类专属小怪

|敌人/内部ID候选|外形与职责|初始血量系数/移速/接触基值|威胁|
|---|---|---|---:|
|铆齿行机 / rivetwalker|扁平六足、铆钉背板、前方短冲锤；主要经验来源|1.1 / 1.7 / 8|0|
|落锚蛛机 / anchorweaver|四条高脚、腹下可见电锚、蓄能时腹囊下垂|1.7 / 1.15 / 10|1|
|导弧浮灯 / arclantern|悬浮双叉电极、中央明亮灯芯、可见引线|1.55 / 1.25 / 10|2|
|滑轨切割机 / railsaw|低身双轮、侧向大锯盘、移动时留下短轨迹|1.9 / 1.8 / 12|2|

普通特殊怪出生距玩家至少6，入镜至少1秒才可起手。首次展示每个机制时单独出现，不叠另一个特殊攻击。普通技能不推拉玩家，不附加禁足、眩晕或技能封印。

### 铆齿行机：交错推进，保留清群收益

普通追兵约75%，其余最多8只承担横向编队：生成时锁定一处玩家侧方3单位的合法集结点，最多绕行1.8秒，再普通追击。每波侧围方向交替，不每帧预测角色位置；到点、路线失效或超时才重算导航。

无远程攻击、无死亡爆炸、无分裂、无正面减伤。让骨矛、奔流、火海和地雷都有清群价值，不通过免疫持续伤害抹掉这些流派。

### 落锚蛛机：旧位置临时失去安全

距离3～8时抬腹蓄能，锁定玩家当前坐标，投出一枚可见电锚。落点半径1.3，预警1.15秒；锚落地后再武装0.45秒，首次完整伤害不得早于起手1.6秒。武装后电区持续2.2秒，每0.6秒造成10伤害；没有额外落地爆炸或接触伤害。

电锚可攻击，生命为当时普通行机最大生命的60%，自身无接触伤害、无经验/药水/金币掉落。击毁即取消未发生的武装或结束电区。蛛机死亡时尚未投出的锚取消，已投出的锚继续有限生命周期。每只最多保留1枚，上一枚消失后至少冷却4.5秒再起手。

玩家可换位避开，也可集中伤害快速拆锚；不是必须清理的关卡任务。边缘和障碍旁落点必须保留可达出口；无法合法投锚时保持普通追击。

### 导弧浮灯：先看两端，再决定穿线或拆点

距离4～9时，在玩家当前点两侧生成两个锁定端点。两端相距5，电弧半宽0.28，玩家起手位置位于连线附近，但不预测未来坐标。显示两枚电极和完整连线，预警1.25秒，再通电0.65秒；同次电弧最多伤害玩家一次，伤害18。

其中一个端点是可破坏的接地电极，生命为普通行机最大生命的70%；另一个为不碰撞的投影。电极无掉落，击破或施法者在通电前死亡会取消电弧。通电后杀施法者不抹掉已发射攻击，但拆电极仍可中止剩余有效时间。两端均不阻挡走位。

端点和线段一次锁定，不能跟随玩家平移。玩家可提前横穿预警线、沿端点绕开，或拆电极。恢复1.5秒、冷却3秒，不连续补线。

### 滑轨切割机：机体移动，攻击点固定

距玩家3～8时，锁定一条位于玩家侧前方的长度5横向滑轨；先用0.9秒轨迹预示机体移动方向。滑行速度3.5，无冲撞攻击，机体保留普通接触伤害。

在滑轨的起点、中点、终点各向同一侧发射一段长3.2、半宽0.3的短切割束，每段各有0.9秒完整预警，伤害18。三个发射点与方向在起手时全部展示并锁定；后段不改瞄玩家。上一束结束0.2秒后才允许下一束发射，机体等在对应点，不为追赶时间省略预警。

每束有效0.12秒；整个滑轨连段占用1槽，恢复1.8秒、冷却2秒。击杀/冻结能取消/暂停尚未发射的部分，已射出的束正常结束。滑轨撞机座或路线无法完成则提前停止并恢复，不穿墙瞬移。破解方式是绕到发射背面，或沿已扫过的轨迹反向切入。

## 5. 两名专属精英

### 185秒：接地织阵者 / gridwarden

外形为高身三足调度机，肩部两个线盘，腹部吊接地锤。基础移速1.35，最终接触伤害20，精英基准血量系数10，再应用一次共享精英×2和本关精英倍率。不得给自身全局护盾、回血或锁血。

循环：布两枚电极 → 单条斜弧 → 两处锚点先后过载 → 恢复。

- 两枚可破坏电极落在自身两侧约3单位，生命各为普通行机最大生命的1.2倍，持续最多7秒，无接触、无掉落。
- 斜弧以两电极为端点，半宽0.35，预警1.25秒、通电0.7秒、伤害22，同次最多命中一次。任意电极被拆则电弧取消，精英仍可受伤。
- 电弧结束后0.3秒，存活电极分别形成半径1.4过载圈，逐个发布，预警各1.15秒、伤害20、有效0.12秒；两圈至少错开0.35秒。已毁电极跳过，不补到玩家脚下。
- 之后恢复2.6秒，无接触伤害，受到伤害+25%。每轮重新布置，旧装置先销毁，不能越积越多。

高单体可直接斩首；清群或穿透可连精英与电极一起清掉；低伤害也可走位避开全部阶段。首次出现只带普通行机，禁止立即叠浮灯电弧。

### 355秒：断轨裁切机 / railreaper

外形为宽体履带机，两侧折叠刀臂，前端张开形成一面带缺口的电栅。基础移速1.45，最终接触伤害22，精英血量基准系数12，应用一次精英×2与本关倍率。

先释放一面**有限宽度、带固定缺口的推进电栅**：总宽10，厚0.55，缺口净宽3.6；以玩家起手位置外3.5单位为初始位置，朝其锁定位置推进5单位，速度2.8。完整预警1.3秒，起点、推进方向和缺口整段可见。缺口偏在起手坐标的一侧1.8单位，左右按轮次交替；不随玩家移动。

玩家可移入缺口，也可从两端绕过；缺口或端点路线至少一条能以基础移速抵达。电栅单次伤害26，同一面仅命中一次。机座不遮电栅，但预警必须穿过机座连续显示，出口校验计入机座碰撞。

电栅结束后完整预警1.1秒，再对精英身前一个锁定方向发出90度、半径2.4的刀臂横切，伤害22。绕背或留在范围外都可躲。之后恢复3秒，无接触伤害、受伤+25%。两段预约两槽，无合法路径时只发第一段，并保留完整恢复。

## 6. Boss：天穹铸雷机 / thunderforge

大型悬浮机械核心、四条关节臂、展开式电栅翼、下方可见中央锚桩；与前两关直立督军/六足虫皇轮廓完全不同。非冲刺型Boss，地表追击速度1.65，最终接触伤害22。恢复、过渡和布阵停驻时无接触伤害。

沿用Boss基础生命计算，应用2.86关卡倍率。55%生命进入第二阶段，过渡1.5秒，不回血、不锁血、全程可受伤。清理Boss未生效的旧预警与装置，不清理小怪已发射攻击。所有攻击按固定循环、种子左右分支执行，不读玩家武器或DPS。

### 技能A：三拍断轨——连续换道，不回到刚离开的线

依次锁定玩家当前坐标的横轨、纵轨、斜轨：每条长8、半宽0.45，分别完整预警1.15秒，放电0.15秒、伤害26。第一条放电结束0.25秒后锁定第二条；第二条放电结束0.75秒后锁定第三条，等待余电消失。因此三拍都能重新判断，而不是三个方向同时追踪。

横轨与纵轨放电后分别留下0.7秒余电，伤害8，0.5秒间隔，仍计入原危险槽。第三条斜轨开始预警前，前两条余电必须已经结束；不得出现三条同时有效。斜轨角度按轮次±45度交替。结束后恢复2.8秒，受伤+25%。

玩家可以连续短距离侧移，不要求全图奔跑；留地武器仍在输出，但原地站着会吃到锁定线。精确躲避不依赖移动速度被动。

### 技能B：双栅推进——提前规划两个缺口

Boss展开双翼，依次发射两面宽12、厚0.6、速度2.8、移动距离6的电栅。每面缺口净宽3.6，伤害28，同面仅命中一次。每面发射前完整预警1.35秒；第一面起手就以虚线展示第二面方向、缺口和先后编号，第二面发布时实线确认。

两面同向平行推进，第二面在第一面发射1.6秒后开始自己的完整预警，不从身后无预警夹击。缺口左右错位不超过2.4单位，不能形成要求玩家横穿整张地图的折返。两面均允许从有限电栅两端绕行。

发布前按缺口实际到达时间校验：需要移动距离不得大于 `4.2 × (可用时间 − 0.35秒)`，再扣掉角色半径与障碍绕行消耗。若下一缺口不可达，在第一面预警发布前减小错位或改为单栅；预警发布后不移动已显示缺口。两面结束恢复3.2秒，受伤+25%。

### 技能C：磁锚开庭——拆角或换边，拒绝完整封笼

在Boss周围半径3.5的三个合法点生成锚桩，形成缺一边的三角形。仅两条边通电，始终有一条明确开口；不围出必须击杀装置才能逃生的闭环。每枚锚桩生命为当时普通行机最大生命的1.5倍，无接触、无掉落；Boss本体仍可正常受伤。

两条电弧各半宽0.35，完整预警1.3秒、有效1.2秒、伤害24，各最多命中一次，占用两个槽。拆掉任一锚桩立即解除关联边；玩家也可从开口换侧或在通电前穿过虚线。

电弧结束后0.4秒，仅一个存活锚桩形成半径1.5过载圈，完整预警1.2秒、伤害24；被拆则该段取消，不改选脚下另一桩。结束销毁所有锚桩，恢复3秒，受伤+25%。

### 第二阶段：改变路线顺序，保留反应时间

第一阶段循环A→B→C，第二阶段改为B→C→A。预警、缺口、伤害和控制规则不缩短。

- B的第二栅缺口换到第一栅另一侧，但仍遵守2.4单位错位上限与可达公式。
- C的三角形开口在起手前旋转120度，方向完整显示；不在生效过程中旋转封口。
- A的第一条轨道改为斜轨，后两条为横/纵，仍逐条完整预警，余电最多保留两槽。
- 每完成两次Boss技能尝试补一组援兵：1浮灯或1切割机交替，每次仅一种，场上已有同类组则跳过。必须等Boss恢复窗口结束、危险槽可用后才能起手，不能把反击窗口偷换成第三路攻击。

Boss战普通行机继续补充，目标场上普通怪28～34、总量与威胁预算不变，每次Boss技能后至少3秒不新增普通波。Boss援兵普通经验按现有50%规则，无药水/金币；无经验装置不进入有效普通击杀药水计数。

## 7. 八分钟编排：教会，再交叉考验

|时间|遭遇与学习目标|
|---|---|
|0～35秒|普通行机双路进入；学习中央和侧路，允许建立第一件武器|
|35～70秒|单只落锚蛛机，首次落锚后至少5秒不叠新特殊攻击；学习旧位置临时封路|
|70～110秒|首次单浮灯，落锚暂退；学习虚线可穿、拆电极能断线|
|110～150秒|首次单切割机，其余只有普通怪；学习绕到发射背面|
|150～175秒|蛛机和浮灯错开至少3秒起手，两个方向来敌；首次将封地与锁线结合|
|175～185秒|停止新增特殊怪与精英，普通波明显减量；回收经验|
|185～235秒|接地织阵者，仅带普通行机；拆电极或斩首两种打法|
|235～290秒|浮灯/切割机两组轮换，不同时补第三种；每拆一组保留至少3秒回收空档|
|290～300秒|暂歇，停止新增特殊攻击单位；已有有效攻击正常结束|
|300～345秒|蛛机占旧位置、切割机占一侧，逼玩家选择另一条回路；不同时封两条唯一出口|
|345～355秒|精英前减压，不补积压怪物|
|355～405秒|断轨裁切机，先学单缺口电栅，再面对刀臂收尾；不叠浮灯锁线|
|405～460秒|两种特殊组合交替：蛛机＋浮灯、蛛机＋切割机；落点和方向按固定轮次变化|
|460～472秒|停止新增精英和切割机，收束已有遭遇|
|472～480秒|停止新增特殊怪，普通波减量；已有精英未死则不强行刷Boss叠场|
|480秒|触发Boss入场；若精英仍活，Boss入场预警保留，待精英被击败后至少3秒再开启Boss第一招，不清除存活敌人作弊，也不补刷精英|

两次精英事件不积压连刷。前一名存活时延迟第二名；若延迟至460秒仍未安排则取消该次，避免Boss前连续精英。精英击杀后至少6秒不新增特殊敌人。

计时随升级、改造选择和暂停停止，不在恢复时追赶补波。后期强配装提前清场获得实在的回收与走位收益，不立即贴脸补怪抵消输出价值。

## 8. 十武器流派在本关的不同收益

|武器|适合的实际打法|需要承担的风险|
|---|---|---|
|飞刀|追猎拆浮灯/电极，往返沿侧路切线；环绕保护换道瞬间|环绕无法替代远程拆点，也不挡电弧|
|火球|在行机队列或锚桩附近重爆，连珠处理分散机关|慢速重爆可能错过已移动的切割机，需抓恢复期|
|圣水|将追兵引过旧电区外的水路，奔流帮助侧路清道|固定圣泉会因电锚逼迁损失覆盖，不能永守落点|
|冰环|解开普通围堵，争取穿缺口时间；碎冰提高多次脉冲收益|不冻结Boss，不取消已经发射的电栅|
|闪电|拆聚集的行机与电极，连桥穿过关键阵位|远距接力收益依赖目标间距；单个Boss收益较低|
|幽灵|猎手从侧路追浮灯，归途切割追兵，攻击不依赖面对方向|出击和回收有空档，不能替玩家承担机制|
|骨矛|沿中央轨道贯阵，重矛穿过装置与施法者|扇射偏清群，窄重矛需要主动整理射线|
|地雷|提前在侧路和电栅出口附近布防，让追兵踩雷|不能直接放雷消除敌方电墙；一直转场会浪费旧雷|
|黑洞|聚普通行机，为贯穿/爆破提供密度；漂移涡心沿换道方向清路|不牵引精英/Boss；坍缩圈需要自己引怪进入|
|圣光|利用机械布阵停驻和Boss恢复期落剑，剑雨拆分散点|锁点后敌人能移出，不能指望每剑自动追上|

装置必须对十把武器统一可攻击，能被合法索敌与范围伤害命中，不要求弹体类型、特定角色或隐藏属性。它们无掉落，无分裂，不会被当作普通怪反复刷经验。

建议测试三类配装，而非设计唯一答案：

1. 拆阵输出：追猎飞刀/猎手幽灵＋接力闪电＋重矛，迅速减少特殊单位。
2. 路线经营：圣泉/火海＋绊线地雷＋黑洞，围绕侧路引怪，再主动换道。
3. 移动清群：奔流圣水＋扇骨齐射＋剑雨/冰环，穿过缺口时维持清路。

每类再混搭至少两把其他武器验证，避免“必须带冰环”或“只有追猎能打”。敌人不获得针对某武器的免疫、反伤或突然加速。

## 9. 视觉与信息层级

- 怪物轮廓：行机低矮六足，蛛机高脚吊锚，浮灯离地双叉，切割机宽体侧锯；精英三足线盘/履带刀臂，Boss四臂展翼。需要在手机横屏直接辨认，不只换颜色。
- 预警：橙红实线/虚线＋箭头与先后数字；玩家武器为各自色彩。可穿预警用虚线，生效危险用实线与明暗脉动，电栅缺口保持空白并有边界标记，不依赖红绿色差。
- 装置：有血条、断线反馈与残余秒数；不可碰撞投影使用空心轮廓，不能和可拆电极画成一样。
- 电栅缺口、锁线与敌方落点始终在玩家武器特效上层。省电模式可减少电火花，不能隐藏缺口、端点、预警计时或真实碰撞范围。
- 顶部固定Boss血条、名称与阶段；底部优先提示当前动作：如“向缺口换道”“先横移，再看第二条轨”“拆电极或从开口换边”。不持续堆满长文字。

## 10. 开发与验收要求

### 文件与存档

第三关ID为3，通关第二关ID2后解锁，当前选关列表为[1,2,3,4]。不新增角色、不恢复成就；不改变现有角色解锁。

开发顺序：地图白盒与路径验证 → 装置可攻击/取消和危险预约 → 四类小怪 → 两名精英 → Boss → 轮廓与动作 → 手机横屏与压力检查。不要等美术完成后才验证缺口是否能躲。

### 公平性与防站撸

所有多段攻击发布前，以基础速度、真实碰撞半径、机座、现存危险和附近敌人做时间路径采样，逐段验证至少一条可达路线。采样只能提供工程检查证据，不能宣称数学证明所有真人都能躲。出现不可达时先修时序/出口，不偷偷增加玩家免疫。

重点回归：锁点不追踪、每段完整预警、击杀/冻结前后取消规则、装置拆除立即断线、已发攻击有限结束、无多槽绕过、无无限装置、无经验/药水刷取、Boss过渡不回血、同一电栅只伤一次、暂停不追赶补波、新旧进度兼容。

至少六种完整配装覆盖上述三类打法，各3位置×3种子，做Boss移动/站定成对检查；普通成长另做前三分钟挂机、成型后挂机样本。任何同配装同位置3种子站定胜2场，都登记为站定漏洞，检查技能实际出手、出口位置、持续控制和反击窗口占比；不只挑会输的配装。

移动机器人失败不作为自动降难度依据。要保留失败、超时和死因；如果多种合理配装都只能输，则先排查锁线不公平、伤害未命中或恢复窗口失效，再由真人确认强度。第三关“比第二关更难”需要同控制器、同配装与真人对照，不能只凭倍率或单次通关宣布。

真机验收包括六武器成型、两槽危险、电弧/电栅与装置并存、3倍速、省电模式。装置和危险实体使用固定容量与复用，不为电火花创建大量节点；预警减少粒子不改变真实攻击。通过网页或桌面模拟不能声称手机不会发热。
