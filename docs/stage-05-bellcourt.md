# 第五关设计：灰烛钟庭

现行三轮精英（0.30.1）：135、225、305秒，第三轮复用本关第一种精英，生命为正常值85%。下文精英攻击机制保留，旧出场时点由[三轮编排](elite-rounds.md)替代；同屏最多一名、Boss等待活精英。

实现状态更新：已接入0.27.0工作区；设计参数仍需试玩校准，实际差异、验证与发布状态见[实现记录](stage-05-implementation.md)。下文保留设计起点，不作为发布声明。
日期：2026-10-20。状态：方案已实现，真人难度未验收。第五关、金币购买、成就和图鉴已接入本地开发版；尚未上传微信后台。

依据：[现行基线](current-baseline.md)、[美术规范](art-direction.md)、[武器与图鉴设计](weapon-unlocks-design.md)。用户已确认：金币与成就为不同武器的独立获取方式；关卡难度应体现解锁成长，但不强制解锁指定武器，开局与升级继续随机。

## 1. 核心体验与推进链

**借钟座避声浪，换位拆蜡甲，通过解锁与配装成长改善输出，在收招时集中反击。**

第五关采用重蜡构造体与执钟侍从的新阵营。相较前四关，新增判断是「这一击需要绕开，还是可以躲到实体障碍背面」，同时用厚蜡甲检验配装和解锁成长，不检查指定武器ID。

推进：通关第四关 → 挑战第五关 → 若输出或清路不足，回较早关卡赚金币或完成成就 → 解锁适合自己打法的新武器 → 随机获得并搭配后再次挑战。玩家可以提前解锁，也可以先用基础池尝试。

关卡ID拟为5，唯一进度条件为通关4。不检查飞轮、重锤、钱包余额、成就数或图鉴完成度。选关说明厚蜡甲及绕台打法，提供查看武器图鉴的入口，不弹「缺少指定武器禁止进入」。不保证初始十武器在任意配装下都可轻松推进，也不人为保证初始池必输；熟练玩家、强配装和后续武器均可形成不同解法。

开局沿用从全部已开放且已解锁武器中等概率无放回随机三选一；升级沿用现有随机规则。没有指定开局、飞轮必出、破甲保底、按Boss血量补关键卡或暗中读取配装改难度。解锁增加可用池，不代表当局必得。图鉴预告和未取得武器不能进入随机池。

新武器首批恰为两把，分别覆盖金币与成就路线，不延伸为固定二十武器计划。不新增最高成就、角色、旧超武或配方。

## 2. 前置装备与厚蜡甲

以下全部为待验证的初始试验值。四武器、四被动、8级和4/8级改造、玩家64级、360秒Boss、100实体与两个危险槽不变。

|对象|厚蜡甲减伤|战斗职责|
|---|---:|---|
|抬烛蜡徒|20%|普通尸潮，允许旧武器保持收割收益|
|鸣钟执事、刻蜡书吏、绕柱爬蜡|35%|成型后的优先处理对象|
|两名精英|50%|需要破甲后切入输出|
|覆钟蜡主|55%|检验持续破甲和Boss反击窗口|

两把新武器均能施加裂甲：命中后先施加一层，再结算本击；每层降低35个百分点厚蜡甲减伤，最多两层、持续3秒，命中新层刷新总持续时间。例：Boss原55%，一层后20%，两层后0%。同一攻击每目标最多加一层，不能靠同次范围命中的多个形状瞬间叠满。计时随暂停停止。

裂甲是新武器的通用机制；旧敌人如没有厚蜡甲则不凭空获得甲，也不因裂甲变成负减伤。厚蜡甲不回血、不反伤、不抵消冻结，不为某类旧武器额外加免疫。裂甲后的伤害让所有装备受益，形成「一把破甲＋其余三槽补清群/单体/控制」的成长结构。

为保证不依赖指定武器，每个Boss恢复窗口自然暴露甲缝：厚蜡甲减伤暂降至15%，与裂甲取更低减伤而不重复相减。精英恢复窗口降至20%；窗口结束恢复原甲值，未过期裂甲继续有效。旧武器可通过抓窗口输出，新武器能扩大有效输出时段；不额外引入强制换武器或白送裂甲。

画面用两片实体蜡甲及断裂层数表达，血条旁显示0/1/2层裂纹；未裂甲时的减伤数字与战报应可诊断。减伤只应用一次；固定伤害、持续伤害及子弹均统一经过最终伤害入口，禁止某武器绕过或重复套用。

首轮关卡倍率：普通生命1.90、精英2.16、Boss生命2.96、接触伤害1.54、经验1.30、药水阈值42。仅提高少量基值，厚蜡甲已经增加有效生命，不再叠巨额血量。下文攻击伤害均为最终值，不再乘关卡/远程/精英倍率。若破甲路线仍拖时，先查裂甲覆盖率与恢复窗口，再调整这些试验值。

## 3. 地图：四座实体钟台与双侧回廊

活动区x±22、y±26，出生(0,-8)。四个固定钟台中心(-9,-8)、(9,-8)、(-9,9)、(9,9)，半宽1.6、半高2.4；中央半径6净空，左右通路及外圈连通。两侧路线参照点为(±15,0)，上下换线点为(0,±16)。钟台与场地边界之间没有封闭口袋。

钟台使用同一份矩形数据服务绘制、玩家阻挡、怪物导航、出生和逃生校验。玩家半径0.3，基础速度4.2；移动采用已修复的分轴小步碰撞，严禁只画障碍不接玩家碰撞。

本关明确新增一条地形规则：**钟台阻挡标有钟纹的敌方声浪，不阻挡地面蜡印与玩家攻击。** 玩家攻击沿用现有穿障碍行为，不临时让飞刀、重锤或飞轮撞墙消失。声浪预警画出声源至钟台形成的遮挡阴影，避免只能记规则。

声浪到达时，按声源到玩家当前位置的线段与钟台矩形相交判遮挡，不用渲染遮罩替代命中规则。声源至少离钟台外缘0.6；每次发布前检查可达遮挡位，也允许从有限扇面两侧离开。障碍边缘误差以玩家完整碰撞圆为准，不能脚尖躲住而身体仍被判中。

不做全图环境常驻伤害。地图用低饱和灰紫石面、乳白蜡流、氧化铜钟座；可通行蜡迹画成薄平地面，实体钟座保持厚重立面与投影，不把装饰蜡滴画成石柱。

## 4. 四类主力小怪

|敌人/候选ID|独立轮廓|初始生命系数/移速/接触最终伤害|上限/威胁|
|---|---|---|---|
|抬烛蜡徒 / waxbearer|矮身双臂托三烛、厚肩蜡块、短脚|1.1 / 1.65 / 12|普通预算内 / 0|
|鸣钟执事 / bellacolyte|高瘦双臂吊横钟、无头盔，前摆钟槌|1.8 / 1.15 / 14|2 / 2|
|刻蜡书吏 / waxscribe|宽扁蜡盘、长刻刀与弯背，拖短蜡尾|1.7 / 1.25 / 12|2 / 2|
|绕柱爬蜡 / waxcrawler|贴地三节长体、四掌、背部断蜡片|1.4 / 1.95 / 14|3 / 1|

蜡徒没有额外范围攻击；追击绕钟台，不穿台贴身。以下三类特殊攻击共用两个危险槽，不能借地面效果另开隐藏槽。

### 鸣钟执事：可被遮挡的声浪

距离3～7起手，锁定朝向，发布90度、半径6扇面。完整预警1.2秒，随后声浪从内向外以6单位/秒传播，波前半宽0.25，伤害20，每次最多伤害玩家一次。危险保留至波前走完，占1槽。

预警显示扇面、波前方向与钟台后方遮挡阴影；出手后源点与方向固定。玩家可绕出扇面或躲到钟台后。发射前击杀取消、冻结暂停预警；发射后声浪有限结束，杀死施法者不让已发攻击消失。恢复1.8秒、冷却3秒。

### 刻蜡书吏：离开刚用过的遮挡位

距离3～7锁定玩家当时位置，画半径1.25蜡印，预警1.3秒，再亮起0.18秒，伤害18，仅一次。留下1.2秒暗蜡装饰，无后续伤害；不因装饰仍在而占危险槽。印记不能放进实体钟台，越界则取消，不挪到另一个未提示位置。

攻击会穿过钟台地形，预警使用滴蜡边缘而非钟纹。玩家可以横移到同一钟台另一侧；不预测未来路线。恢复1.6秒、冷却3.5秒。与声浪组合发布前验证至少一条可达出口，不允许声浪与蜡印同时封死唯一遮挡位。

### 绕柱爬蜡：沿地形绕侧，正面留路

先沿导航绕到玩家一侧，入镜至少1秒后，锁定朝向进行长3、宽0.65的短扑。完整预警1秒，扑速5.5，伤害18，同扑最多一次，占1槽。路径撞钟台立即停止并恢复，不沿墙瞬移补扑；玩家可侧移或借钟台断路。

蓄力和扑击期间身体接触伤害关闭，避免同一动作双伤。发射前冻结暂停，死亡取消身体攻击；恢复2秒期间接触关闭、承伤+20%，然后冷却2.5秒。

## 5. 两名精英

### 135秒：双钟司祭 / twinbell

背挂两枚大小不同铜钟，宽肩长袍，双手各执短槌。生命基准系数10，再应用一次共享精英倍率及本关精英系数；速度1.3、接触最终伤害20。

循环：单扇声浪 → 固定蜡印 → 反击。声浪120度、半径7、预警1.3秒、波速6、伤害24；蜡印在声浪结束0.4秒后重新锁点，半径1.5、完整预警1.25秒、伤害22。每段最多一次伤害，预先预约两槽，未发段随精英死亡取消。两段后恢复3秒、无接触、承伤+25%。不同时召唤特殊敌人。

### 265秒：封蜡抬钟者 / waxporter

两条粗臂拖钟、后方两只短支足，低宽轮廓区别于司祭。生命基准系数12，再应用一次精英强化及本关系数；速度1.2、接触22。

循环：向起手时锁定位置拖钟直推5单位，宽1.3，预警1.35秒、速度3、伤害24；撞钟台即停，无额外爆炸。停下0.5秒后，从实际停点发120度、半径5声浪，重新完整预警1.3秒、伤害24。两段占两槽，不以撞墙缩短后段预警。第二段方向在第二次预警开始锁定，明确显示改变。

恢复3.2秒，无接触、承伤+25%。拖钟与普通接触不叠伤；死亡取消身体攻击，已发声浪自行结束。可选择引它撞台后从另一侧切入。

## 6. Boss：覆钟蜡主 / waxbelllord

巨大的倒悬铜钟外壳，下伸三条粗蜡足，中央蜡面随敲钟张合；没有军团长戟、机械臂或鹿角。Boss本体全程可受伤，慢速追击1.45，普通寻敌时接触22，蓄力、攻击、恢复、转阶段无接触。

50%生命进入第二阶段，过渡1.5秒、不回血不锁血；清理自身未发预警与预约，已发的有限声浪正常结束并计入危险槽。没有落点可用时步行重定位，不贴脸传送。

### A：避钟再离蜡

先发120度、半径8声浪，预警1.4秒、波速6、伤害26。可绕出扇面或借钟台遮挡。声浪结束0.4秒后锁定玩家当前点，半径1.6蜡印，完整预警1.3秒、伤害24。

前一段结束后才锁第二段，玩家有换到钟台另一侧的时间；不在声浪有效时把唯一掩体用地面圈封掉。结束恢复3秒、承伤+25%。两段预约两槽，第二段取消时仍恢复。

### B：双拍换侧

向玩家当时方向发100度、半径8声浪，完整预警1.4秒；结束0.6秒后重新锁定第二个100度方向，完整预警1.4秒。每拍伤害26、各最多一次。两次间隔提供完整重新判断，不同时从两侧夹住玩家。

第二次显示序号2，不能以第一拍残余纹理代替第二拍预警。结束恢复3.2秒、承伤+25%，两段共预约两槽。

### C：裂蜡开庭

Boss锁定面前方向，在朝向两侧各3单位放一枚半径1.3蜡印。第一枚预警1.3秒，结束0.45秒后第二枚重新完整预警1.3秒，伤害24。中间通道保持至少2单位净宽，不能由钟台截成死路。

两印结束后Boss举钟暴露甲缝3.4秒：承伤+25%，关闭接触、不补怪、不增加第三段攻击。玩家可以先用破甲武器叠层，再让其余三武器输出。

第一阶段循环A→C→B；第二阶段B→A→C。第二阶段只改变顺序及固定左右交替，不缩短预警、不提高全部速度、不新增第三危险。普通援军沿用9秒补/5秒停节奏，首次Boss起手前至少3秒；Boss恢复窗口不安排特殊援军，场上普通目标28～34，总体仍受100限制。

本表使用真实秒数，不能再次套480刻度压缩。升级、改造与暂停停止导演计时，恢复后不补刷积压批次。

|220～230|休整，不新增特殊怪|
|230～255|两侧尸潮＋两种已知特殊行为，最多两危险|

## 8. 配装、随机成长与难度验收

第五关面向已通关第四关、会使用改造和反击窗口的玩家。建议尝试解锁新武器，但没有最低指定装备要求。新武器若抽到，正常升级至4级形成首改；其余槽位自由随机选择。首次特殊怪之前保留30秒基础成长，不要求开局抽到破甲。

- 重锤路线：借钟台聚拢近侧目标，慢速重击破甲，飞刀/寒霜补近身，火球/圣水补收割；需承担近身距离风险。
- 飞轮路线：沿钟台侧道整理直线，让远程飞轮切甲，幽灵/闪电补后排；对分散目标不能常驻全体破甲。
- 初始十武器路线：通过单体爆发抓暴露窗口、控制普通围堵、地形避声浪推进；成型不佳可能输出困难，但不能写成固定无解。若多种合理成型路线均被甲值拖死，先调整甲缝窗口和普通怪密度。

先用固定配装对照仅基础十武器、重锤＋三基础、飞轮＋三基础，隔离机制收益；再用同角色、种子与升级策略做完全随机成长。随机组分别记录未解锁、仅购买、仅成就、两把均解锁，不能预送武器、等级或重抽。区分没抽到目标、抽到未成型、已成型仍失败。记录成长、裂甲覆盖率、危险出手、击杀速度、普通怪拥堵、死因与Boss耗时。新武器路线需能用主动走位完成合理时长的战斗；候选Boss时长60～120秒，必须经试玩调参，不能写成已达成。

如果基础武器与新武器差别微弱，先查减伤/裂甲是否实际生效；如果新武器路线也普遍拖时，先查叠层机会和恢复窗口。金币购买时间、挑战可完成性和随机池稀释同样属于关卡难度，不能只测预置满级样本。若已解锁路线多数局都因迟迟无关键候选无法推进，应先降低本关对破甲的依赖，而不是偷偷保底或强制指定开局。

## 9. 美术与工程接入
