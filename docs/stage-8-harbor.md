# 第8关：骸潮港湾

设计日期：2026-10-13；原设计基线0.12.4。状态：0.13.0已完成可玩实现与本地验证，真人难度、微信真机验收待完成。下文保留设计目标，落地范围与验证结论见文末。

遵守 [后续关卡设计规则](level-design-rules.md)。通关第7关解锁，沿用八分钟、60级、六武器位和自动分支流程。

## 核心体验

主题是“清出路线，边走边打”。玩家先学习识别成排推进和侧翼包抄，再学会处理远程落锚；后半局在货堆之间聚怪收割或切换到开阔区域。成型后持续有尸潮可打。

不新增潮水涨落、地图缩圈、氧气、关卡词缀或挑战任务。港湾水面只是不可达边界的视觉主题，不产生未预告的伤害。

## 地图原型与玩家指标

沿用世界约 x∈[-23,23]、y∈[-27,27]，玩家中心活动区 x∈[-22,22]、y∈[-26,26]，出生点(0,0)。1单位约48像素；玩家半径约0.3，基础速度4.2单位/秒。无跳跃要求。

四组不可推动的货堆为矩形，中心在(-8,-8)、(8,-8)、(-8,8)、(8,8)，半宽2、半高3。其余场地开放，水岸沿世界外围装饰。使用矩形碰撞，而不是画矩形、按圆形判定。

```text
                  北侧绕行区
       左侧路线    中央路线    右侧路线
          [货堆]             [货堆]
                       ↑
       ←──────── 出生/横向通道 ────────→
                       ↓
          [货堆]             [货堆]
                  南侧绕行区
```

考虑玩家半径后，中央纵向通道约11.4单位宽；横向中央通道约9.4单位宽；两侧路线各约11.4单位宽。货堆北/南端到活动边缘各约14.7单位。所有货堆都能从四周绕行；中心、侧路、外围形成连通环路。

预期常用路线是从中央看清落锚，再切入侧路引怪，绕过货堆后返回中央输出。玩家可反向绕行，不要求固定跑圈。货堆阻挡玩家、敌人移动及Boss冲锋；初版不阻挡武器或敌方投射物，选关提示明确“货堆可挡冲锋，不能挡远程落锚”。危险圈落到货堆上仍以可达区域判定，取消无法逃脱的落点。

地图数据必须同时供绘制、圆/矩形碰撞、敌人绕行、出生采样、冲锋终止和危险检测使用。敌人被货堆挡住时沿可见拐角绕行，不穿模、不瞬移、不无限顶墙。原型先验证中心和两侧路径连通，再制作港口美术。

## 专属敌人

保留游荡骷髅作为尸潮主量。新增三种独立敌人种类，加入现有生命、受击、控制、经验和结算流程，不用同一种骷髅换色冒充全部新行为。

初始参数相对于本关普通骷髅：

| 敌人 | 生命/经验 | 速度 | 行为与反制 | 配置边界 |
|---|---|---|---|---|
| 水手尸 | 1.0倍/1份 | 1.4 | 4–6只横排或纵排进场，1秒进场提示；锁定横向间距和目标行进方向，向预告的玩家旧位置推进最多2.5秒，再转为追击。可从侧面绕过或沿排贯穿收割 | 不正面格挡、不远程攻击；编队槽位固定，不强行补位；总上限24 |
| 溺亡者 | 0.8倍/1份 | 2.0 | 从一侧进场，瞄准玩家侧前方约2.5单位的位置，侧切最多1.8秒后直接追击。目标点与左右方向在侧切开始时锁定，可提前转向摆脱 | 不冲刺、不隐身、不瞬移；总上限6，单批最多2 |
| 投锚手 | 1.25倍/2份 | 1.3 | 在约6单位处停下，朝玩家当前位置投锚。落点圈半径1.1，1.4秒完整预警，落锚后0.25秒结束危险；可离开落点或绕后优先击杀 | 威胁2，上限2，首次可见0.8秒后才能施法；攻击间隔5秒，进入1.5单位近身范围时取消未落锚攻击并恢复1.2秒 |

水手尸、溺亡者只造成现有普通接触伤害；不因行为变化再额外提高接触伤害。投锚初始伤害10（固定伤害，不能重复叠乘关卡倍率），只有落锚时判定一次，无额外拉拽、眩晕或长驻毒池。

水手尸保持明显的排队轮廓和船服，溺亡者体型更小、带侧向水迹，投锚手携带可辨识的锚。颜色之外还要有轮廓及动作区别；没有专属素材时使用明确的原型标识并标注美术待替换。

新增敌人数量计入全场100只上限。单批尸潮中的水手尸替换部分普通骷髅，不在原有波次之上无限叠加。精英出现时停止新的包抄和投锚手，存活者仍保留并受危险槽限制。

## 八分钟节奏（真实秒）

| 时间 | 体验与敌人配置 |
|---|---|
| 0–30 | 普通骷髅，提供开局升级机会；介绍货堆绕行。无新远程攻击 |
| 30–60 | 单侧一排4只水手尸，之后逐步到6只；让玩家看清成排推进和绕侧路线 |
| 60–90 | 保持低密度普通尸潮，单独加入1只溺亡者；提示“转向摆脱侧切” |
| 90–120 | 两种近战配合，每批至多1只侧切敌人；不引入投锚 |
| 120–150 | 第一次出现1只投锚手，降低近战补充；提示锁定落点、离圈即可 |
| 150–164 | 第一段收割潮，以普通骷髅和水手尸为主，不补投锚手 |
| 164–172 | 8秒不补怪的拾取窗口，存活怪不自动消失 |
| 172–180 | 降低近战补充，不加新远程，为精英腾出空间 |
| 180–210 | 沿用第一精英时间；停止专属特殊怪补充，精英死亡后保留现有短休息 |
| 210–250 | 货堆侧路遭遇：单侧排队推进＋另一侧少量包抄，学习选择绕行方向 |
| 250–260 | 10秒拾取窗口 |
| 260–300 | 开阔区遭遇：水手尸＋最多2只投锚手；允许绕后、追踪或范围击杀后排 |
| 300–330 | 成型收割潮，不新增投锚手；提高普通怪补充，不提高生命 |
| 330–340 | 10秒拾取窗口 |
| 340–350 | 仅低频普通怪，为第二精英让路 |
| 350–380 | 第二精英；停止专属特殊怪补充 |
| 380–420 | 综合测试：排队推进与侧切交替，投锚手最多1只；不能同一批同时投放三种新角色 |
| 420–460 | 最后收割潮，停补投锚手，侧切每批最多1只；保持成型后的群怪目标 |
| 460–468 | 仅补普通骷髅，停止所有专属怪和精英补充 |
| 468–480 | 12秒Boss前拾取窗口，不补新敌人 |
| 480起 | 沉港船长登场，清理旧投锚危险、旧专属怪及精英，保留预算内普通尸潮；执行Boss节奏 |

第8关使用自己的节奏表，优先于通用节拍，避免两套停刷时间意外叠加。精英回避、死亡休息和暂停高于普通波次；跳过的事件不补播。每段前约10秒给简短提示；教学提示不能长期覆盖Boss危险提示。

## Boss：沉港船长

角色问题：玩家能否在尸潮中保留侧向通路，躲开锁定攻击后反击？Boss不能只换皮套用内外圈法术。

登场2秒提示，不攻击；血量降到50%时进入第二阶段，清理自身旧危险，转阶段提示1.5秒，期间停止补怪。两阶段不回血、不无敌。普通追击初始速度1.7/1.9，能受现有Boss减速规则影响，接触伤害沿用现有Boss规则。

### 招式

1. **抛锚落击**：锁定玩家位置，落点圈半径1.5，1.4秒预警，18点固定伤害，危险持续0.25秒，之后恢复2.4秒。第二阶段可追加一枚落锚，但在第一枚结束后重新锁定、重新预警1.4秒；不提前追踪玩家，不把两次攻击压成同一判定。
2. **拖锚冲锋**：直线方向锁定，预警1.3秒，最大路程6、速度6，身体扫掠半宽0.65；只在距离2.5–8且几何逃生检查通过时使用。冲锋碰到货堆或边界立即停止，进入恢复；撞货堆恢复2.8秒，否则恢复2.2秒。18点固定伤害，同一次冲锋最多命中一次；冲锋与普通接触共享受伤保护，不双重计伤。
3. **召潮号令**：1.2秒号令提示后补一批普通骷髅，最多12只，使用现有Boss援军进场提示和安全缺口；这些召唤计入尸潮目标，不另开数量预算。号令期间不额外叠加定时补怪，之后恢复2.6秒。

一阶段顺序：落锚→冲锋→号令；二阶段：完整预警的双落锚→冲锋→号令。无合法冲锋方向时改成单次落锚；没有安全落点则等待0.35秒重试，不向视野外或无路可逃处强放攻击。二阶段只增加已学会招式的配合，不突然加入未教学的全屏技能。

固定尸潮仍是9秒密集补怪、5秒停刷；目标数量沿用后期关卡上限，不能因为第8关再提高全场上限。Boss战不补投锚手与溺亡者，危险集中在Boss本身，普通怪提供清群和清路目标。危险槽上限2，落锚与冲锋提示计入；冲锋提示只表达身体命中路线，不再额外做一次直线伤害。

## 武器与组合空间

- 贯穿/弹射：沿水手尸队列收割，在货堆间清出通路；代价是需要选择输出角度。
- 圣水/毒雾/地雷：在侧路引怪或绕货堆建立伤害区；Boss恢复时贴近或引入伤害区，不能靠无限等Boss入池。
- 幽灵/雷电/单体分支：优先处理投锚手、精英及Boss；清群能力不足时用第二组组合补路线。
- 近身飞刀/镰刀/战斧：在开阔地绕侧，利用冲锋撞货堆的恢复窗口反击；不要求穿过危险直线接近Boss。

不保证某个推荐组合固定出现，不给关卡抗性强制淘汰武器，也不把“所有分支都必须同样强”作为目标。

## 初始数值与难度目标

第7关当前关卡倍率：普通血量1.46、精英1.64、Boss血量2.08、伤害1.26、经验0.85、药水间隔40击杀。第8关试验值：1.48/1.66/2.14/1.28/0.85/40，仍沿用现有全局Boss血量计算，不再额外乘新的倍率。

相对第7关，Boss耐久仅约增加2.9%。难度增加应主要来自队列、侧切与落锚的站位配合。验收时若出现Boss长时间磨血，优先检查靠近机会、目标选择与伤害可达性，不直接继续加血。上述数字需实际开发后验证，不是已经通过试玩的平衡结论。

## 开发拆分与接口边界

1. 扩展StageId/关卡配置到8，打通解锁、旧存档读取、选关指南、Boss名称及结算；旧存档不能直接解锁8。
2. 新建港湾地图/节奏数据模块，所有时间用真实秒；共享矩形障碍几何，先验证绕行和冲锋碰撞。
3. 新增三种敌人类型及明确状态，复用现有受伤/控制流程；成排与侧切不改已有敌人的全局行为。初次可见等待、暂停与来源死亡取消危险要一致。
4. 接入独立港湾刷怪编排；普通怪上限、进场提示、精英回避与Boss支援保持兼容。
5. 独立船长Boss状态机接入现有Boss分发；复用落点圈预警与固定伤害字段，补连续冲锋碰撞和单次命中记录。
6. 加入敌人轮廓、锚击/冲锋标识及港湾装饰，控制实体池容量和预警层级。
7. 完成配装比较、真机检查后再构建；上传、审核与发布分开记录，不把本地构建写成已发布。

## 验收清单

- 解锁：七关前不可进入8，七关通关解锁；旧存档及已有成就正常；结算能识别新敌人死因。
- 地图：玩家、每种新怪与Boss均能沿三条纵向路线及中央横路通行；货堆边角不卡住、不穿模，出生点不在障碍内。
- 教学：首分钟前没有投锚；编队槽位、侧切点及锚击方向/位置锁定后不追踪；屏外敌人不突袭施法。
- 控制：冻结、减速、敌人死亡及暂停能正确暂停/清理专属状态；不重播跳过的波次。
- Boss：撞堆停冲锋、单次冲锋不重复伤害、阶段切换清理、每次二连完整预警、无合法路线时延迟；近身路线有实际输出窗口。
- 数量：100敌人、2危险槽，号令与定时补怪共享目标；没有无限经验、回血或实体分配。
- 成对模拟：第7/8关各使用同一套至少五个种子、同一角色与策略，覆盖清群、追踪单体、近身持续三类配装；完整保留未成型、超时和失败结果。
- 真人重点：第一次死因是否能理解；成型后是否仍有怪可打；能否用两种不同组合通关；Boss是否要求走位且不拖时。未收集前不宣称真人难度已验证。
- 微信真机：触摸移动、预警可读性、密集Boss尸潮的平均/P95帧耗时，记录设备和场景。此项当前待开发与验收。

## 0.13.0 实现记录

第8关已接入选关、七关通关解锁、旧存档校验和第8关最佳成绩。港湾木板与四组矩形货堆使用一致的绘制、碰撞、出生采样及危险检查数据；敌人使用带缓存的拐角可见图绕行。货堆不挡投射物。独立节奏不叠加旧关环境事件。

水手尸、溺亡者、投锚手是独立敌人类型，分别实现编队目标、侧切点及落锚圈。视觉暂复用已有像素角色，补充船服条纹、水迹、锚标识与尺寸差异；船长复用大型角色并添加锚冠。这不代表全新专属美术已经完成。

船长具有落锚、冲锋、号令循环；半血清理旧危险，第二次落锚重新锁定和预警。冲锋连续检测货堆碰撞，撞堆停止并恢复，单次冲锋只伤害一次。号令与定时尸潮共享数量目标，全场100敌人/2危险槽不变。

224项测试与类型检查通过：解锁/存档、地图边界/绕行、教学时序、停刷、上限、锁定目标、冻结/暂停、落锚取消/单次伤害、撞堆/冲锋单次伤害、半血完整二连。站定满级组合测试已扩展至第8关，测试中仍会失败。浏览器检查八关选择、指南、地图与Boss预警，控制台无警告或错误。
