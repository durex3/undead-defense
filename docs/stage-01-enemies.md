# 第1关：小怪、精英与Boss设计

现行设计基线更新：2026-10-19。编号、成长、存档与验收状态以[当前项目基线](current-baseline.md)为准；美术遵循[四关统一美术规范](art-direction.md)。本文招式参数属于设计参考，实际行为以当前代码为准。

## 目标与现有问题

目标是成型后仍要移动、改变突破方向、选择击杀目标。普通怪压缩位置，特殊小怪发起逼位，精英组织进攻，Boss交替改变安全区。强配装能够更快拆阵、获得更长输出机会。

旧版Boss双线钳击把玩家当前坐标留在中央安全通道，站定天然免疫该招；独立满配可在下一轮威胁前击杀Boss。盾卫仅挡弹体，缺少对地面清场的空间应对；猎手走到侧面后退化为普通追击。不能靠全面免疫、强制锁血、无限加血或玩家站定计时惩罚解决这些问题。

## 公共战斗规则

- 保留基础移速4.2、玩家半径0.3、六短墙地图与360秒Boss。
- 原100怪、6威胁、2危险槽继续生效；移动中的突袭和地面危险也占槽，不能把危险藏到普通AI计数外。双段技能提前预约槽位，队友不得插入第三个攻击。
- 预警位置在施放时锁定，之后不追着玩家移动。后续第二击可以重新锁定，但必须重新给完整预警。未发射时击杀/冻结施法者取消/暂停攻击；发射后的实体不消失。
- 冰冻与击退继续有效。仅精英和Boss采用有限控制抗性：一次冰冻完整生效，解冻后2秒内后续冰冻时长为原值35%，最短0.15秒；再次解冻刷新窗口，不能永久免控。抗性状态显示碎冰图标，换目标仍有收益。
- 所有新技能伤害是最终固定值，不重复乘关卡或远程×2。血量先沿用现有同类成长基线，不额外统一翻倍。
- 施放前检查整段连招：基础速度玩家必须存在可达出口，出口净宽至少1.4。检查地图、现有危险和附近活怪，并模拟后续攻击的时间；无法保证时改为单段或延迟，不直接强放。现有直线路径采样不能充当完整连招可达性证明，需补时空采样验证。
- 给每个区域明确视觉身份：橙色直线表示冲刺/弩箭，紫色落点表示留地危险，金色连线表示阵型保护。重叠时预警绘制在武器特效上层。

## 普通与特殊小怪

| 敌人 | 新职责与攻击 | 如何破解 |
| --- | --- | --- |
| 铁棘步卒 | 仍是主要经验来源。生成时分配追击或侧围角色；最多8只侧围兵，向玩家侧前方3单位的锁定集结点绕行2秒，再追击；其余正常追击 | 从薄弱方向突破，避免所有怪排成同一条尾巴 |
| 棘盾禁卫 | 保留120度正面弹体减伤和后排掩护。举盾3秒、收盾1.8秒；连续站在伤害地面0.6秒后，沿合法侧向移出最多2单位，移速1.6，1秒后停止，冷却5秒；不会瞬移 | 绕背、收盾时集火；地面武器依然能造成完整伤害并逼其离开阵位 |
| 钉地弩兵 | 保留预判贯阵箭；每第三次攻击改为锁定玩家位置的钉地箭：圆形半径1.2，预警1.1秒，命中14，残留2秒，每0.7秒8伤害，持续危险整体占1槽。攻击轮次图标明确 | 看圆圈换位，趁其装填击杀；不能只站在冰环内承受弹道 |
| 猎袭战犬 | 到侧向集结点后发动一次锁定突刺：距离2～5，预警0.85秒，速度6、长度4、半宽0.4、伤害16，仅命中一次；撞墙提前停止，恢复1.2秒，再普通追击。每只只突刺一次 | 向突刺路径侧面移动或冻结打断，利用恢复期清掉 |

盾卫不获得全伤害减免；弩手距离小于1.5时取消未射技能并后撤最多1.5单位，后撤每4秒最多一次，避免无限风筝。所有特殊小怪至少入镜1秒、出生距离至少6，才允许起手。

侧围路径只在角色分配、目标到达或路径失效时重算，不每帧计算全局路径。特殊怪原有上限保持盾卫4、弩手2、猎手4；铁棘步卒侧围角色不是新增危险攻击。

## 专属精英：替换第1关通用精英

两种精英每次只出现一种、最多1只；精英自身威胁3，队伍总威胁不超过6。首次178秒出现军团旗官，第二次350秒出现破阵骑将；若前一只仍活，不叠加第二只，待击杀后的6秒补给窗口结束再安排一次，不补刷多个积压事件。

### 军团旗官：先拆阵，再杀精英

外观为背大旗、持短戟的重甲单位。移速1.45，接触伤害18固定；血量/经验/掉落沿用现有精英基线，额外精英×2只应用一次。

循环为整队4秒 → 旗阵攻势 → 恢复2.5秒。

整队时链接最近最多2名特殊小怪，距离不超过5；每名获得一次能吸收其最大生命15%的有限护盾，护盾持续4秒，8秒内同一目标不能重复获得。不回血、不复活，不给精英自身护盾。击杀军旗长立即清除关联护盾，护盾条与生命条分开显示。

旗阵攻势先锁定玩家所在半径1.5圆区，预警1.2秒、伤害20；圆区结束0.4秒后，命令一名存活猎手执行带完整0.85秒预警的侧突。圆区和突刺预约两槽；无合法猎手时只执行圆区，不临时贴脸召唤。

玩家处理选择：高单体先杀军旗长拆护盾，清群先杀薄弱侧小怪打开出口。两种路径都可行。

### 破阵骑将：引冲锋撞墙，争取反击

外观为低身骑乘骨兽的长枪兵，移速1.7，接触伤害20固定，血量/掉落沿用现有冲锋精英基线。

距离2.5～7时锁定一条长度6、半宽0.65冲锋线，预警1.1秒，速度6.5、伤害26，仅命中一次。撞墙硬直2.8秒；正常结束硬直1.8秒。硬直期间无接触伤害、受到伤害增加25%，明确显示破甲图标。硬直结束至少等待1秒才开始下一次预警。

每第二次冲锋起手前，在旧玩家坐标标记半径1.2的碎甲落点：预警1.2秒、爆炸18，之后立即消失，不残留；落点和冲锋错开至少0.5秒并预约两槽。无法验证出口时只冲锋。玩家侧移可以避开，反复退回同一点会吃第二段。

## Boss重做：铁棘围城督军

保留现有血量基线和50%转阶段，撤掉“平行双线夹着玩家却不打中央”的旧钳击。首领全程不锁血、不回血，不按玩家DPS动态调整血量。

阶段一按“钉位 → 破阵 → 横扫换区”循环；出生后1.5秒展示，第一个技能立即进入完整预警。恢复阶段停止追击且无接触伤害；每段预警与动作有独立状态，不因上一段提前结束而缩短预警。

1. **钉位连击**：锁定当前玩家坐标，半径1.6落点预警1.1秒、伤害26。落点结束后0.35秒锁定玩家新坐标，再预警1.0秒、伤害26。两击都不追踪；第二击结束恢复2.0秒。要求连续换位，而非躲一次停在原地。
2. **破阵冲锋**：沿用长度6、半宽0.65、预警1.2秒、速度7、伤害24的冲锋；冲锋结束后，无论碰墙与否，都在Boss终点发起半径2.8横扫，完整预警1.0秒、伤害24。之后恢复2.8秒，碰墙则恢复3.4秒并受伤增加25%。玩家先侧移，再决定撤离或反打。
3. **横扫换区**：以Boss位置为圆心，先给半径3.0内圈预警1.1秒、伤害24；结束后0.35秒对半径3.0～5.0外环给1.1秒预警、伤害24。内圈结束立刻显示其为安全区。玩家可先外撤再切回，或始终留在5单位外牺牲输出距离；此安全外圈由远程小怪提供压力。

进入第二阶段：清掉Boss未生效危险，过渡1.5秒，不清掉已发射小怪攻击；整段可达性重新校验。次序改为“钉位连击 → 横扫换区 → 破阵冲锋”，不缩短上述预警。每轮只允许一组专属援兵：盾卫+弩手或两只猎手交替；最多保留一组，存活则不补同组。援兵遵循出生预警/威胁预算、半经验、无药水金币。

第二阶段的第二个钉位落点额外残留1.5秒，每0.7秒8伤害，占用原危险槽直到结束；其他危险需等槽释放。通过落点位置记忆迫使换边，不叠加无预警补射。Boss不得因两槽繁忙连续跳过整轮攻击：延迟等待并保留待执行段，2秒仍无法合法执行则退回单段，统计降级原因。

## 教学与导演编排刻度

以下是导演刻度，非实际游戏秒数；第1关实际时间为刻度×0.75，480刻度对应360秒Boss。

0～30秒普通追击；30～60秒盾卫；60～100秒弩手（首次先用普通箭，第三次引入钉地）；100～130秒单次猎手突刺；130～170秒盾弩协同；170～178秒暂歇；178～225秒军旗长，仅带有限普通兵；225～285秒盾弩与猎手错开至少3秒；285～293秒暂歇；293～350秒混合进攻；350～395秒重骑；395～460秒成型阵型轮换；460～472秒收束，停止新增精英/猎手；472～480秒暂歇；480秒Boss。

成型阶段特殊阵型每10秒尝试一次，已有阵型活着不再叠加同组。若一波被玩家迅速拆掉，仍保留至少3秒清场回收时间，不能瞬间补怪抹掉强配装收益。计时遇暂停/升级停止，不追赶补刷。

## 专属外观要求

铁棘步卒：短矛与侧围箭头；盾卫：大型棘盾，盾面方向真实对应判定；弩手：双臂横弩和清晰装填动作；战犬：四足、低身预冲姿态。两名精英分别以背旗和骑兽轮廓区分，Boss使用大型棘甲、长戟和臂弩轮廓。必须在手机尺寸靠轮廓辨认，不能只换颜色或顶部图标。程序绘制独立轮廓与步行动作；资源来源与绘制预算见[统一美术规范](art-direction.md)。

## 实施顺序与验收门槛

先实现共享危险预约/连续攻击状态、有限控制抗性和出口验证；再实现小怪、专属精英、Boss；最后接专属形象和动画。玩法先用可辨白盒，不能因等美术卡住机制验证。

测试必须覆盖：预警冻结/死亡取消、已射实体保留、阶段清理、护盾不回血、不重复倍增、两槽预约释放、冲锋不穿墙、地面持续伤害节流、有限冰抗窗口、两段都可躲、恢复期不接触伤害、暂停不追赶刷新。

至少用6种互不相同的满级配装（覆盖清群、单体、近身持续三类）×3初始位置×3种子进行Boss站定与移动成对测试，固定敌人参数，保留实际配装和每段出手/命中/中断/跳过原因。站定不能稳定通关：同配装同位置3种子中胜2场即记为站定漏洞，须检查攻击覆盖、无限控制或恢复占比；不得只挑会输的配装。连续移动策略应在多种配装下存在通关样本，不用降低强度换取机器人必胜。

额外验证普通成长、第一分钟后挂机、4分钟后挂机各6种子，确认后期机制真的出手。模拟最长12分钟，超时单列。真实手机验收包括预警可读、出口可操作、帧耗和发热；仅模拟结果不能声称已经杜绝站撸。
