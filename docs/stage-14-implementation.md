# 第十四关开发记录 · 0.36.0

2026-10-21。第十四关「蚀昼观台」在本地实现，通关13解锁。保留肉鸽生存、随机成长、四武器四被动和360秒Boss，新增机制集中在敌人与精英/Boss战斗。**不上传微信后台**；后台仍为此前0.33.9开发版，没有提审或正式发布。

## 战斗实现

EclipseMap / EclipseGeometry / EclipseSystem通过StageStrategy注册，六根实体石柱、四主力（晦砂蠹、引晖巡盘、回晷长颈、偏轴环足）、两精英（双环测晷者、偏轴锁曜体）及三阶段「噬曜仪主」均接入。美术沿用Cocos Graphics，冷紫灰石台、旧金刻度和偏心浑仪；小型蠹的分节足、悬盘、长颈、偏轴、双环及Boss三阶段展开分开绘制。

光束支点、起始角、旋向、时间在发布时锁定。每束内端1.4、外端6.2、半宽0.20，2.4秒转90度，普通完整预警2.2秒、精英/Boss2.4秒。石柱按光束半宽扩张后求首个射线交点，圆帽停在实体外；截长不足内端时不生成幽灵圆帽。地图边界同样截光，但边界不计入柱影成就。

判伤与绘制共享当下截断胶囊。预警扇面、箭头、扫过的地面、连接支架均无伤；仅当前亮束有伤。连续判定在起止时刻及柱角遮挡变化处分段，以旋转胶囊真实距离和运动界递归收敛，最终命中必须在真实角度、真实截长上验证，时间容差1e-7秒、接触容差1e-9；不把整个扫过扇形或弦段当危险区。每个连续扫束最多一次命中尝试，双束独立。

每束从预警到收束预约一槽；反向复照的两段共享一槽且中间另有完整2.4秒预警。双轴两束原子预约两槽，发布前共同检查基础4.2移速、0.35秒反应、石柱滑行和当前人群下的逃生路径。候选围绕实际身体旋转，失败则真实导航换位后重试；不平移已经发布的支点、不读取玩家实时输出改血量。手机完整可视检查约束实际截断后的扫束；双轴角度向内错开0.2弧度，避免原始组合超出画面。

冻结、死亡或转阶段取消未来束；已经释放的当前有限扫束保持原时钟完成，死亡来源保留光轴标记。寒霜冻结立即清理待释放束，避免跨帧延迟撤招。最后当前束结束后才恢复并暴露甲缝。施法组中身体固定、持续可伤，不额外叠加普通碰撞伤害。Boss死亡直接胜利清场。

135/225/305/311秒四名精英按既有教学/返场节奏编排，返场正常生成生命100%，不额外削血或加血；两危险槽、威胁6、100实体上限保持。最终精英与其已发危险结束后，至少三秒交接再启Boss招式。Boss援军保持9秒补、5秒停、每三秒最多六名、目标28名，恢复/过渡/交接不补。

Boss按70%/35%进入三阶段，过渡至少1.5秒，不回血、不锁血、允许跳阶段。I A/B/C、II B/A/C、III C/B/A依次轮转，加入偏轴、双轴对转、终阶段双仪与独立预警的反向复照。固定最终束伤害普通22、精英26、Boss26、III双仪C组28，不再乘关卡接触倍率。

成长继续采用参考有效输出×目标时间的共享数学公式：普通系数3.025759921、精英3.614341760；Boss参考543.8826335 DPS×113.1264694秒＝61,527.522077生命，HUD显示61,528。恢复倍率到0.35下限，仅缩放恢复，预警和扫束时间不压缩。

## 成长、成就与存档

新增「观台复明」与「十二途逐晖」，成就总24。后者需要12种实际起手，每种3组不同合法双改、起手8级，至少36次合格胜利。每局Boss三个阶段各在有效主动束组中连续借真实石柱遮光至少0.8秒，III必须双轴C组；该位置必须在未截断胶囊原本会击中的范围内，且真实柱体令实际束无法击中。预警、内圈、超射程、束间空处及地图边界均不能替代。每段计时还用未遮挡距离的运动界证明整段接触，并用连续实际束判定排除短暂漏光，柱角处分段确认真实柱影；计时条件中断即重置，完整有效束组结束后才提交阶段标记，取消/冻结/未完成组不计；Boss来源实际扣血必须为0，跳阶段不补造标记。

胜利结算按runId去重；合法排序双改键用Array.from序列化到可选eclipseQualified，重复组合不增加组合进度，失败不清已有记录。奖励仅「逐晖者」称号与曜环徽纹，无永久属性、额外金币或抽取权重。成就图鉴新增起手进度入口，逐系列显示0/3～3/3；战斗提示显示I/II/III与当前柱影连续计时。

圣水增加史诗「长明灵泉」，稀有→史诗1440金币，完整普通→精良→稀有→史诗共2520金币。普通基准伤害倍率2.05，只继承一次；新增悬浮四面泉核、分离拱柄、三瓣落地及分段泉纹，图标、飞行、落地和水区均改变几何。范围、持续、周期、命中次数、元素及原改造不额外增强；指环追加部分40%伤害、复制范围半径80%与烛台面积换算继续生效。仍十四系列，各系列只有一个随机池位置；未实现进阶的其他系列不收费。

第14关胜利360金币，1～14首次通关合计3220金币，未购买其他物品可覆盖圣水全路线并余700。旧存档键、rules及版本不变，旧金币、购买、品阶、通关、旧挑战和三手动位保留；新字段单独修复，不从旧数据推断新挑战。
