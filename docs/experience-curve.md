# 从开局递增的升级经验

每一级所需经验从 1 级开始严格增加，后段增长更快。旧规则前 24 级有相同需求的相邻等级，之后固定 36 点，导致杀怪效率提高后迅速满级。

统一入口为 `assets/scripts/battle/ExperienceCurve.ts`。令 `n = level - 1`，升下一级所需经验为 `6 + n + min(n, 2) + floor(n² / 30)`；上限处取最后一级的有限数值供界面使用。

| 当前等级 | 升下一级所需经验 |
| --- | --- |
| 1 | 6 |
| 2 | 8 |
| 3 | 10 |
| 10 | 19 |
| 20 | 39 |
| 30 | 65 |
| 40 | 97 |
| 50 | 137 |
| 63 | 198 |

达到 64 级累计需要 5142 点经验。等级上限仍为 64，Boss 仍在八分钟登场；经验掉落、拾取、合并与余量保留不变。没有按时间锁住升级。
