# 武器分批开放与关卡成长设计

状态：设计稿，2026-10-20更新。本文记录后续成长方向，不代表已经开发或开放。当前游戏行为见[当前项目基线](current-baseline.md)。

2026-10-21追加：下文“五关/十二武器”等为当时规划背景，当前运行范围为十关、十四系列。后续新武器与进阶必须遵守[品阶/职责平衡预算](weapon-balance-0.33.6.md)，验收包括全部系列、合法改造、可用品阶及辅助整队收益，不能仅凭单次面板伤害定强度。

## 当前范围

当前工作区运行时已有五关、十二种武器，其中前十把默认开放。第五关及首批两把武器、金币和两个图鉴的设计见[灰烛钟庭](stage-05-bellcourt.md)与[图鉴及解锁方案](catalogs-and-unlocks.md)，已接入当前工作区，真人/真机平衡待验收，见[实现记录](stage-05-implementation.md)。

取消此前预排的第11～20把武器清单、五把金币加五把成就的数量安排，以及固定五档强度。这些内容不作为开发任务。现阶段不为了凑数量开发更多武器或成就，具体数量随实际关卡需求确定。

最高成就暂缓，不把第四关当作最终关卡。取消此前「仅使用前十把、整局最多三把，通关第四关」的成就与奖励绑定；未来有更多关卡后再设计长期挑战。

## 已确定的成长方向

- 前十种武器默认开放。后续新增武器需要解锁，具体开放批次随关卡规划确定。
- 有些武器通过通关成就解锁，有些通过金币购买；不要求每把同时满足两种条件。
- 通关一局可以获得金币，金币跨局保留，用于购买已经开放的金币武器。
- 解锁门槛越高，武器数值应越强。具体倍率结合对应关卡和武器实际表现设计，不预设强度上限。
- 金币系统、商店条目和武器可以分批开放；写入规划不代表马上开发，也不代表一次全部上线。
- 成就围绕真实存在的关卡和挑战设计，不预先凑满一套成就数量。

## 关卡与武器的推进关系

用户最新确认：解锁成长应帮助推进难关，但不强制解锁指定武器作为关卡入口条件。第五关只需通关第四关；重锤或飞轮均不是开门钥匙。玩家受阻后可选择刷金币买武器、完成成就解锁另一武器，或改变现有配装和打法再尝试。

金币武器金币足够可直接购买，不附加成就；成就武器完成对应条件后永久解锁，不再收费。前十把默认开放。

战斗内开局及升级保持随机。武器解锁后进入随机池，不可指定开局，不提供必出或保底，不保证当局取得某把新武器。

关卡可以体现整体装备强度门槛，不保证初始武器任意配置能轻松通关，但不能靠指定ID免伤、缺武器禁止进入或动态反制实现。必须为不同武器和打法保留实际收益，并测量随机成长的失败原因。

具体关卡需写清预期玩家进度、建议成长方向、可用金币/成就路径、随机池影响与不同配装的对照结果。先做实际准备开发的批次，不预排后续十把或最高成就。

## 分批开放规则

每一批只安排实际需要且能完成的内容。已规划、开发中和已开放必须明确区分。

|内容|开放条件|
|---|---|
|新关卡|关卡设计与实现完成，前置武器可以取得，完整推进链可验证|
|新武器|有对应玩法需求，实际攻击、升级与表现完成，解锁方式可用|
|通关成就|对应关卡或挑战已经存在，判定与奖励完成|
|金币系统|奖励、余额保存、消费与结算完成，且有本批实际开放的消费用途|
|金币商店条目|对应武器完成并列入本批开放配置，价格与前置关卡收益匹配|

武器尚未实现，或尚无实际可用的获取途径，任意一项未满足就标为「暂未开放」。允许在图鉴中展示已确定的规划条目，按钮不可用，不能购买、抽取、领取或装备，也不占可完成成就的数量。不为这些条目临时编造获取方式或要求立即补齐开发。

|武器状态|展示与使用规则|
|---|---|
|暂未开放|实现未完成、获取途径未就绪或尚未列入开放批次；图鉴可展示，明确标注「暂未开放」|
|已开放但未解锁|实现与获取途径均已就绪；显示真实的金币价格或成就条件，达成后才能使用|
|已解锁|已经取得且处于开放批次，可进入可用池；不强制指定武器入场|

新关不能依赖「暂未开放」的武器作为唯一通关解法，相关成长路径必须真实可用。

当前第五关批次拟新增两把武器，见配套设计；数量是本批方案，不代表后续必须按同样数量补充。

## 金币与数值待定项

保留「通关获得金币、部分武器用金币解锁」的方向。此前的固定关卡奖励、首通翻倍、300～2600金币价格表撤回。首批新的试验奖励与360金币单商品见[图鉴方案](catalogs-and-unlocks.md)，尚待实测。

对应批次开发前，再根据关卡通关时长和武器需求决定通关奖励、是否设置首通额外奖励、售价及预期积累局数。失败或退出是否给奖励也留到金币系统细化时确定。

建议解锁武器的获取时间必须纳入关卡节奏，不能只靠抬高金币价格拖长进度。高门槛武器的强度应在目标关卡体现，具体伤害、周期、范围等参数通过同等级配装验证。

## 后续实现需要保留的要求

- 金币、购买记录和成就跨局保存，兼容现有合法关卡进度。
- 同一局结算不重复发金币；重复点击购买不重复扣款。
- 已解锁且已开放的武器才进入可用池。解锁不直接增加本局持有武器数量。
- 关卡不强制指定武器入场；保持开局与升级随机，按实际随机成长验证难度。
- 界面提示前置武器的取得途径，以及未开放内容的状态。
- 存档字段、旧账号补偿和技术接入位置在实际开发范围确定后细化，不沿用此前未实施的整套二十武器方案。

## 下一次设计的完成标准

只需针对下一批实际准备制作的关卡，明确其前置成长需求、建议的新武器、对应金币或成就来源，以及开放顺序。不要求同时设计后续所有关卡、武器或最高成就。
