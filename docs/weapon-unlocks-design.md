# 武器分批开放与关卡成长设计

状态：设计稿，2026-10-19。本文记录后续成长方向，不代表已经开发或开放。当前游戏行为见[当前项目基线](current-baseline.md)。

## 当前范围

当前只有四关、十种武器。本次只更新设计文档，不新增武器、成就、金币功能或前端界面。

取消此前预排的第11～20把武器清单、五把金币加五把成就的数量安排，以及固定五档强度。这些内容不作为开发任务。现阶段不为了凑数量开发更多武器或成就，具体数量随实际关卡需求确定。

最高成就暂缓，不把第四关当作最终关卡。取消此前「仅使用前十把、整局最多三把，通关第四关」的成就与奖励绑定；未来有更多关卡后再设计长期挑战。

## 已确定的成长方向

- 前十种武器默认开放。后续新增武器需要解锁，具体开放批次随关卡规划确定。
- 有些武器通过通关成就解锁，有些通过金币购买；不要求每把同时满足两种条件。
- 通关一局可以获得金币，金币跨局保留，用于购买已经开放的金币武器。
- 解锁门槛越高，武器数值应越强。具体倍率结合对应关卡和武器实际表现设计，不预设强度上限。
- 金币系统、商店条目和武器可以分批开放；写入规划不代表马上开发，也不代表一次全部上线。
- 成就围绕真实存在的关卡和挑战设计，不预先凑满一套成就数量。

## 关卡与武器的推进关系

后续部分难关可以建立在玩家已经解锁更强或更适合该关武器的基础上。允许出现「当前武器很难甚至无法通关，先取得前置武器再回来挑战」的成长门槛，不要求所有未来关卡都能仅靠初始十把武器通关。

推进循环为：挑战受阻 → 在较早关卡完成成就或重复通关攒金币 → 解锁所需武器 → 再挑战难关 → 开放后续内容。

必要武器必须在该难关之前能够取得。不能把通关难关作为获得其必需武器的唯一条件；金币武器也必须能够使用前面已开放关卡的收益买到，避免循环卡关。

关卡设计时需要分别写清：

1. 本关面向的玩家进度和预期已有武器。
2. 哪种武器是通关前提，哪种只是有帮助；若有多种可行武器，列出替代方案。
3. 前置武器在哪里开放，通过哪项已存在的成就或多少金币取得。
4. 武器如何帮助通关，例如伤害达到清怪要求、穿透处理阵列，或爆发覆盖首领输出窗口。
5. 如果需要特定武器，玩家如何在进入本关前获得可用配装，避免只有随机抽到才能尝试。
6. 通关后解锁什么内容，以及下一批关卡和武器是否已经具备开放条件。

具体关卡编号、武器名称、成就条件和数值，留到对应关卡设计时确定。当前不提前指定第5关以后的完整内容。

## 分批开放规则

每一批只安排实际需要且能完成的内容。已规划、开发中和已开放必须明确区分。

|内容|开放条件|
|---|---|
|新关卡|关卡设计与实现完成，前置武器可以取得，完整推进链可验证|
|新武器|有对应玩法需求，实际攻击、升级与表现完成，解锁方式可用|
|通关成就|对应关卡或挑战已经存在，判定与奖励完成|
|金币系统|奖励、余额保存、消费与结算完成，且有本批实际开放的消费用途|
|金币商店条目|对应武器完成并列入本批开放配置，价格与前置关卡收益匹配|

武器尚未实现，或尚无实际可用的获取途径，任意一项未满足就标为「暂未开放」。允许在图鉴中展示已确定的规划条目，按钮不可用，不能购买、抽取、领取或装备，也不占可完成成就的数量。不为这些条目临时编造获取方式或要求立即补齐开发。

|武器状态|展示与使用规则|
|---|---|
|暂未开放|实现未完成、获取途径未就绪或尚未列入开放批次；图鉴可展示，明确标注「暂未开放」|
|已开放但未解锁|实现与获取途径均已就绪；显示真实的金币价格或成就条件，达成后才能使用|
|已解锁|已经取得且处于开放批次，可进入可用池；有配装前置要求的关卡仍按其入场规则处理|

后续难关如果依赖某把武器，该武器必须先完成实现并开放获取；不能让玩家必须依靠「暂未开放」的武器才能推进。

本次不确定首批新增武器数量，也不把十把新武器拆成必须完成的批次。后续先设计需要的新关卡，再决定补充哪几把武器。

## 金币与数值待定项

保留「通关获得金币、部分武器用金币解锁」的方向。此前的固定关卡奖励、首通翻倍、300～2600金币价格表、总价和刷关次数估算撤回，不作为当前定案。

对应批次开发前，再根据关卡通关时长和武器需求决定通关奖励、是否设置首通额外奖励、售价及预期积累局数。失败或退出是否给奖励也留到金币系统细化时确定。

前置必需武器的获取时间必须纳入关卡节奏，不能只靠抬高金币价格拖长进度。高门槛武器的强度应在目标关卡体现，具体伤害、周期、范围等参数通过同等级配装验证。

## 后续实现需要保留的要求

- 金币、购买记录和成就跨局保存，兼容现有合法关卡进度。
- 同一局结算不重复发金币；重复点击购买不重复扣款。
- 已解锁且已开放的武器才进入可用池。解锁不直接增加本局持有武器数量。
- 如关卡需要特定配装，届时同步设计可控的入场或取得方式，不能只扩充随机池。
- 界面提示前置武器的取得途径，以及未开放内容的状态。
- 存档字段、旧账号补偿和技术接入位置在实际开发范围确定后细化，不沿用此前未实施的整套二十武器方案。

## 下一次设计的完成标准

只需针对下一批实际准备制作的关卡，明确其前置成长需求、必要的新武器、对应金币或成就来源，以及开放顺序。不要求同时设计后续所有关卡、武器或最高成就。
