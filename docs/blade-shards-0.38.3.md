# 0.38.3 · 碎刃散射重构

2026-10-21。用户反馈碎刃飞出去便消失、收益低。旧机制等整轮主刀结束后，在最后一把刀的终点沿固定方向发两片短刀，碎刃经常没有合适目标；另扣主刀15%伤害，受控场景中可能为负收益。

## 当前行为

- 同一轮主刀**首次造成实际伤害**时触发，从命中位置散出至多两把短程锁敌碎刃。优先选择命中点2.8范围内的其他存活敌人；附近只有原目标时两片补打原目标。原目标死亡且周围无目标时不向空地盲射，不因整轮结束再次散射。
- 主刀不再减伤；每片继承触发刀伤害快照的60%，不再乘一次品阶或指环倍率。若由复制刀触发，就继承复制刀已经折减后的伤害。每轮至多一组，不随主刀数量、去回命中段或穿透次数增加。
- 碎刃是实体弹体，有限转向6弧度/秒、总行程2.8，命中一个目标后结束，不穿透、不往返、不递归。锁定目标死亡/离开预算范围后不无限追踪，不延长寿命；空挥不触发。优先其他目标的碎刃忽略原触发者，避免出生便被原目标吞掉。
- 保留原来0.3单位飞离后可碰撞的规则及同帧子弹延后推进，主刀碰撞与碎刃碰撞分别结算。碎刃生成不改变其他武器、冷却、金币或账户字段。
- 同一系列四品阶共用机制，兼容原`shards`改造ID、已有进度及合法配方；更新改造说明、暂停详情与生成式改造指南。0.38.1金币显示及0.38.2追猎切换修复均保留。
