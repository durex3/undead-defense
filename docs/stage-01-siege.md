# 第1关：铁棘围城

更新：2026-10-19。初始开放，ID1；360秒进入Boss战。成长、存档与验证状态见[当前项目基线](current-baseline.md)。

## 核心体验

绕侧拆盾弩阵，优先处理旗官和射手，躲过战犬突袭与骑将冲锋，在督军连续攻击后的恢复期输出。具体敌人技能见[敌人设计](stage-01-enemies.md)。

## 遭遇与美术

先教学盾、弩、犬，再组合阵型并引入两名精英，最终迎战铁棘围城督军。导演使用 `siegeScoreTime` 将480秒编排压缩至360秒，不把旧480秒时间表直接当成游戏秒数。

冷灰铁甲、暗红布、淡金兵器与暗石地面；短矛、棘盾、横弩、旗帜、骑兽和督军长戟形成不同剪影。动作、图层及手机验收按[统一美术规范](art-direction.md)。

当前第1关倍率：普通生命1.65、精英1.85、Boss生命2.45、关卡伤害1.42、经验0.85、药水阈值42；来源 `StageRules.ts`。固定技能伤害不再重复套关卡倍率。
