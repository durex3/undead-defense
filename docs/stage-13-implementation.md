## 已实现

独立EdgeCourtMap/Geometry/System通过StageStrategy注册。四主力为铁屑傀、掷锋傀、踏刃傀、牵锋兽，两精英为双铗裁手、换锋司傀，Boss为换锋傀主。阵营以冷铁偏心傀体、关节足、持刃/空手/接刃状态区分，仍用Cocos Graphics。

- 飞刃拥有独立的去程、停驻、回收时间表；停驻刀及连接细线无伤。渲染与判伤共享每程胶囊、固定端点、角度、时间；去/回各最多尝试命中一次，低帧按每程起止时刻拆分相对扫掠。
- 本体按真实有限突进路径移动，飞刃从本体真实位置或已公布的到位点发出，不能单独平移危险快照冒充本体移动。全部候选可围绕实际起点旋转，失败则真实导航换位重试。来源、顺序和每段独立启动倒计时可见。
- 一刃从预警、飞出、停驻到回收始终预约一槽，本体计划另占一槽；双刃禁止追加第三次本体突进。整组关闭普通接触扣血，仅按明确实体判伤，避免突进和接触重复伤害。
- 冻结/转阶段撤掉未来段，已释放刃完成当前单程，活本体完成当前有限步；死亡的身体不保留幽灵冲撞。最后已发段结束后才进入完整恢复。Boss死亡直接胜利清场。
- 135/225/305/311精英编排、至少六秒错峰、最晚328/334、生成时正常HP100%、两危险槽/威胁6/100实体、Boss等待最后精英及旧危险结束和至少三秒交接均接入。Boss援军有数量及补援/停援节奏。
- Boss70%/35%三阶段，I A/B/C、II B/A/C、III C/B/A，不回血、不锁血、允许跳阶段；III有双刃或一刃两步，不缩短完整预警，不临时追踪。回收后护皮开缝，近身/地面/远程均能打本体。

Boss候选预算最终沿当前公式为60,450.289945生命，HUD向上取整60,451；普通系数2.988735725、精英3.566295430；恢复0.387420489只作用恢复，不作用预警。固定技能普通22/精英及Boss26/第三阶段28，使用最终伤害入口。通关340金币、结算去重，不读取玩家实时DPS调整血量。
