## 已实现

- 独立墓苑地图、四主力/两精英与错峰返场、100实体/威胁6/两危险链预约、墓台挡身体但不挡骨震和友方攻击。普通/精英初登场与返场按同时间正常生成HP100%。Boss等待最后精英与已发攻击结束，再休整至少3秒。
- 实心有限扇形骨震、原地原朝向回响、0.18秒半开判伤窗口。圆弧/径向边/原点共享绘制与判伤参数，玩家圆连续轨迹检测；预警/灰色余痕无伤，每脉冲只尝试一次伤害。初震结束后另给完整2.4秒回响预警，静默间隔不释放预约槽。
- 「负棺镇墓者」→首次真实死亡→已发脉冲收尾→2.4秒裂棺→「裂棺猎骸」→最终死亡。一死一复活，不再固定三阶段。第一命不增加击杀/金币，不触发通关，不锁1HP；致死溢出不穿到第二命，死亡态不可锁定或阻挡导航。
- StageStrategy新增可选生命周期入口，保留待复活HP0实体、独立推进死亡/复活时钟、拦截首次死亡。旧1～15关默认路径不改。两命共用稳定遭遇ID，命次分开；玩家生命、等级、装备和冷却保留，目标燃烧/裂甲/减速/灯标/缝线清理，友方弹体命中去重及持续场原寿命/节拍保留。
- 第一形态A前震、B留痕回响、C双肩错拍。第二形态A真实侧移后旧址回响，B旧址与身体夹击，C身体近震/旧址/前扇三拍两链。B恢复后先实际导航换位再尝试C，避免最近旧痕与身体重合；未到位不发布虚假来源。旧痕只存一枚，12秒过期；不可复用时降级身体招式，完整预警不缩短。
- HUD区分两种形态、剩余命数、复活倒计时、本体/旧址及链/拍编号；暂停、升级与后台暂停均停止游戏时钟。失败/退出不会后台自动复活或结算。
- 合计HP63,198.698550，第一命25,279.479420，第二命37,919.219130（40%/60%）；HUD取整不反写实际HP。补给按整场累计实际损血25/50/75%各一次，避免每命三次。此预算沿用平滑趋近公式，后期仍增长但增幅减小，当前装备基线Boss极限67,200；新增装备输出档位后再校准，不能无限套指数膨胀。
- 新增「墓苑破棺」「十二途断棺」，总28成就。后者12实际起手各5组合法双改，起手8级，负棺A/B及裂棺实际双址B完整无伤后近身真实反击，且全Boss来源无伤；至少60组合格胜利。配方版本1冻结，重复/失败/中断/单源降级/打尸体不能冒充条件，旧挑战不扩大。称号「拆棺猎手」与裂棺双芯徽纹无属性收益。
- 火球史诗「烬冕焚星」已开放，稀有→史诗1440金币，完整路线2520；普通伤害基准2.05倍。双菱火芯、三焰叶、断冕、分节尾迹、六瓣爆炸与冕纹火海；不额外加半径/弹数/持续或控制，主爆/碎焰/火海品阶只乘一次。保持14系列，图鉴升级图标不挤掉简介。
