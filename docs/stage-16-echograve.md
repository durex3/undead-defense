# 第十六关设计 · 回骸墓苑

2026-10-21设计，现已在本地0.38.0开发开放；实施与验证见[开发记录](stage-16-implementation.md)，已按用户最新指示上传0.38.0开发版本，未提审或发布。以下保留原设计预算和验收要求。按用户新要求，第16关起Boss不再固定三阶段，本关采用**一次复活、两种形态、一次最终胜利**。肉鸽生存、随机成长、四武器四被动和360秒Boss保持，依据[统一规则](level-design-rules.md)。

## 1. 新判断：辨认当前身体与旧骨痕

本关Boss「镇墓者」初为厚重的**负棺镇墓者**，首次倒下后棺甲崩裂，复活为轻快的**裂棺猎骸**。不是原模型重新站起来加伤害：第一形态低伏四足、背负大棺甲、动作沉重；第二形态直立双足、展开肋骨猎翼与长前爪，身体轮廓、移动和出招组合都改变。

核心机制为**骨震留下可见旧痕，完整预警后在原位置、原朝向再次发动**。第一形态教会看扇形和等待回响，第二形态离开旧痕位置，并把旧址与当前身体组合成双来源夹击。旧痕不会追踪、瞬移或无预告爆炸，危险也不会无限积累。

- 候选ID16，通关15解锁，没有指定武器、品阶、移速或成就门槛。
- 四主力、两精英、三轮精英，精英初登场/返场均为同时间正常HP100%，**精英不复活**。
- 100实体、特殊威胁6、全场两危险预约槽，包含预警、待回响与未来段。
- Boss只复活一次，没有70%/35%分段，没有隐藏第三条命；第二次倒下才通关。
- 建议新增2成就（26→28）及火球史诗一档；不增加新系列，随机池仍十四系列。
- 候选胜利400金币，首条命倒下不发通关金币、不算通关。

## 3. 骨震、旧痕与两槽预约

### 3.1 真正的危险几何

单次骨震是**从原点O出发的实心有限扇形**，不是整圆，也不是环形。基准半径4.2、半角45°，普通预警2.2秒、精英/Boss2.4秒；只在到时后的0.18秒半开窗口有伤。扇形内侧覆盖O，不存在原地贴在轴心的永久安全点。

危险快照锁定原点、角度、半径、半角、due/end、来源个体/命次/组/段。玩家圆与真实扇形相交才算命中：扇内为0距离，扇外求两条径向边及有限圆弧的最近距离，再与玩家0.3半径比较。必须保留圆弧与两端边角，不能把半径4.2当整圆伤害，也不能用扇形包围盒或三角形近似判伤。

低帧按due/end拆分玩家实际运动，连续检测玩家圆扫过扇形；墙滑使用实际分段轨迹。每个脉冲最多一次命中尝试，不持续每帧扣血。预警和结束后余尘均无伤，暂停不推进攻击时钟。正常最终伤害普通22、精英/Boss26，裂棺形态C为28；走最终伤害入口，不再次套接触伤害倍率。

攻击组中关闭额外普通接触叠伤，身体始终可被正常武器攻击；普通追击接触另按明确状态处理，不把无伤移位伪装成冲撞。

### 3.2 原地回响

回响严格复用已公布骨震的**原点、朝向、半径与半角**。初震结束后另有完整2.4秒预警，才在同一处再震0.18秒。基准时序：初震t0+[2.40,2.58)，回响t0+[4.98,5.16)。不能在第二下重新瞄准玩家，也不能把旧痕挪到新身体脚下。

从预告到回响结束，一条“初震+回响”链始终预约一槽，中间空窗不归还。双来源同时公布时原子预约两槽，禁止附加第三次冲撞、落石、墓台爆炸或额外震圈。

画面区分：当前身体来源用骨白棺口符号，旧痕来源用青紫裂棺符号，显示对应组号、下一拍序号与独立倒计时。地面余痕在未激活时是灰色断纹、无填充、无伤；激活时出现完整扇形边界/蓄力纹；到时才有短暂实心骨震。不能用只有颜色不同的两个相似圆圈让玩家猜来源。

### 3.3 裂棺形态的旧址复用

只保留**一枚**最近完成的、来自当前命次身体骨震的旧痕，最多保留12秒。未激活的旧痕是无害历史标记，不是持续伤害，也没有已经预约的未来攻击；它不能突然发作，只有后续招式明确激活并给足2.4秒预警才成为危险、占用预约槽。

旧痕保存原几何，不重新跟踪玩家、不随身体移动。身体离旧痕至少1.5才能使用双来源招式；太近、过期、出可视区、旧痕来自上一条命或联合退路不合格时，放弃该次旧痕联动，改为当前身体单次骨震且重新完整预警。身体下一次真实完成骨震后可更新标记，不叠第三枚痕，也不能把标记直接刷新到未到达的目标点。

所有候选同时检查：实际扇形极值与边界/手机HUD、两个危险槽、基础4.2速度/0.35秒反应、墓台碰撞与当前人群下的**联合**无伤路径。旧痕不可转向/平移适配场地，只能放弃复用；当前身体的新招可在公布前选朝向，失败则真实导航换位。不得通过瞬移、隐藏扇形、无敌帧或减少完整预警放行。

### 3.4 取消与来源生命周期

冻结/死亡/变身取消未发脉冲，已发0.18秒地面脉冲完成原窗口后结束，不追加或延时。旧痕链被中断就不计本组挑战。第一形态死亡立即清空未激活痕与未来回响，当前已发脉冲仍有可读来源；等待它结束后才开始复活演出。最终死亡则胜利清场，不继续留下伤害。

所有Boss来源伤害归属**整场镇墓者遭遇**，两命、复活前留下的已发脉冲都计入同一Boss无伤记录，不能因为第一命HP归零便失去来源。普通/精英只正常死亡，不借用Boss复活机制。

## 4. Boss：一死、一变、再战

### 4.1 两命总预算与明确提示

候选合计生命沿当前StageGrowth(16)公式为63,198.698550，按40%/60%分配：负棺25,279.479420、裂棺37,919.219130。数值为浮点预算，HUD各自向上显示25,280/37,920，合计显示63,199；**不能把两条HUD取整数再相加作为实际HP**。

开战即显示「负棺镇墓者 · 余命2」，双命标记与说明“棺甲破碎后会裂棺复生”。第二形态显示「裂棺猎骸 · 余命1」。血条是当前形态实际HP，可附总剩余百分比；复活时明确显示“裂棺复生”，不显示胜利、金币或通关章，也不使用第一/二/三阶段标题。

两形态不再有70%/35%血线转段。第一命真实归零，进入死亡/待复活状态，而非停在1HP。一次复活，不重复触发；第二命归零才触发最终死亡与结算。

### 4.2 第一次致死的状态机

`负棺存活 → 第一命倒下 → 等当前已发骨震结束 → 裂棺复生2.4秒 → 裂棺存活 → 最终死亡`。

- 第一命致死当帧记录一次“命次结束”，停止继续接收伤害、取消未来攻击、停止援军补入。尚存追兵不凭空删除；复活演出不新增Boss伤害，但并非全场追兵冻结。
- 第一命HP保持0，不是存活锁血。负棺实体/逻辑遭遇需保留以管理已发来源与复活；它不参与武器锁定、碰撞与导航阻挡，不占用新的特殊威胁角色。
- 已发0.18秒脉冲结束后，完整播放2.4秒裂棺演出，之后仅一次恢复到第二形态的预分配HP。例：10.00秒致死、当前脉冲到10.12结束，则12.52秒进入第二形态。
- 致死溢出伤害不穿透尚不存在的第二命；同帧其他命中在死亡态不能累计成第二命伤害或重复复活。伤害统计只计对当前实际HP造成的伤害，不把溢出和复活生命当额外输出。
- 复活间隔中的不可伤是明确的死亡演出状态；不能对存活形态额外加长无敌、锁1HP等候招式播放。第二形态从首次新锁定起仍给完整2.4秒预警，不能复活瞬间攻击。
- 清理第一命自身的燃烧、减速、裂甲、引魂烙记和缝针连接等临时目标状态，第二命按新生命开始；玩家生命、等级、武器、被动、经验、冷却、全收经验充能均保留，不免费满血或重置CD。
- 已发友方弹体/火海等保持原寿命与节拍，死亡期间不打尸体、不补回错过的伤害。其原命中去重不能因复活被清空而让同一发额外命中；第二命活过来后正常存在的持续技能按原节拍继续，不能为变身再乘一次品阶或复制倍率。
- 暂停/升级/后台暂停使用游戏时钟，停止复活倒计时；失败或退出立即停止遭遇，不在后台自动复活/结算。现有手动位保存的是账户，不承诺新增局中Boss战恢复。

### 4.3 负棺形态：沉重、来源单纯

近距追击速度1.6，远距追近用既有导航速度5；站定出招，保留可打身体和恢复空门。A→B→C循环，无血线强制变化。

|招式|内容|预约|整组结束后基础恢复|
|---|---|---:|---:|
|A 棺前开骨|身体前方实心扇，r4.2、半角45°，一次骨震|1|4.2秒|
|B 负棺留痕|身体r3.6、半角60°骨震，同几何2.4秒独立预警后回响；本体不移动|1|4.6秒|
|C 双肩裂震|身体两扇，方向为发布朝向±55°、各半角40°，第二扇晚0.8秒；不追加回响|2|4.8秒|

C中央方向留30°角缝，但缝不是整个半径都安全：角色半径0.3需要距源大于约1.16才能完整站入缝；轴心仍被真实扇形覆盖。玩家也可绕背或离开有限范围，不能只认画面中线就判免伤。

### 4.4 裂棺形态：移位、旧址与当前身体交错

近距追击/组内无伤移位速度2.4，远距导航追近5。A→B→C循环，攻击来源与时序更复杂，仍不缩短完整预警。没有不画的追踪弹、额外冲撞或强制指定武器。

|招式|内容|预约|整组结束后基础恢复|
|---|---|---:|---:|
|A 离痕追步|身体r4.2/半角50°初震→同几何回响。初震结束后本体沿可见路线向侧方2.4单位真实移位；移位本身无伤、不另出新招，旧痕留原地回响|1|4.6秒|
|B 旧址夹猎|激活合法旧痕一次，同时当前真实身体发布新扇，第二来源晚0.8秒；不追加额外回响。旧址角度不变，新扇r4.2/半角50°|2|4.8秒|
|C 双痕猎幕|当前身体近震圆r1.65→旧痕复现→当前身体前扇r4.2/半角50°；身体两拍一链、旧痕另一链，不再添加第四击|2|5.2秒|

C示例：近震t0+[2.40,2.58)，旧痕[3.60,3.78)，新扇[4.98,5.16)。身体与前扇朝向从组公布时锁定，全过程原地施法；前扇距近震结束另有2.4秒预警，不等第三拍突然换向。圆震明确画为实心圆，不能与扇形混用判定。

A的移位目标在组公布时锁定，身体按同一实际导航路径移动，绕不开墓台则停止移位/选可达候选，不能穿台、瞬移或把旧痕跟着身体拖走。没有中途追加追踪攻击；B/C只能从已经到位的当前身体发布。若没有有效旧痕，B/C退为各自的当前身体招式，照常完整预警与恢复；不能为了凑组合凭空生成旧址。

每次身体骨震正常完成后可保存当前命次骨痕，组内不覆盖已经公布的旧痕快照。初次裂棺清除第一命的历史标记；先通过A生成第二命旧痕，再逐步出现B/C双来源。旧痕循环不积压，屏幕只保留当前有关的一枚灰痕。

恢复统一乘关卡0.35一次，不作用于预警、回响间隔或复活演出。A移位和回响间隙身体仍可打，但未整组收束不视为完整暴露；组结束才享既有恢复暴露收益。两命基础护甲均55%，不秘密对高阶/近身武器免疫，复活后主要强在动作和组合。
