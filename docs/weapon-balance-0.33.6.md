# 武器品阶、职责预算与0.33.6平衡

2026-10-21。针对重锤相对其他武器过强的试玩反馈，调整现有十四个系列，并建立后续新武器必须执行的横向验收。本轮不更改武器获取价格、已解锁权益、品阶记录、随机权重、敌人生命或关卡预警。第十一关仍是设计稿，未注册运行关卡。

## 1. 先前检查的缺口

此前检查过基础输出与机制，但主要横向脚本只遍历十把基础武器；重锤、飞轮、引魂灯和缚影缝针未进入同一比较。旧`weapon-balance.mjs`、`compare-weapons.mjs`还引用已废弃的武器/进化API，不能当作当前平衡证据。功能测试通过不能证明各武器强度合理。

新正式入口为`npm run weapons:benchmark`，遍历`ALL_WEAPONS`及所有已开放品阶，不再另手写十武器列表。基准只诊断输出、覆盖与辅助收益，不是玩家胜率或真机性能认证。

## 2. 品阶采用明确预算，不设置隐藏伤害硬上限

以8级、无被动、无改造的普通主输出系列为100个参考强度单位；品阶依次乘1.00/1.25/1.60/2.05。对应主输出参考带：

|品阶|相对普通权重|主输出参考区间|
|---|---:|---:|
|普通|1.00|80～120|
|精良|1.25|100～150|
|稀有|1.60|128～192|
|史诗|2.05|164～246|

这些是同一参考场景下的预算单位，不是所有技能单次伤害必须相同。落地验收按职责分配实际DPS参考带：控制、破甲、聚怪、传伤、增伤需要占用预算，不能拿满主输出又免费拥有全部功能。高品阶形态在对应系列基准上递增，不能比较一次重锤和一次水区跳伤得出结论。

`WeaponBalance.ts`逐系列定义普通基准DPS带，实际带乘目标品阶权重。参考环境为游侠自带10%伤害、30秒高生命目标，无被动/改造/敌人AI。主输出偏向80～120，控制40～65、破甲按系列65～100、聚怪30～45、增伤18～25、传伤45～65；具体职业的细分范围与指定场景见配置及报告。引魂灯/缚影缝针分别按稀有/史诗权重计算，不用低自身输出误判其整队价值。

地雷以移动目标触雷作验收基准，其他当前系列以近距目标作基准；不能要求地雷凭空炸远处。远距、背后、移动、八目标团/环/纵列、护甲Boss与暴露Boss仍全部记录，用来检查短板是否真实、长处是否过强，不因为一个有利场景达标就删除其他结果。

同品阶、同角色、同被动下比较；当前部分普通系列尚未实现进阶，不伪造稀有圣水来凑同品阶测试。报告明确保留各系列的实际初始品阶，飞刀与重锤额外检查全部已开放进阶。

## 3. 具体调整

- **重锤**：首锤伤害、举锤时间、覆盖、裂甲及已购买品阶倍率保留。单轮追加锤各造成首锤40%伤害，裂纹继承所属锤的快照；回摆仍每整轮一次。数量成长继续增加打击次数，不能把全额爆发及破甲收益按数量同时翻数倍。以8级精良、游侠为例，首锤101.2不变，三锤总伤303.6→182.16；合法重击改造仍保留大数字。
- **飞轮**：基础单击28→24，追加飞轮为首轮40%伤害；去返和端点绞切分别沿用已有逻辑及上限。保留裂甲与回收固定的特点，收紧多枚同敌重叠的总收益。
- **圣水**：1～8级每跳9/12/12/15/18/20/23/26，保留0.4秒跳伤、同源重叠不叠加、水区/回涌和既有周期，改善持续封路的实用输出。
- **落雷**：逐级单雷36/45/45/54/66/74/88/100，周期及同敌主雷每轮一次保持，不用多目标上限伪装单体连击。
- **地雷**：基础35→60，仍需武装、触发，到期不免费爆炸；提高玩家成功引怪后的回报。
- **黑洞**：基础跳伤6→8，仍不拉精英/Boss，重叠不叠加。
- **幽灵**：基础16→14.4，有限追猎与目标分配不变，收紧低风险追杀收益。
- **火球**：基础伤害不变，碎焰主爆代价20%→30%，收紧重爆＋碎焰在同一点的高收益，其他形态不删。
- **引魂灯**：伤害逐级8/10/10/10/13/13/17/17；基础烙魂16%，聚焰22%，不叠层，目标数、有效期和范围限制保留。
- **缚影缝针**：针击逐级168/210/210/210/270/270/336/336，补足史诗解锁的直接伤害价值。传递比例20%/深缝30%、至少0.25秒间隔、单对连接、单次/整段预算、不递归继续执行；上限由缝针自身伤害推导，不按伙伴生命放大。
- **飞刀、寒霜、骨矛、圣剑**基础数值本轮保留，继续作为近身、控制、贯穿与锁点输出的参照。

图鉴同步解释首击/追加击差别、灯的16%/22%和碎焰代价，不用旧文案掩盖变化。品阶系数在攻击快照中只乘一次，追加攻击继承快照，不在命中层重复乘品阶。

## 5. 新武器与后续调整的强制流程

1. 设计时写初始品阶、战斗职责、参考预算带、条件优势和明确短板；与至少两把同职责/相近品阶武器对照。强单体、强范围、控制、破甲和辅助不能同时免费拉满。
2. 把新系列加入`ALL_WEAPONS`并补全`WEAPON_BALANCE`。配置为完整`Record<Skill,...>`，遗漏预算应直接导致类型检查失败，不能默认跳过。
3. 正式基准必须覆盖1/4/8级、各自初始品阶、所有可用进阶、全部合法双改、九类场景。新增品阶通过`validGrade`枚举，不再手写只检查飞刀/重锤。
4. 基础职责参考带为必须通过项；合法双改在近距/移动诊断中上限为该职责/品阶上限的1.8倍，防止多重派生失控。改造换覆盖或控制可以牺牲单点，不能因此要求每种改造都比无改造单点更高。
5. 引魂灯、传伤、破甲等必须增加四槽整队对照，报告自身伤害及整队增量；冻结、聚怪另测有效控制目标秒数、目标类别与免疫。不能只凭辅助自身DPS给它大幅加伤。
6. 单次/总段预算、命中去重、同源叠伤、递归与品阶叠乘均需功能回归；新效果不得因为有DPS预算就跳过判伤和性能验收。
7. 同种子、同配装的现有Boss输出窗口对照；再做真实Cocos构建、图鉴文案、冷重启存档与微信真机试玩。机器人完整通关不作为硬门槛，真人反馈继续调优。

这些范围是可评审的首版规则，不是已经证明所有场景完全均衡。若新机制需要超预算，必须写出代价、实测及调整理由；不能只因是解锁武器就无限抬高数值，也不能先量好输出再随意扩大预算以过关。

## 6. 本轮验证

- 714组运行时输出与整队诊断，14系列职责带、38个品阶参考/护甲样本、140个改造上限检查通过。完整数据见`artifacts/weapon-balance-0.33.6/before.json`及`after.json`。
- 523项自动回归中522通过、1项历史跳过、0失败。新增首锤保留、追加伤害预算、进阶不叠乘、飞轮有限去返与全系列预算覆盖；灯的期望改为新16%。TypeScript通过。
- 十关×五套四武器配装共50组高生命/无敌输出窗口诊断，均实际四槽，24～99秒结束；包含重锤/飞轮及灯/针配装，数据见`artifacts/four-weapon-boss.json`。不代表真人胜率。
- Web/微信构建通过；真实Cocos浏览器实测精良8级重锤首击101.2、三击合计182.16，确认追加快照及品阶只结算一次。补回码、三个手动存档、覆盖/读取/删除及冷重载继续通过，未捕获运行异常。
- 0.33.6已上传微信后台开发版本，包大小2,894,507字节，见[回执](../artifacts/wechat-upload-0.33.6.json)，未提审或正式发布。
