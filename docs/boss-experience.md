# 0.17.1：Boss战继续成长

2026-10-14。Boss战原本没有关闭升级，但持续刷新的援军被归为召唤怪，不掉经验。统一经验曲线变慢后，玩家可能未满级就进入Boss战，旧地图经验捡完后失去继续成长的来源。

## 当前规则

- Boss尸潮导演补充的普通援军显式标记 `bossReinforcement`，击杀掉落普通怪50%的经验，再乘本关经验倍率。比如第13关每只为0.425点；结晶合并保留小数，不向下取整。
- Boss技能召唤怪、其他召唤怪和分裂子怪不具有该标记，仍不掉经验。通过owner为0来猜身份会误判分裂子怪，因此不使用owner推断。
- 援军仍不掉金币和药水；只增加经验，不让经验分支顺带开启药水掉落。
- 登场前留下的正常怪维持原来的完整掉落。Boss击败后正常结算。
- 拾取和全收经验均可触发原有升级与分支流程；升级继续暂停战斗，经验余量保留。仍为64级上限，经验曲线、尸潮密度、Boss血量和技能规则不变。

## 验证

TypeScript检查与333项测试通过。测试覆盖六个代表关卡的普通/援军/技能召唤/分裂掉落区别、药水边界、金币隔离、Boss战50→51级、63→64级、升级余量及满级不越界。原有转阶段、尸潮预算、进场提示与暂停测试保持通过。

额外整局模拟见 `artifacts/boss-xp-sim-report.json`；六局均通关：第11关50→56级、54→56级，第12关52→58级、52→57级，第13关51→56级、53→56级。这里只是固定种子的成长样本，不代表所有配装。不依据机器人战败降低难度，不把机器人通关率当真人胜率。
