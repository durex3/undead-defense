# 0.38.2 · 追猎穿刺切换修复

2026-10-21。用户反馈：选中飞刀「追猎穿刺」后仍绕着主角转。旧实现对已发刀阵保存了改造快照，选择追猎后还保留旧刀阵到本轮结束；四个品阶均可复现。受控复现中后续能正常远射，未把短暂延迟描述成永久失效。

现在通过Armory.onModification在实际选择成功后撤回已有绕身刀和未发出的旧刀阵快照，释放对应组预约，不触发取消组的碎刃、不额外造成伤害、不重置冷却、不赠送一轮攻击，也不清理其他武器。下一次原定攻击使用追猎快照。改造说明明确“立即撤回旧刀阵；下一轮远射”。4/8级改造节点、互斥、每局最多两改造及品阶价格均保持。

本轮沿用0.38.1已发布金币UI：战斗顶部生命旁显示账户金币，主菜单、选关和暂停页显示余额。
