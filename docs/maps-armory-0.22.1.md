# 0.22.1 双地图适配专属改造

2026-10-15。按确认方向保留铁棘围城/赤砂虫巢原有小怪、精英和Boss行为，调整地形、常规敌潮来向与路线提示。[布局图](../artifacts/maps-0.22.1.svg) 由真实碰撞配置生成，可用 `node tools/map-layouts.mjs` 重新导出。

## 设计原则

- 流派有空间优势，不要求唯一武器或配方。
- 地面持续区通过引怪受益，侧路来敌迫使玩家观察换线；不根据玩家武器或是否站定偷偷改变刷怪。
- 墙体仅阻挡移动，攻击和预警穿墙的既有规则不变。
- 起点、中央Boss区和所有侧路连通，所有障碍都有至少两个绕行方向，没有新增死路。
- 怪物数值、单波目标数量、威胁预算、全场上限、精英时间、休整窗口和8分钟Boss时间保持原规则。

## 第一关：铁棘围城

旧图四个相同大方块改成六段错位短墙：左右各两段竖墙，南北各一段横墙。中央保留半径6净空，西/东侧路中心(-15,0)/(15,0)与南北换线点(0,±9)保持连通。路径地砖标出这些方向，绘制尺寸和碰撞尺寸读取同一份配置。

短墙纵向尺寸5、厚度2.8—3；横墙长度6、厚度2。中央东西通路最窄15单位；南北横墙两端均可绕过，不能守住一个门堵住全部敌人。游侠基础移速4.62，中央与侧路之间约3.3秒，可主动换线而非瞬间转场。

常规步卒仍从两个方向来，30秒后按阶段将主要轴线从东西切到南北、斜向、东西、南北，并有小幅种子偏移。特殊敌人的盾弩组合、战犬绕侧、旗官与骑将行为继续沿用原导演。开局先学绕盾，随后横移躲弩线，再应对交错推进。

- 追猎/往返飞刀：沿墙端换线、切远程后排。
- 重爆火球：在队列汇合时输出；持续跑散会错失爆点。
- 火海/圣泉：引敌经过墙端或通路，需留意另一条侧路。
- 环绕/奔流：移动穿过中央，再借侧路脱离。

这些是优势而非通关条件；盾面减伤和撞墙恢复机制不变。

## 第二关：赤砂虫巢

旧图三个大岩块改成五个分散岩岛。左右主岩岛分别偏到(-10,3)/(10,-3)，上方岩岛变薄，另加西南/东北两块短岩台，形成西北—东南的斜向沙道。起点(0,-8)、中央和外圈地标均能互通。

主岩岛尺寸3.6×4.8，上方4.8×2.4，外侧4×2；任何岛都可从两侧绕行。三处巢纹仅用于辨认位置，不额外刷怪、不新增伤害或必须摧毁的任务物。

135秒前保持双路虫潮；135秒后双路与三路分组交替。三路各自留出间隔，最大22只常规波仍有超过90度的方向空隙；实际落点仍受屏幕边缘、玩家距离、地图边界和碰撞检查，找不到原方位时会转向合法位置，因而不保证每波视觉上严格呈三个等分扇区。分裂、喷砂、潜沙、孵巢、暴君和巢皇攻击均不改写。

- 碎焰/碎刃：处理分裂后的小群体。
- 奔流/回涌：跨岩岛转场时沿途清路。
- 固定水区/火海：绕岛聚拢敌群后引入；长期守同一块岛会错失远侧来敌。
- 重爆/追猎：抓滚虫撞岩与巢皇出土停顿，优先处理危险单位。

## 实现与验证

`SiegeMap.ts` / `SandMap.ts` 提供共享碰撞与绘制配置；`MapEncounters.ts` 只选择常规波空间方向，不参与怪物属性、数量、攻击预警或武器倍率。路线提示进入战斗HUD和关卡说明。

新增11项空间回归：玩家/大体型路径连通、所有路线间真实寻路、矩形碰撞一致性、障碍分离、中央净空、沙道线段净空、起点/巢纹合法、阶段空间节奏、50个不同地图位置与时间的刷怪落点、两关原始数值。旧滚虫撞墙测试根据新岩岛坐标更新，仍验证取消后续攻击并暴露护甲。

本轮全部229项检查通过，TypeScript严格检查通过。机器人通关观测仅用于发现卡死和运行异常，不能替代真人对流派优势、通关难度及手机发热的验收。新存档规则沿用0.22，不再次重置新版本进度。
