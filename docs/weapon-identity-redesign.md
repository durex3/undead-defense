# 十武器玩法与特效重新设计

日期：2026-10-19，最新修订2026-10-20。状态：基础机制、四十项改造接入及绘制已实现；平衡与真机手感待试玩。用户要求重新检查每种武器特点，并反馈幽灵、寒霜的效果与特效差，以及飞刀、长矛相似。

本文记录本轮武器重构方向；实际可运行行为以[当前基线](current-baseline.md)、`Armory.ts`、`ExtraArmory.ts`及配置为准。文中数值作为首轮调参起点已接入，不代表已经平衡或发布。实现结果与验证见[十武器重实现记录](weapon-reimplementation.md)。

最新规则优先见[四十项改造对照](weapon-modifications-guide.md)：飞刀改为四把实体刀持续环绕，取消本稿早期分段挥切、两刀及冷却空档描述。

## 设计边界

保留十把现有武器、每局最多四武器和四被动、六分钟进入Boss、武器八级及4/8级两次改造。每武器仍四种改造，其中一对互斥，保持五种合法双改造；下面逐项重订改造，不增加分支数量。保留武器与改造ID，变化在行为和说明；后续实现不得靠ID保留就假定旧数值仍适用。

不增加第十一把武器，不提前开放未来金币武器或最高成就，不调整已有解锁与关卡布局。所有武器自动施放，不新增瞄准、切武器或主动技能按钮。保持统一矢量墨线、深色外沿、大色面与明确动作，不能靠换色分辨十种相同光圈。需要玩法变化时在模拟层实现，Painter只读真实阶段与命中事件。

## 重构前实现的具体问题（保留诊断依据）

核查入口：`ArmoryConfig.ts`、`ExtraArmoryConfig.ts`、`Armory.ts`、`ExtraArmory.ts`、`SpellPainter.ts`、`ExtraSpellArt.ts`。

| 武器 | 已有实际特点 | 需要解决的问题 |
|---|---|---|
| 飞刀 | 周期1.6秒、双刀，默认每刀命中一人；猎手可穿两人 | 主刀同拍、窄角发射；造型实际是弯月，短刀身份不清，远看与其他亮色投射物接近 |

| 圣水 | 投掷到固定位置，0.4秒跳伤，持续封路 | 水区、火海、黑洞、冰环常以圈表达，持续伤害的来源和位置不好读 |

| 幽灵 | 每轮召唤2只，追到敌人命中一次后回收；盘魂才追加攻击 | 看起来像有脸弹体；目标死后继续飞旧位置，缺少替代索敌；绘制用a.angle但移动未更新它，尾迹方向可能错 |
| 骨矛 | 速度12、长直线、线段碰撞，一矛贯穿多目标 | 与速度11的飞刀速度接近，基础同样从角色发射；数量增加主要变成近似平行射线，重量与排阵价值不突出 |
| 地雷 | 后方布设，武装后由敌人触发，到期不爆 | 应明确武装/就绪/触发三态，不能画成又一个常驻伤害圈 |
| 黑洞 | 普通追兵聚拢、同步跳伤、结束爆发 | 功能独立，但要看得出敌人在向内移动，不能只看见紫色圈 |
| 圣剑 | 提前锁定落点，延迟后单次落剑，可十字/重落 | 应是抓停顿的重单点，不要变成频繁落下的另一种雷电 |

基础职责并非全部重复，但玩家看见的过程不足以支持这些差异。重构要同时调整机制、动作和反馈，不能将“有测试通过”等同于“体验好”。

数量成长：保留现有等级与数量被动规则。飞刀增加本轮绕身短刀（追猎为远射刀）；骨矛增加窄扇射线、绝不新增每矛穿透上限；寒霜增加同中心错开0.22秒的脉冲且不能绕过3秒冻结间隔；雷电增加不同落雷目标；幽灵增加同时在岗伙伴；其余增加主弹/水区/雷/核/剑数。子效果不再次读取数量生成后代。

幽灵在岗上限按现有最大8伙伴设计（基础升级到4、数量被动+2、群灵+2），超过已开放属性上限时需显式限流。其他实体仍受既有池容量约束，数量增加不允许无声截断施放。数量改变后的整轮时长必须小于冷却；冷却缩减和满数量极值要专测。

### 飞刀与骨矛：先解决基础手感重叠

用户追加决定：飞刀默认环绕自身，替代本稿初版的错时点射方案。两刀相位错开，位置随角色移动，半径1.9；每轮0.95秒内旋转一圈，每刀每目标最多一次，然后进入冷却空档。数量增加环绕刀；持续属性可延长在场，但最多冷却的85%。半径与碰撞宽度读取施放时范围快照。碰撞沿真实圆弧采样，不能用一条穿过角色的弦判定，不额外伤害空心中心。

`orbit` ID保留并重定义为“扩阵巡刃”：半径2.7、单刀伤害×0.8。`hunt`改为“离阵追猎”，替换整轮环绕而非额外免费发射，速度15、有限转向、最多穿两人。两者互斥；`return`使基础刀阵先扩大再收拢、分出回程命中段，猎手则锁定一次回收路线；`shards`仍每轮固定2子刃。默认飞刀无须升四级才有绕身身份。


骨矛在蓄力开始选方向：从玩家到候选敌人的方向中，选择射程内穿过可命中敌人数最多的一条，平局再取最近目标；最多检查当前100敌人，不能跨帧随机抖方向。方向锁定后0.20秒发射，蓄力时已有短杆和骨节收拢，发射瞬间长杆前顶。每矛对每目标一次，贯穿不衰减；不因敌人死亡弯向下一只。蓄力随角色移动，发射点读发射时角色位置；选线评分用蓄力起点，仅作选线建议，移动可能降低命中，这也是走位取舍。

### 寒霜：一次明确的结冰事件

基础施放后0～0.10秒地面快速生出分叉霜纹，仅为准备；0.10秒主爆在固定施放中心半径内结算一次，冰棱向上顶出；0.10～0.28秒为亮面与碎冰峰值，0.28～0.50秒消退。主爆之后进入区域的敌人不补主击，不把残留霜纹当持续伤害。数量新增的是独立错峰脉冲，每个脉冲也只有一次主爆。

主击附40%减速，时长保留现有duration；普通怪冻结0.75秒、精英0.25秒、同目标两类冻结均间隔3秒，后续命中只刷新减速。Boss、装置、正在冲锋的敌人仍不冻结或减速，照常受直接伤害。不能通过冻结取消已经发出的危险。冻结壳在敌人身上明确显示“谁被冻住”，结束壳破碎只作装饰，不带隐含伤害。

外扩改造替换主爆为0.10～0.60秒到达真实外缘的冰棱波，按扫过半径逐个结算一次；三相改造改为0.10/0.32/0.54秒三次扇区采样，同脉冲一个敌人最多主击一次；复震仍在施放0.8秒原中心结算一次、不冻结。所有采样需跨时间阈值处理，低帧率跳过视觉帧也不能漏伤或重复。

### 幽灵：有伙伴感的有限追猎

学习后生成固定在岗伙伴描述（非敌人、无碰撞、不挡弹、不承担仇恨），围绕角色侧后方小幅浮行；不是每轮增加永久单位。周期到达，分配不同可受击目标，依次离队；只有同一Boss时允许伙伴共同追击。优先级保持“基础最近，猎手优先精英/远程”。目标出场、潜沙、死亡或超追击范围时，在剩余追猎时间内最多重新索敌一次，不去扑空的旧坐标。

一次任务：出击追踪最多1.4秒；首次接触真实爪击16；0.22秒后第二次爪击16，第二击要求目标仍存活且在伙伴攻击半径内，不能隔空必中。第二击阶段可短追最多0.45秒，落空则回队；总任务上限3秒。盘魂替换第二次直扑：首次爪击后在锁定接触点0.9秒三跳，不追着敌人移动。归途在开始时只锁定一次玩家位置；到达锁点后切回驻队形态，驻队只是视觉归位，无伤害、无无限追踪。

周期到达但所有伙伴未回队时不复制伙伴、不累积补发；下一次任务需伙伴回队且周期到达。每个伙伴携带当前任务参数快照，任务中升级只影响后续任务。伙伴数量增加在下一轮调度生效；不会让新伙伴抢占旧任务目标。归途收割仍每伙伴每目标每回程一次。

盘魂倍率改成70%单爪是因为基础任务改为两爪：不能把旧“24伤主击+3次35%”原样移植到“16伤双爪”后导致改造反而丢失大量任务伤害。目标站在盘旋范围的理论收益由32变为(16+3×11.2)×0.8=39.68，站不住则收益下降。猎手与群灵用每任务总伤害、追击时间、覆盖目标数一起验收，不能只看单次倍率。

表中世界像素按48像素/单位绘制，游戏缩放后仍需在844×390画面复核；长矛杆和幽灵衣摆不是碰撞范围。所有装饰不得暗示额外可伤区域，实际边界/宽度通过施法刻痕与真实命中对应。色彩是辅助，去色后也要认得短刀、长杆、伙伴、冰冠、落雷、重剑。

普通模式每把武器单次装饰优先控制在少量合批提交，省电减少尾迹/碎屑/内部刻纹，保留真实攻击阶段、目标方向及控制状态。继续沿用既有实体池、128粒子槽及45,000近似顶点预算；敌人预警始终最后绘制。主角定位线保留，不能靠放大十种武器特效遮住敌人动作。

## 数值比较与验收

不将一级纸面DPS当作平衡结论。对十武器分别采样1/4/8级，控制角色、被动、敌人生命、地图、随机种子及同一时段一致；四级/八级覆盖基础、单改与合法双改。无被动基准与“伤害/冷却/数量/范围/持续全满”的极值分开，实际四槽组合另测。

固定六种场景：单体移动精英、低速Boss、分散8敌、直列8敌、密集团8敌、贴身四面包围。每种场景持续30秒，开局冷却一致；记录真实伤害、有效命中、过量伤害、空放、目标死亡后浪费、冻结有效时间、遭接触次数、近身脱围成功率以及峰值在场实体。控制收益与聚怪收益单列，不能为了伤害表好看把每把武器都调成爆炸。

候选目标：飞刀在分散近敌的响应快于骨矛；骨矛的直列总伤高于自身分散场景；幽灵对移动目标的有效命中率高于锁点圣剑；寒霜明显增加包围场景的脱围窗口；圣剑在静止单体上优于移动单体；地雷需要引怪才收益，黑洞在可牵引群体才有优势。若某把在单体、分散、密集、解围均领先，先削覆盖/频率，不能保留为万能答案。

回归必须覆盖：错时飞刀换目标及发射点；骨矛贯穿去重与高速线段碰撞；寒霜主爆只结算一次、迟到者不吃旧主击、扇区跨帧、冻结间隔/免疫；幽灵目标死亡重索敌上限、二爪接触条件、三秒任务上限、固定回收点、伙伴不复制；其余武器原有同源重叠、有限复击与池容量不退化。所有伤害结果在30/60Hz及短暂低帧率下允许时序采样误差，但不能漏段或递归重复。

画面验收：先做十武器一级无改造原尺寸动图，隐藏武器名字和颜色后能区分攻击身份，再做4/8级改造和四武器混战。至少组合飞刀+骨矛+幽灵+寒霜，以及火球+圣水+黑洞+圣剑，确保近似武器能同时读清。三四关双危险、完整HUD和微信真机还需真人验收；离线Painter截图与构建成功只算工程证据。
