# 武器系统重设计 v1：基础武器、统一属性、单一进化

状态：历史方案，已由[行为改造方案 v2](weapon-system-redesign-v2.md)替代。2026-10-15。

本文只提出方案，尚未删除或替换当前武器代码。所有初始数值均为候选值，未经过新体系实战验证。

## 1. 这次要解决什么

现有18把武器、每把两个分支、9组武器组合及额外联动，叠加独立武器特例和角色专精，已经超过玩家能直观理解的范围。主要表现是：

- 不知道“拿到搭配”“选择分支”“形成超武”分别意味着什么。
- 满级后攻击行为改变，感觉伤害、覆盖或压制力退回低级。
- 不清楚属性是否影响某把武器，升级只能靠猜。
- 多层控制叠加后容易站定通关，与两关机制压力相冲突。

新体系的玩家说明只需要三句话：

> 武器决定怎么攻击，被动决定哪些属性更强。
> 每把武器升到8级，拥有对应被动就自动进化。
> 进化不吃装备、不占新槽位，每把只有一种终极形态。

## 2. 借鉴什么，做哪些调整

《吸血鬼幸存者》的普通进化常见条件是武器满级、拥有对应被动，再通过宝箱获得进化；被动物品提升角色属性。这些规则存在武器及版本例外，本文不照搬全部系统。[武器及进化说明](https://vampire-survivors.fandom.com/wiki/Weapons)、[被动物品说明](https://vampire-survivors.fandom.com/wiki/Passive_items)。

我们借鉴“武器攻击方式＋共享属性＋单一进化”的结构，做以下调整：

|项目|本游戏方案|目的|
|---|---|---|
|武器池|首版10把，单局最多6把|先减少重复玩法|
|被动池|8种，单局最多4种|让属性有取舍，控制信息量|
|武器等级|1—8级|让每级变化明确|
|被动等级|通常1—4级；数量类1—2级|避免升级没有实际变化|
|进化条件|武器8级＋指定被动至少1级|全武器同一套条件|
|进化触发|满足后立即自动进化|不用找宝箱，不再询问分支|
|进化消耗|不消耗武器或被动，沿用原武器槽|杜绝槽位和配方歧义|
|关卡|仅铁棘围城、赤砂虫巢，保留现有强度|让配装服务于走位与反击|
|角色与成就|保留三个角色，不恢复成就|不增加新的养成层|

删除双分支、武器与武器融合、额外组合触发伤害、组合目标选择器，以及“保留联动”概念。系统统一使用“进化”这个名称；不再同时出现分支、组合超武、联动三套分类。

## 3. 基础武器与唯一进化

所有武器自动攻击。玩家负责移动、选装、拾取和判断反击窗口；不增加手动瞄准按钮。

|基础武器|普通形态与定位|主要弱点|指定被动|唯一进化及变化|
|---|---|---|---|---|
|环绕飞刀|短距离绕身切割；清理贴身追兵|不能稳定打到远程后排|复刻指环|**绞肉刀环**：更宽的旋转刀圈，更稳定的近身覆盖；保留攻击间隙|
|烈焰火球|向密集敌群发射火球并爆炸；远程清群|飞行与爆炸有延迟，难追高速敌人|力量徽记|**豪火球术**：火球变大，爆炸附短暂燃烧；仍按周期发射，不变成持续全屏火雨|
|冰霜新环|间歇脉冲伤害与减速；帮助脱离包围|输出偏低，脉冲之间不能保护玩家|广域烛台|**寒潮脉冲**：两道扩散冰环，小怪短冻；两道环共用一次冻结限制，不形成永久冰冻|
|连锁闪电|自动选近处危险敌人，再向邻近敌人跳跃；打散紧密阵型|跳跃需要目标邻近，分散怪群效果较弱|疾咏沙漏|**雷霆审判**：主击增强，末端雷爆；不附加冰属性伤害|
|幽灵伙伴|幽灵周期出击并返回；追踪远程与精英|输出有往返周期，近身清围能力有限|长效符文|**幽魂军团**：更多幽灵分批出击，已锁定目标死亡才改选；攻击和返回阶段清晰|
|圣水瓶|向敌群前方落瓶，形成持续伤害区；引怪进入封锁带|水区固定，转场后需要重新铺设|拾魂吊坠|**净化圣泉**：水区缓慢向玩家靠近并逐步扩大；不瞬移贴身，不产生永久安全圈|
|骨矛齐射|自动朝危险敌人方向发射穿透骨矛；直线破阵|对侧后方缺少覆盖|复刻指环|**白骨贯阵**：更宽骨矛、多线穿透；仍依赖方向，不追加跳弹规则|
|雷霆地雷|沿移动路线留下陷阱，短暂布设后触发；撤退反击|敌人不踩就没有伤害，站定只能有限铺设|生命护符|**连爆雷阵**：爆炸触发附近已布设地雷；每颗每轮只触发一次，不重复连锁|
|黑洞印记|在敌群处短暂聚拢普通怪并持续伤害；配合区域输出|自身伤害偏低，不能牵引精英或首领|长效符文|**吞噬漩涡**：引力范围扩大，结束时爆发；漩涡之间有明显空档|
|圣光柱|向危险目标落点投下圣剑；定点爆发|落点提前确定，高速目标可能走出范围|力量徽记|**裁决圣剑**：更强主剑和少量副剑覆盖邻近敌群；保持落剑预示，不连续覆盖整个屏幕|

选敌规则公开且稳定：幽灵、骨矛、圣光优先附近精英/首领，其次远程，再次最近敌人；火球、圣水、黑洞优先密集怪群；闪电优先附近危险目标后跳跃；飞刀与冰环以玩家为中心，地雷以移动路线布设。攻击不依赖玩家朝向，不出现敌人在右边却一直向左攻击的情况。

同一被动可以作为多把武器的进化条件，但不会让这几把武器互相触发额外伤害。拿到被动时只获得其属性，不会提前获得终极技能。

### 现有18把武器的去留

|现有武器|处理|
|---|---|
|飞刀、火球、冰环、闪电、幽灵、圣水、骨矛、地雷、黑洞、圣光柱|保留题材，按上表重做规则与数值|
|回旋镰刀、回旋战斧|首版移除，两种往返刃器暂不与飞刀/骨矛并列堆数量|
|毒雾尾迹|首版移除，持续区域伤害交给圣水，沿路反击交给地雷|
|噬魂蝙蝠|首版移除，追踪召唤交给幽灵，暂不做自动吸血武器|
|火焰锁链、灵魂锁链|首版移除，不再并列多个持续锁敌和束缚系统|
|亡骨图腾|首版移除，召唤定位先由幽灵承担|
|灾厄陨石|首版移除，远程爆炸与落点爆发分别交给火球、圣光|

“移除”指不再出现在新武器池及配方中；可复用旧图形素材，但不保留其旧数值、分支或联动逻辑。

## 4. 被动装备与统一属性

被动默认对本局所有适用武器生效，角色加成也走同一属性计算。界面必须显示适用武器；不适用时不能制造升级效果。

|被动|各等级效果|最高级|进化用途|
|---|---|---|---|
|力量徽记|伤害+10% / +20% / +30% / +40%|4|火球、圣光|
|疾咏沙漏|攻击冷却−6% / −12% / −18% / −24%|4|闪电|
|广域烛台|攻击范围+10% / +20% / +30% / +40%|4|冰环|
|长效符文|持续时间+10% / +20% / +30% / +40%|4|幽灵、黑洞|
|复刻指环|攻击数量+1 / +2|2|飞刀、骨矛|
|风行靴|移动速度+8% / +16% / +24% / +32%|4|无，纯走位选择|
|生命护符|最大生命+15 / +30 / +45 / +60|4|地雷|
|拾魂吊坠|拾取半径+20% / +40% / +60% / +80%|4|圣水|

以上为相对基础值的累计加成，不是每级再叠一次表内数值。生命上限提升时当前生命增加同样点数，保留已损失生命差值；不是按百分比额外回血。拾魂吊坠不增加经验总量。

**范围一律指线性尺寸**：圆形增加半径，刀刃增加宽度，爆炸增加半径。界面写“攻击范围”，详情明确“半径/宽度”；+40%半径意味着面积约为1.96倍，平衡测试必须按这个结果评估，不能当作面积仅+40%。

暂不引入暴击、幸运、诅咒、经验倍率、收益倍率、额外护甲、随机触发率和局外永久属性树。弹速、穿透次数、击退强度作为武器自己的属性，通过武器升级改变，不再为每项单开被动。

### 属性适用表

所有武器均受伤害与冷却影响；角色移动、生命、拾取属性与武器无关。其他属性如下：

|武器|攻击范围|攻击数量|持续时间|
|---|---|---|---|
|飞刀|刀刃与环绕半径|刀数|不适用|
|火球|爆炸半径|每轮火球数|进化后的燃烧时间|
|冰环|脉冲半径|不适用|减速/冻结时长，受控制上限约束|
|闪电|末端雷爆范围，仅进化后|首击链数，不增加每链跳跃数|不适用|
|幽灵|命中范围|出击幽灵数|出击阶段时长，不延长无输出返回阶段|
|圣水|水区半径|每轮瓶数|水区存在时间|
|骨矛|矛宽，不扩大射程|每轮矛数|不适用|
|地雷|爆炸半径|每轮地雷数|未触发地雷保留时间|
|黑洞|引力与伤害区半径|不适用|漩涡存在时间|
|圣光|落剑伤害半径|每轮落剑数|不适用|

复刻指环只强化表中适用武器，永不增加冰环和黑洞数量。多个幽灵/火球/落剑合理分配目标，不把新增数量全部打在已经必死的同一个普通怪上。

同一类加成相加，跨维度效果各自结算：最终单次伤害＝武器当前等级基础伤害×（1＋角色伤害加成＋装备伤害加成）。最终冷却＝武器当前等级基础冷却×（1−总冷却缩减）。不再额外乘旧rankDamage或隐藏角色专精倍率，避免重复放大。

候选安全上限：总冷却缩减40%，移动加成40%，范围加成60%，持续时间加成60%，伤害加成60%。数量不再接受其他叠加来源，每轮最高为武器基础数量＋2；进化自身数量变化已写入其基础数量，不作为隐藏第三种加成。

控制上限独立于持续属性：普通怪同目标冻结至少间隔4秒、单次最多0.8秒；精英单次最多0.2秒、至少间隔6秒，冲锋阶段免疫；首领不冻结、不被牵引，减速最多10%。已锁定预警不能因受控反复重置或消失。

## 5. 武器升级与进化

### 普通升级

1级就完整展示攻击方式；2—8级强化同一套玩法，不到满级突然从环绕改成远程、从追踪改成随机。每级只调整1—2项玩家能理解的内容，每次选择必有实际收益。

以飞刀为例，下面是不含角色和被动的候选升级表：

|等级|单次伤害|刀数|攻击周期|变化|
|---|---|---|---|---|
|1|8|2|1.6秒|基础环绕攻击|
|2|10|2|1.6秒|伤害8→10|
|3|10|3|1.6秒|刀数2→3|
|4|10|3|1.4秒|周期1.6→1.4秒|
|5|13|3|1.4秒|伤害10→13|
|6|13|4|1.4秒|刀数3→4|
|7|16|4|1.4秒|伤害13→16|
|8|16|4|1.2秒|周期1.4→1.2秒|

进化后：候选单次伤害20、基础刀数4、攻击周期1.2秒，刀圈更宽；复刻指环照常提供额外1—2把刀，不重复计算。每轮刀圈存在时间候选0.65秒，不受持续时间加成，以保留输出间隙。单把刀对同目标每轮只命中一次。

其他武器沿用“伤害、数量、冷却、武器特色”交替成长的原则，但不强行每把武器都加数量。正式实现前补齐另外9把的逐级参数表与命中规则，不能只换名字或共用一个总伤害倍率。

### 自动进化

- 每次装备或升级后检查：该武器8级，指定被动至少1级，且未进化。
- 满足即自动完成；先拿被动或先把武器升满都有效。
- 同时满足多把，全部完成；不随机选一把、不要求下一次升级再出现进化牌。
- 被动只需持有，不要求满级；被动不会消失，武器槽不会腾空。
- 简短显示“环绕飞刀 → 绞肉刀环”，不增加需要确认的弹窗。
- 底部名字、图标、暂停详情、结算统计同时切换成进化武器。
- 进化保留当前冷却进度，不重置到低级或借机免费触发一轮攻击。
- 已在场的旧弹体完成自己的生命周期后释放，新攻击使用进化形态；基础武器不会继续作为第二套技能暗中施放。

进化必须保持8级已有的基本攻击能力，并增强一个清晰卖点。伤害、覆盖和攻击间隔分别验证，不能只看总DPS提高，就允许原来的稳定命中变成大部分攻击落空。

## 6. 单局成长、抽选与槽位

保持开局三选一武器、玩家上限64级、8分钟迎战首领，Boss战继续获得经验。经验需求从开局逐级增加，不通过加经验倍率让玩家提前满级。

6把8级武器共48次获取/升级；4个4级被动共16次，合计64次选择。开局提供一次，之后最多63次升级，理论上恰好能全部升满。若选择2级封顶的复刻指环，总需求减少2次；选药剂会占用成长机会，因此不承诺每局必然满配。进化不额外消耗升级次数。

候选节奏目标：2分钟初步形成3—4把武器；3—5分钟出现第一把进化；6—8分钟形成主要配装但仍有成长空间；不以5分钟全满64级为正常节奏。以上是待测试目标，不是自动赠送等级或固定发牌时间。

三选一候选按类别权重抽取：已有武器升级55、新武器20、已有被动升级15、新被动10。先按合法且非空类别归一化抽类别，再从类别内均匀抽一张，不放回直到3张；绝不把类别权重误当成每张牌权重。槽位满、等级满或已经进化的物品不再进入对应候选。

- 选过的物品没有下一次必出保证。
- 不强制每次都出现新武器，也不保证配方被动必出。
- 配方缺件只做提示，首版不暗中提高其权重。
- 保留每局3次重抽；重抽仍遵守槽位和等级限制。
- 合法成长项不足3个时按实际数量显示；全部成长项完成后才进入补给选择。
- 非满血且没有成长项时提供回复20生命；满血且没有成长项时显示“继续战斗”，不会只给一张无意义血瓶。
- 暂不加入无限突破、商店出售随机成长等级、场景额外被动槽等例外，避免升级规则再次分叉。

四个被动槽意味着不是任意六把武器都能全部进化；六把普通武器都能升到8级。配装页提前标注缺件，玩家可选择共享进化被动的武器来节约槽位，或者牺牲一把进化换风行靴。未进化的8级武器必须仍可承担自己的战斗职责。

## 7. 界面怎么让玩家看懂

### 三选一

顶部分两行：6个武器槽、4个被动槽。显示当前图标、等级以及进化状态，空槽也可见。

卡片示例：

> 环绕飞刀　Lv.2 → Lv.3
> 刀数 2 → 3
> 进化：8级＋复刻指环　✓ 已拥有指环

新武器卡显示“一句话攻击方式＋基础数值＋进化条件”；被动卡显示“冷却−12%→−18%”，附当前装备中受影响的武器图标。没有相关武器时说明“当前无适用武器”，不阻止玩家为后续配装提前选择。

### 标识与详情

普通武器使用普通图标；进化武器使用专属图标并加统一金色进化标记。图标、名称、文字共同传递状态，不能只靠颜色。8级但缺被动显示“8级·待进化”，与“已进化”区分。

暂停点击武器：攻击方式、当前实际伤害/冷却/数量、适用属性、唯一配方。暂停点击被动：当前加成与影响哪些已装备武器。属性面板只显示伤害、冷却、范围、数量、持续、移动、生命、拾取8项，不把每把武器的弹速/穿透混进全局属性。

结算展示10种武器对应的实际基础/进化名字、伤害、击杀；删除联动伤害和联动触发次数，不重复统计。

## 8. 三个角色如何接入

仍保留游侠、炼金术士、亡灵使者。为避免删掉旧武器后出现无效专精，建议将原来逐武器加成一起改为简单的全局属性：

|角色|候选被动|定位|
|---|---|---|
|飞刀游侠|伤害+10%，移动速度+10%|走位与直观输出|
|炼金术士|攻击范围+15%，持续时间+15%|区域与持续效果|
|亡灵使者|冷却缩减8%，拾取半径+20%|攻击频率与拾取|

角色不决定进化配方，不绑定开局武器。每个角色都能使用全部武器，适用限制仍以属性表为准。角色加成与被动装备合并后应用总上限。

解锁沿用当前两关方案：游侠初始开放，通关铁棘围城解锁炼金术士，通关赤砂虫巢解锁亡灵使者；已有角色继续保留。此处为随武器重做的建议，不表示现有三个角色被动已经被修改。

## 9. 配装例子与两关定位

**移动清路**：骨矛、飞刀、火球、闪电、地雷、圣光；被动选复刻指环、力量徽记、疾咏沙漏、风行靴。进化骨矛/飞刀/火球/闪电/圣光，地雷普通8级；适合清线后切到旗官和弩兵侧面，不能靠飞刀抵挡锁定预警。

**引怪封路**：圣水、幽灵、黑洞、冰环、火球、骨矛；被动选拾魂吊坠、长效符文、广域烛台、力量徽记。进化圣水/幽灵/黑洞/冰环/火球，骨矛普通8级；持续换位置将虫群带入水区，黑洞不能吸住暴君或巢皇。

例子展示槽位取舍，不代表最优解或推荐玩家固定抄作业。两关不设计为某一套配方才可通关；合理配装应降低清路压力，但盾弩夹击、连续钉地、折返滚虫和首领连续攻击仍要求走位。先保持关卡原参数，通过新武器实测再讨论调数值，不能暗中降关卡难度补偿重做。

## 10. 存档与替换边界

- 继续保留角色解锁、关卡14/15稳定内容ID对应的新显示1/2、历史最高记录和主备份机制。
- 原成就继续仅作旧档兼容数据，不恢复任何成就功能。
- 新武器/被动/进化使用新的明确ID与规则版本，不复用旧fire.meteor之类有歧义的分支ID。
- 旧进化记录存入历史兼容字段，不自动兑换成新武器、不自动给予局外属性，也不作为新体系解锁条件。
- 新规则上线后重新开始战斗；本项目没有可续玩的局内存档需求，不承诺把一局旧双分支配置转换成新配置。
- 存档迁移先验证主档与备份，生成新版本数据后再写入；写入失败保留内存进度并重试，不能清空旧档。保留可读备份并验证回退。
- 旧配置文档标记为历史版本。新的代码不同时运行旧分支/组合系统和新进化系统。

## 11. 开发顺序与验收

1. 审阅本文，确定武器池、被动槽数和自动进化规则。
2. 补齐10把武器逐级参数、进化参数、命中间隔与对象上限；这些参数仍需实测调整。
3. 先做统一属性计算、合法候选生成和进化状态机，再做飞刀/火球/圣水的完整样本。
4. 验证成长连续性和界面后，迁移剩余7把；彻底移除旧分支、配方、联动计算和相应界面。
5. 同步角色属性、存档迁移与结算统计，完成两关完整试玩和手机测试。

验收至少覆盖：

- 所有10把武器的每级收益真实生效；8级和进化不会退回低级数值。
- 按两种拿取顺序均能自动进化，多把同时满足时全部处理，不耗伙伴、不占新槽。
- 属性适用矩阵逐项检查；不适用属性无隐藏收益，同一伤害倍率不会重复计算。
- 六武器四被动的候选始终合法；满级、满槽、缺配方、重抽和全满状态均有正确表现。
- 幽灵/骨矛/圣光不会持续反向攻击；范围图形与真实判定一致。
- 同种持续区域对单个敌人的叠加有明确命中规则，不靠重叠无限叠伤害；正式参数表逐武器定义。
- 每关以多套合理配装进行移动与站定对照：移动配装存在可完成样本，站定不能稳定通关首领；不把机器人失败直接当作需要降低难度。
- 角色、旧14/15关成绩、备份恢复、写入失败和旧进化历史迁移不丢数据。
- 3倍速按固定模拟步长结算；攻击对象池满时延后整次施放，不覆盖未结算伤害；限制纯视觉粒子不削减实际伤害。
- 中端手机实测帧率、持续发热与密集场景；桌面网页通过不等同真机性能达标。

本稿明确不承诺：首轮数值已经平衡、任意配装都能六把进化、玩家一定在首领前满64级。下一步应先确认结构，再制作可测的完整参数表，而不是一次堆入更多武器。
