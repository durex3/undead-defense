# 0.21.0 两关重排与移除成就

当前冒险仅开放两关：第1关铁棘围城（原14关），第2关赤砂虫巢（原15关）。所有生命、伤害、经验、刷怪时间和敌人/Boss行为保持原样。其他关卡移出选关和解锁流程。

内容内部仍使用稳定ID14/15，显示编号由关卡顺序产生，避免旧第1/2关成绩被误认成新关卡成绩，且不改变所有按内容ID执行的战斗规则。旧关卡配置和机制仅作历史兼容及回归资料，不属于当前可玩关卡列表。

成就列表、入口、快捷键、奖励判定、结算提示和解锁门槛移除。旧成就ID只用于读取旧存档并保护已有角色访问权，游戏不再生成新成就。

新存档初始开放游侠与铁棘围城；通关铁棘围城开放赤砂虫巢和炼金术士；通关赤砂虫巢开放亡灵使者。已有解锁不撤回，旧v1/v2角色迁移阈值维持原样，旧v3已经满足解锁条件但尚未写入解锁列表的角色也补全保存。迁移只新增角色，不抹除任何已获角色。

沿用原存档键、备份和版本读取规则。保留旧关卡成绩、旧成就、历史最高记录、进化记录与角色通关记录。旧14/15关成绩直接对应新显示第1/2关；旧1—13关记录不用于新关解锁，不在当前界面展示。读取选择最高有效revision，错误主档回退备份，写入失败保持内存进度并重试。

删除15项过时的旧关卡解锁/成就测试，替换为7项新流程与迁移测试；战斗机制回归测试保留。383项测试与TypeScript检查通过。验证新存档、旧v1/v2/v3、旧1/2关防串档、旧14/15成绩、备份恢复、写入失败与重复观察。

本次未修改武器的分支/超武结构，武器简化仍待确定方案。尚未提交或上传微信后台。
