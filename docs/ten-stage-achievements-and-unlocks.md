# 十关成就与武器解锁建议

本文为早期提案，数量、价格、挑战与成长规则已由[十关武器品阶与成长系统设计](ten-stage-progression-design.md)取代。后续开发以新文档为准。

2026-10-20。状态：基于0.32.0十关开发版的**设计建议，未新增运行时成就、商品或武器**。当前仍为十二把已实现武器、四项成就；第十关开发与诊断见[实现记录](stage-10-implementation.md)。本文建议下一批做到**16项成就、14把武器，其中10把默认开放、4把通过金币或成就解锁**。不是新增14把，也不把原有十把重新上锁。

## 最新确认：三条成长路线并存，升级采用新形态

用户已要求开发本批内容，并进一步明确：金币购买、成就解锁、金币升级三条路线并存。金币升级将已拥有武器进阶为同类型的新武器，具有新的名称、外形和更高伤害，保留原武器的核心攻击特点。不是只有百分比加成的强化按钮。此节优先于下文早期提案中的「不把金币直接换成永久攻击力」等限制；运行时尚未实现这些新增内容。

- 金币购买：保留重锤与候选引魂灯；成就解锁：保留飞轮与候选缚影缝针。进阶是取得武器之后的成长，不取代两种获取路线。
- 同一武器系列在随机池只占一个位置。进阶后用新形态替换基础形态，不同时投放基础版与进阶版，不额外占武器槽、不提高该系列的抽取权重。
- 进阶购买在局外生效于下一局，展示具体新形态和收益后扣款；不在战斗中购买并改变当前伤害。仍保留局内1～8级成长与合法改造。
- 同类型的含义是保留攻击方式与职责，例如重锤继续使用慢速重击与裂甲。新形态需要可识别的轮廓和攻击特效变化，并提供实际伤害提升；名称、配色变化不能单独算完成。
- 每个系列先规划一条基础形态到进阶形态的路线，不一次增加多段进阶或分叉。具体名称、形态、数值和价格需随武器规格确定；此前口头提出的180/360金币及8%/16%加成不作为已确认配置。
- 图鉴分别统计武器系列与进阶形态，不能把形态当成额外随机武器。已拥有和未进阶状态必须清楚展示，购买、成就和进阶记录均兼容旧存档。

成就方面，用户指出原挑战条件偏容易：十项通关记录与挑战成就应明确区分，挑战要求需要提高。三阶段各踩签等条件仍需核对实际触发机会，尚不能把对话中的举例当成已经实现的判定。

验证以机制正确、运行稳定、存档和消费正确为主；不要求自动玩家通关作为发布门槛。机器人胜负仅作为平衡参考，真人难度由实际试玩判断。

## 1. 为什么先增加两把

现有十把默认武器已经覆盖环绕、爆破、持续封路、冻结、连锁、伙伴、贯穿、布雷、聚怪和锁点裁决；重锤与飞轮补近侧/中距裂甲。十关不需要每关再塞一把同类武器。

[第九/十关诊断](../artifacts/library-stage/simulation.json)中，满级四武器输出诊断第十关均能过三阶段Boss，基础组合约100秒，含重锤/飞轮约58～61秒；但正常生命、随机选卡、有限0.6秒预测的机器人，第十关十二局为6胜、6局900秒仍战斗。基础池三局为2胜、1局未结束，通关样本约718/817秒。部分样本未取得力量等输出被动，机器人选卡与走位也不是最优策略。这说明装备成长与输出差距仍需调优，不能解释成「必须再解锁更多强武器才能玩」。

建议下一批只增加两种职责清楚的新武器，先把现有厚甲/输出/恢复窗口调好。14把是当前十关批次的目标规模，不是以后永远不能增加。

开局三选一目前从已解锁池均匀不放回抽取。某一把指定武器进入开局选项的概率，在12/14/16把全解锁时分别为25%/约21.4%/18.75%；这只是开局展示概率，不是整局获得率。四武器的无序组合数从12把时495种变为14把时1,001种，16把时1,820种，未计算改造与被动，验证成本已经很高。先做两把并保留随机，不添加指定、保底或强制配装门槛。

## 2. 四把解锁武器的获取分工

|武器|状态|获取路线|建议条件/价格|节奏与职责|
|---|---|---|---|---|
|镇钟重锤|已实现，保留|金币|360金币，足够即可买|近侧慢重击与裂甲，现有条件不变|
|裂甲飞轮|已实现，保留|成就|原「破阵熟手」自动解锁|中距去回贯穿裂甲，不追溯收回|
|引魂灯（暂名）|下一批候选，未开放|金币|720金币，足够即可买，不叠通关或成就门槛|弱输出的定点支援区，改善持续输出窗口；不是治疗或另一种水瓶|
|缚影缝针（暂名）|下一批候选，未开放|成就|新「解签留路」自动解锁，不再付金币|敌人配对与有上限的伤害转递，提供群体/单体目标选择|

金币路线两把、成就路线两把，目的不同，不对同一商品同时要求钱和挑战。通关、成就数、图鉴比例、上述任何武器都不是关卡入场条件。

新两把只有完成动作、八级成长、四改造、五种合法双改、真实特效与验证后才开放。本文只确定角色和获取方式，具体伤害/周期/转递上限另写武器规格并实测；当前不能购买、抽取、使用或领到不存在的武器。

### 引魂灯的职责边界

自动在近侧敌群边缘放置一处固定灯区，短时间给区内有限目标附加不叠层的「烙魂」，使友方对这些目标的有效输出略提高。自身伤害低，占一个真实武器槽；一名玩家同时最多一个灯区。离区标记短暂结束，不能永久铺满地图。

它的价值是帮助已有主力武器利用Boss恢复期与清群窗口。不开回血、无敌或减速，不增加经验/金币掉率，不代替裂甲；不能把所有连锁、持续、派生伤害各自再乘一次。暂定只有一个全局标记倍率入口，和护皮/裂甲/恢复增伤按固定次序各结算一次，具体倍率以测试为准。

若最终只是「换色圣水＋更高数字」，撤销该武器方案，不为凑14把硬做。

### 缚影缝针的职责边界

周期性选取两名附近敌人，短时建立一条可读的缝线；命中一端时，有限的一部分伤害转递给另一端。连接的是两个敌人身份，不是复制骨矛直线或飞轮弹道；每次最多一对，距离过远、死亡或持续结束就断线，不无限续接。

转递必须有独立间隔、单次与整段上限，不能递归触发自身，也不再触发其他命中派生、吸血或击杀收益。派生伤害归属缝针，不能把普通小怪的低剩余生命当作对Boss无限增伤入口。只有一个目标时仍有低强度基础针击，不要求Boss必须召唤小怪才有用。自动目标选择不得连中无敌、未登场或已死亡目标。

这是职责提案，尚不是可实施数值表。若测试显示转递很难解释或在Boss援军上失控，应缩减为固定伤害的有限传导，不能直接扩大危险/特效预算。

## 3. 成就规模：16项，保留四项旧ID

结构为10项通关记录＋3项机制掌握＋3项配装探索。通关记录让每关都有回应；机制和配装条目让玩家尝试不同打法。只给两个成就武器奖励，其余是可查看的图鉴完成章，不加永久属性，不额外重复发通关金币。

### 十项通关记录

|关卡|名称建议|完成条件|兼容方式|
|---|---|---|---|
|1 铁棘围城|围城初破|正常结算通关1|可据现有合法通关记录补标|
|2 赤砂虫巢|赤砂脱困|正常结算通关2|同上|
|3 雷铸机庭|雷庭止鸣|正常结算通关3|独立于「破阵熟手」，不要求满级改造|
|4 苍棘猎原|逐月归来|正常结算通关4|可据现有合法通关记录补标|
|5 灰烛钟庭|钟庭来客|正常结算通关5|保留`bellcourt_clear`|
|6 锈潮船坞|潮间过客|正常结算通关6|保留`tideworks_clear`|
|7 折晶矿窟|棱间行者|正常结算通关7|保留`prismvault_clear`|
|8 蚀根温室|温室回生|正常结算通关8|可据现有合法通关记录补标|
|9 断羽风廊|借风过廊|正常结算通关9|不把借风位移量叠到通关章条件|

以上奖励均为图鉴完成章。第十关不是全部游戏的最终关，不命名为「毕业」「终章」或最高成就，也不预排后续全部关卡。

### 三项机制掌握

|名称/ID建议|可直接判断的条件|奖励|设计理由|
|---|---|---|---|
|破阵熟手 / `forge_mastery`（已有）|通关第3关，结算时至少一把武器8级且有两项合法、不互斥改造|现有裂甲飞轮|保留旧条件和旧完成状态|
|拆阵有方 / `device_tactician`|同一局第3关，亲自摧毁至少2个实际生成、可受伤的电锚/电极，并最终通关|机制完成章|鼓励先拆装置；不要求特定武器、无伤或击杀限时|
|解签留路 / `seal_pathfinder`|同一局第10关，成功踩断至少2枚不同危险ID的未释放封签，其中至少1枚属于Boss，并最终通关|候选缚影缝针，完成实现后才开放|两枚无需同一招、无需同一阶段，也不用两签全踩；展示新反制选择|

「亲自摧毁」仅计友方造成的真实击杀，不计自然到期、主人死亡撤销、阶段清除或调试删除；「成功踩断」只计实际撤销的危险，不计走过已释放的灰签、重复接触同一ID或冻结/击杀替代撤招。

不做“风里站满N秒”“故意留活精英”等鼓励拖延或挨打的成就，也不在三阶段Boss上强行追加无伤、低血量、极短限时或必须指定武器。

### 三项配装探索

|名称/ID建议|条件|奖励|边界|
|---|---|---|---|
|双核成形 / `dual_mastery`|任意一局通关，结算时至少两把武器8级，且各完成两项合法改造|配装完成章|不要求四把全满、固定角色或指定武器；现有随机成长可逐步达到|
|三路起手 / `three_openers`|累计以任意3种不同开局武器完成通关|配装完成章|任意三种，不指定清单；重复相同起手只算一种；开局武器以实际三选一结果为准|
|改造异途 / `modification_paths`|同一把任意武器，分别以两种不同合法双改造组合完成过通关|配装完成章|一局最多提供该武器当前组合；组合顺序无关，A+C与C+A相同；不能用一次换卡伪造两次通关|

不要求12/14把全收集才算完成，不用一项武器解锁去卡另一项武器解锁，也不要求抽到刚开放的新武器才能拿普通通关章。

16项中，当前4项是3个通关章＋1个成长掌握；因此下一批实际新增12项，而不是再叠16项。现有武器持有者不被重新上锁，旧成就进度不归零。

## 4. 金币节奏

沿用每次通关固定100/120/140/160/180/200/220/240/260/280金币，没有首通倍奖或每日限额；失败与退出不给，重复有效胜利可积累。

|顺序各通关一次到达|累计金币|示例消费后余额|
|---|---:|---:|
|第3关|360|买重锤后0|
|第7关|1,120|买重锤360＋候选引魂灯720后40|
|第10关|1,900|两件金币商品均买后820|

这是奖励表的算术结果，不是完成时长保证。720为下一批价格起点，不能为了消耗通关后的剩余820金币再硬加高价商品；若真人通关普遍很慢，应降低价格或改节奏，不强迫刷旧关。金币足够时允许提前购买引魂灯，不额外加第7关通关限制。

十关结束后仍可重复通关积累；不把金币直接换成永久攻击力，也不加消耗品税。成就完成章不另给金币，避免与固定通关收入重复计奖。

## 5. 运行时与旧存档边界

当前`ProgressStore`只有四项成就白名单、重锤购买白名单和旧schema下的通关/最佳记录，不具备上述新挑战的完整历史。实现时必须先扩展校验与观测，不用读到一个未知ID就把整个合法存档重置。

- 十项通关章可以从`stages`中已有的合法关卡完成记录补标；只补对应记录，不猜测缺失关卡。不凭角色解锁、游戏时长或最高击杀倒推出通关。
- `forge_mastery`及既有购买/成就保持；金币不重算、不补发历史局数奖励，也不重复补发旧武器。
- 摧毁装置、踩签、开局武器集合、不同双改组合需要从新增版本开始记录真实事件。没有历史证据时保持未完成，详情说明从新版开始统计；不能凭第3/10关通关直接补“拆阵有方”“解签留路”。
- 每局唯一`runId`去重；成就在胜利结算时写入，事件ID在局内去重。失败的局内挑战计数不满足“本局并通关”的条目；跨局开局/改造集合只接纳成功通关的快照。
- 新武器未实现时不开放“解签留路”的可领取武器奖励，也不展示“已解锁但不可用”。可以先上机制完成章并另行明确奖励开放批次，或待缝针一起上线；推荐同批上线，避免用户误以为能立即使用。
- 图鉴16项需要分类/分页：通关记录、机制掌握、配装探索；保持原有只读详情和返回位置。武器总数14、默认10、解锁4、当前拥有数、暂未开放数分别计算，不把四种改造当四把武器。

建议局内新增最少观测：实际开局武器、有效装置击杀数、唯一踩签危险ID及是否Boss、胜利时满级/合法双改快照。账户仅保存已完成ID和跨局集合；不需要逐帧录像、站定时间、DPS反制或额外隐私数据。

## 6. 落地顺序

1. 先完成第十关与现有基础池/解锁池的输出差距复测，尤其正常生命、真人走位和600/900秒仍未结束的局。
2. 确认本文16项／14把的批次规模和两种新武器职责，再写新武器完整规格；现有四项ID和获取条件保持兼容。
3. 实现最小真实事件观测、扩展存档校验、通关章回填、成就图鉴分类，验证重复结算和缺失字段。
4. 两种新武器完成后随对应金币商品/成就奖励一并开放，测试所有角色、十二种现有来源、两新武器与三阶段Boss的相互作用。

目前第十关开发不会自动把本设计的16项成就和14把武器加入运行版。最终数量为建议，可在实际试玩后减少；不建议当前直接扩到20把或堆满几十项重复成就。
