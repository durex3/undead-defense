# 武器品阶与史诗试炼实现记录

2026年10月20日，工作区开发版0.33.0。对应[十关设计](ten-stage-progression-design.md)。Web与微信本地构建均通过；0.33.0已上传微信后台开发版本，未提审或正式发布，真人平衡验收待试玩。

## 当前开放内容

- 十四个武器系列：十个默认普通、精良重锤360金币、精良飞轮由既有破阵熟手解锁、稀有引魂灯1,440金币、史诗缚影缝针由高难解签留路解锁。
- 飞刀三次进阶：旋纹飞刃、银月环刃、星陨刃阵；重锤两次进阶：裂钟符锤、震庭鸣钟。目标品阶价格360、720、1,440。史诗无需进阶，其他未完成路线明确标记暂未开放。
- 进阶修改同一系列的形态与伤害系数，不新增随机池条目；每局固定品阶快照，局外交易只影响后续新局。所有角色、局内八级成长及原合法改造沿用。
- 十项通关章、三项机制挑战、三项配装挑战。旧通关可回填对应通关章，旧金币、购买及四项成就保留，不补造挑战事件或历史收入。
- 解签留路按用户追加要求提高：以六种不同实际起手分别通关第十关，每局Boss三个阶段各踩断至少一枚Boss封签，并且不受任何Boss来源伤害。失败不清空已完成起手，同一起手重复成功不重复累计。
- 第五至十关的恢复时长依次乘以0.9的一至六次幂。预警、出口、危险槽和精英正常生命100%保持；第十关踩签反制额外0.6秒恢复不缩短。

引魂灯最多一个固定灯区，基础持续3秒、半径2.2，7级半径2.5；选点距离8，最多6个标记，增伤12%，基础伤害间隔0.5秒。离区标记最多延续0.6秒，数量上限包括残留标记；区内与残留竞争名额时优先当前灯区目标。数量属性不增加灯区或连线数量，范围与持续属性按武器配置生效。

缝针基础选点距离10，最多一对连接；基础持续2.5秒，端点距离超过8断线；传递比例20%，每0.25秒至多触发一次。设S为含通用伤害属性与疾针减伤、但不含深缝/长线/倒刺的针击伤害，单次传递上限0.7S、整段预算4S。传递量取触发伤害20%、单次上限及剩余预算的最小值，再经过另一目标的防御结算。烙魂不在转递时重复放大；转递不能触发自身，不复制触发来源武器的改造或其他命中派生。任一端死亡、到期、埋地、未登场或超距则断线，不自动无限接续。单目标仍有基础针击与短暂针形特效。

## 新武器改造

每把四项改造，其中第一与第二项互斥，共五种合法双改组合，4级和8级沿用原改造选择。

|武器|改造|收益与代价|
|---|---|---|
|引魂灯|聚焰照魂|增伤18%，最多3个标记，与展灯广照互斥；新增尖焰符形|
|引魂灯|展灯广照|最多10个标记、半径增加25%，自身伤害降低25%；扩大灯区边界|
|引魂灯|余烬留痕|离区保留1.2秒，灯区持续降低20%；新增环绕余烬|
|引魂灯|魂焰震荡|每跳伤害翻倍，间隔由0.5变为1秒；新增周期扩散波纹|
|缚影缝针|深缝传伤|比例30%、整段预算增加25%，基础针击降低25%，与疾针连缝互斥；新增双股线|
|缚影缝针|疾针连缝|周期降低25%，针击及传递上限降低20%；新增线间亮点|
|缚影缝针|长线引缝|断线距离增加30%、持续加0.5秒，针击降低15%；新增两端线结|
|缚影缝针|倒刺穿针|针击增加40%，整段传递预算降低25%；新增三组线刺|

所有新形态均以代码绘制轮廓、拖尾和攻击效果；五个进阶形态及两把新武器具有独立图鉴图形。图鉴列表保留武器简介，右上角升级箭头直接打开进阶预览，操作区显示目标品阶、价格或金币差额，提供「可升级」筛选；未完成路线与史诗状态明确标注。图鉴购买确认展示前后形态、伤害倍率、花费和剩余金币。未拥有武器不能进阶，交易使用预期品阶防止旧按钮重复扣款，主备写入均失败时不改变余额或拥有状态。
