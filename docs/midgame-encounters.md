# 第 3～7 关中后期遭遇优化

2026-10-13，本地开发调整，接续前两关挂机反馈修正。尚未上传微信后台。

## 设计与实现

普通怪继续承担收割与成长，不改全局血量、移动速度、武器伤害、冰环或 Boss 招式。前一分钟、已有环境教学段和两次精英登场保留。压力来自各关原有角色的配合、方向和出场节奏。

第 3、4、5、7 关使用实际战斗秒数 150–164、220–250、280–310、380–410 的压力窗口。每段后有 10 秒新波次停刷时间，现存敌人和敌人攻击继续存在，不强制清场；环境攻击停止并清理，已生成的尸爆毒池保留。原有全局喘息、精英优先、击杀精英后的补给时间和 Boss 前安静段优先于压力窗口。

| 关卡 | 三种配合与走位判断 |
| --- | --- |
| 3 熔骨祭坛 | 盾阵弓手：绕侧切后排；野猪弓手：横移避冲锋；盾阵召唤师：切后排阻止增援 |
| 4 幽钟教堂 | 女妖弓手：避扇形与箭线；鼓手盾兵：优先支援目标；召唤师弓手：清后排并留意钟环 |
| 5 亡者王庭 | 盾兵弓手、鼓手女妖、盾兵召唤师：保留退路并选择优先目标 |
| 6 亡者熔炉 | 保留现有按种子排列的护阵推进、双翼追猎、后排唤潮及炉柱路线；调整压力段出场间隔和准备后的首轮攻击等待 |
| 7 永夜裂隙 | 弓手幽魂、术士幽魂、女妖弓手：两翼交火，横移避线与固定落点 |

压力段基础出场间隔 9 秒加 0–6 秒随机量，再沿用原有后期关卡间隔修正；仍受威胁预算、单种上限和存活支援怪限制。每次最多三个特殊怪，每段只配置两种角色，现场可能有前一段存活敌人。进场准备 1.2 秒，准备完后首轮攻击至少等待 0.6 秒，仍需满足可见时间、距离、危险槽和完整攻击预警。

盾阵后排在可用空间中放在盾兵外侧 1.8 单位，靠实际位置和现有护盾机制形成配合，不增加投射物遮挡规则；侧翼配合从不同方向靠近。底部提示显示遭遇名称和处理方法；危险与 Boss 提示优先，精英战不展示当前压力段提示。

## 验证与边界

新增六项回归测试，覆盖四关所有压力窗口的实际出场角色、进场准备、威胁与单种上限、后排位置、侧翼角度、停刷补给窗口、环境清理和毒池保留、暂停、精英优先、Boss 前安静段、HUD 与随机流稳定。连同前两关修正，全量 278 项测试及 TypeScript 检查通过。

对照基线是本轮开始时的代码（0.16.0 加尚未提交的前两关修正）。相同游侠、六槽、种子 1/19/72、默认分支、未锁定组合，`icecamp` 按闪电/冰环/幽灵等优先升级但受随机卡池限制。`camp` 前 60 秒走位、60–480 秒停下且使用全收经验、Boss 后恢复走位；`collector` 全程走位。五关每组六局，修改前后共 60 局；不是开局塞入满级武器，未拿到冰环的局也如实保留。

| 关卡 | 挂机策略撑到 Boss，前→后 | 持续走位结局，前→后 |
| --- | --- | --- |
| 3 | 1/3 → 1/3 | 3 通关 → 3 通关 |
| 4 | 1/3 → 1/3 | 3 通关 → 2 通关、1 Boss 战失败 |
| 5 | 1/3 → 1/3 | 3 通关 → 2 通关、1 超时 |
| 6 | 1/3 → 1/3 | 3 通关 → 3 通关 |
| 7 | 0/3 → 0/3 | 2 通关、1 超时 → 2 通关、1 Boss 战失败 |

第三关种子 19 的站定样本在 480 秒时生命由 65.35 降至 19.15；第四关种子 1 由 64.60 降至 57.52。第五、六关对应站定样本入 Boss 时生命仍分别为 75.6 和 70，说明本轮没有完全消除强势站定配装。第七关挂机样本都在本轮首次压力窗口前失败，不能据此证明其成型后压力已校准。Boss 招式和数值没改，但前段随机消耗、配装和血量会影响后续结果。

补充近身双镰路线，第 3、6 关各两个种子，共两次通关、两次 720 秒超时；不能称为全配装验证通过。超时、Boss 战失败和未成型均须作为后续平衡线索，不按单次机器人胜负强行调成固定通关率。
