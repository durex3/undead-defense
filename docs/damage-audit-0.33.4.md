# 十关精英与Boss伤害判定复查

2026-10-21，0.33.4。范围为关卡1～10的精英、Boss及其投射物、落地危险区；同时检查同用这些判定的普通敌人。核对真实伤害几何、绘制入口、预警/生效/结束时钟、重复命中限制、冻结或击杀后的处理。无需自动通关作为验收条件。

## 本次修复

1. **第二关直线攻击误判为大圆**：`frontierLane/frontierImpact`的radius是长度，但旧伤害代码用它作圆半径。巢皇交剪、虫群砂线的首次命中以及二阶段持续沙裂均可能伤到侧方安全位置。统一使用起点至终点、半宽为width的有限胶囊；预警绘制、伤害和逃生采样共用端点与几何。未缩短预警、削减伤害或调整难度。
2. **第二关通用扇形内部未完整显示**：绘制工具的arc先moveTo，导致中心至圆弧不是一个闭合子路径，填色退化成外缘弓形。改为从中心lineTo采样圆弧，填满真实扇形并补齐径向边线。
3. **第三关扇形与引擎圆弧方向不一致**：Cocos Graphics.arc自身新开子路径，方向规则还会让原参数绘制补角。改为显式采样闭合扇形，与判定角度一致；圆形蓄力进度弧也改为显式采样。

## 后续关卡规则

新技能应让绘制和伤害共用路径/角度/宽度/落点及时钟；长度不能当作圆半径。移动攻击只在实际扫掠段判伤，空心安全区、无伤装饰与结束后的轨迹必须保持安全。扇形填色必须包含中心，避免直接套用Canvas的圆弧方向假设。至少覆盖内外边界、旋转、预警前、结束后、持续伤害及重复触发，并在真实Cocos构建检查，不能只依赖离线绘图库。
