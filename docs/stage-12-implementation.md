# 第十二关开发记录 · 0.34.0

2026-10-21。第十二关「裂釉熔窑」已开发并在本地开放，通关十一关即可进入。遵照用户本轮要求，**不上传微信后台**；后台仍为此前0.33.9。本轮网页与微信包只做本地构建。玩法依据[确认方案](stage-12-glazekiln.md)，后续规则见[统一入口](level-design-rules.md)。

## 已实现内容

- 独立耐火墙地图、四类主力、两种精英及「裂釉炉心」，使用Cocos Graphics绘制釉陶躯体、导嘴、瓷轮、双坩罐和三烟囱；地图与双方身体导航接入独立KilnMap。
- 六分钟编排及三轮精英，135/225/305/311秒出场，返场使用同时间正常精英100%生命；两名精英至少间隔六秒，前轮存活/休整会推迟，超时取消尚未出场者，不删除活精英。
- 直路、单分流、双折弯和两条错拍组合。发布时锁定路径和支路，实线箭头与暗色虚线区分；只有移动火体有伤，整条预警路径、火尾经过处及未选支路无伤。每计划一个危险槽，双计划原子预约两个，包括延迟预警与缩尾。
- 精确胶囊判伤按头/尾经过路径节点的时间拆分；每段端点线性移动，直边用线性不等式、圆帽用相对二次交点求扫掠。绘制读取同一弧长截取结果，不用转弯弦线或整块包络代替实际火体。
- 导火栓固定160生命、无护甲、不移动、不挡路。靠近4.5距离内，对有锁定目标的攻击提高优先级，仍须满足该武器射程与轨迹。骨矛在该窗口沿栓方向出手，其余时间保留密集纵列选线；自动布置/环绕武器保留原职责。
- 预警击碎取消整招；主干已发时截断未发支路，当前段和尾部照常走完；火头已进支路则该有限段完成。主人死亡、冻结、转阶段同样只撤未来段，同时关闭该计划的成就资格。自然清理不记玩家击碎。栓不计杀数、金币、经验、药水或旧拆阵成就，不触发死亡后的传伤结算。
- Boss70%/35%三阶段，不回血、不锁血、允许跳阶段；旧已发段结束和1.5秒过渡均满足后才进入下一轮。I A/B/C、II B/A/C、III C/B/A；大招仍两槽，不临时追踪。
- 完整快照发布前可平移/旋转以适配场地、HUD和墙体，保持长度、叉角、速度、相对延迟；失败则真实换位重试。联合基础速度退路检查不依赖击碎栓或无敌时间。修复了移动绕场时双分流反复被墙体拒绝的问题。

## 成长与奖励

第十二关沿用固定数学预算：普通生命系数2.945290474、精英3.509946978、Boss59,173.377942（HUD向上取整显示59,174）。该值不读取当前玩家DPS。恢复系数0.43046721只作用恢复，预警普通2.0秒、精英/Boss2.2秒不缩短。通关320金币，结算ID去重；十二关各一次共2,520金币。

成就总数18→20：釉庭熄炉（通关章），十路断焰（10种实际起手，每种2组不同合法双改；起手8级；每局Boss三阶段各分流前亲自击碎Boss栓，且Boss来源实际扣血0）。同组合和同局不重复计入，失败保留进度；跳阶段可正常赢，但不补造未完成挑战。奖励「断焰司炉」称号和裂釉徽纹，主菜单与成就图鉴真实展示，无额外属性/币/随机权重。

骨矛增加精良「棘脊骨枪」、稀有「釉裂骨矛」、史诗「焚髓贯星」，逐阶360/720/1,440金币；相对普通伤害1.25/1.60/2.05。图标、飞行实体、拖尾和裂骨命中特效随品阶改变；不扩大射程、碰撞或随机池。裂骨仍使用ridge ID，父快照35%、每矛最多三次、每目标一次，指环复制衰减继承一次。保留十四系列。

存档键及rules不变，新增可选kilnQualified字段，按起手保存合法排序双改键，集合用Array.from序列化。损坏的新挑战项按字段修复，不抹掉旧金币/进阶/通关；不从旧章推断新机制挑战。三手动位与独立自动存档保持。
