# 0.33.2 单关轮播选关

2026-10-21。按用户指定改为单关主题图，不再同屏平铺多关卡。此项与火球、圣水、落雷和飞刀优化共同组成0.33.2。

0.33.2已上传微信后台开发版本，包大小2,888,632字节，见[上传回执](../artifacts/wechat-upload-0.33.2.json)。未提审或正式发布。

- 一次仅显示当前关卡，主题图直接复用本关完整地图的等比缩略图与本关Boss绘制；无需另外维护不一致的地图图片。
- 右箭头下一关，左箭头上一关；第一关/最后一关的外侧箭头变暗且无点击行为，不循环跳转。
- 支持方向键、A/D切换、Enter/空格开始、Esc返回。浏览未解锁关卡不修改当前选择或存档；未解锁的开始按钮不可点击，键盘也不能绕过限制。
- 保留关卡主题、特点、胜利奖励、解锁/通关状态与进度圆点。已解锁关卡可直接开始，使用主菜单当前选择的角色。
- 采用现有1280×720参考分辨率与SHOW_ALL等比缩放；完整背景遮住旧HUD，避免菜单边缘露出战斗控件。

`node tools/check-stage-carousel-browser.mjs`使用独立Chrome测试资料目录和真实Cocos Web。已验证844×390、667×375手机横屏和1280×720桌面；包括真实右箭头点击、左右键切换、首尾边界、锁定关卡Enter拦截、Esc返回和已解锁关卡直接开始，无浏览器运行错误。截图与回归记录见 `artifacts/stage-carousel/`。不代表微信真机触控和性能验收。
