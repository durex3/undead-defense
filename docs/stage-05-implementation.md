# 第五关、武器解锁与双图鉴实现记录

日期：2026-10-20。开发版0.27.0，已接入当前工作区。未提交、推送、上传微信后台或正式发布。真人平衡与微信真机待验收。

## 已实现

- 第五关灰烛钟庭，ID5，通关第四关解锁，不要求飞轮、重锤、金币或成就数。360秒进入Boss战，四武器四被动，保留64级、武器8级、4/8级改造。
- 四钟台实体碰撞、怪物绕行及声浪遮挡共用地图数据；钟台不挡蜡印和友方攻击。声浪使用真实传播前沿、扇面与身体半径检查，预警与命中共享几何。
- 四类主力小怪、两名精英、三技能两阶段覆钟蜡主；两个危险槽与连续攻击预约，前摇冻结/死亡取消、已发声浪有限保留、身体冲撞死亡取消。精英未死时延后Boss首招，不清掉存活精英。
- 厚蜡甲与两层、3秒裂甲统一经过伤害入口；无甲敌人不会得到负减伤。Boss/精英恢复窗口自然暴露甲缝，基础武器仍可利用窗口输出。
- 镇钟重锤360金币直接购买，无成就或关卡附加条件；裂甲飞轮通过「破阵熟手」解锁，无额外费用。八项改造、十种合法双改都接入真实行为与绘制。
- 前十把默认开放。两把新武器未解锁时从随机开局及升级池排除；取得后加入原随机池，不指定、不必出、不保底。
- 主菜单的武器图鉴、成就图鉴；武器筛选/分页、独立剪影图标、四改造详情、购买确认、余额差额、成就奖励跳转及返回；方向键移动焦点，Enter/空格确认，Esc返回。
- 通关1～5各奖励100/120/140/160/180账户金币，失败退出不给账户金币。奖励按runId去重，重复结算不重复发钱。单局击杀gold保持单独统计，不直接兑换为持久余额。
- 原armory-v1进度兼容可选账户字段，旧1～4关记录保留，旧账号没有可证明的挑战快照不自动授予飞轮。主备选最高有效revision；购买至少一份成功保存才完成，双写失败余额/持有均不变，提示重试。

## 策略接口

`battle/StageStrategy.ts`是关卡分发入口，提供地图、导演、敌人/Boss行为、清理、死亡和危险处理。每局创建一次策略对象，各关系统保存各自状态。前两关共用波次调度，后三关使用独立导演；不把所有关卡行为塞回主循环。

战斗入口在SurvivalWorld、SpawnDirector、EnemySystem与BossSystem，武器推挤/落点修正也通过策略地图。表现层仍使用EnemyCatalog与独立BellArt，不依赖战斗策略来改变伤害。
