# 四十项武器改造与搭配对照

更新：2026-10-21（0.33.6）。本文仅覆盖十把基础武器的四十项改造，数值与配置同步；全十四系列的平衡与解锁武器见[品阶职责预算](weapon-balance-0.33.6.md)。真人手感与微信真机仍待复测。

## 成长与改造规则

普通升级为1～8级数值成长；专属改造在4级和8级各免费选择一次，每把最多两项。每武器四项中A/B互斥，其余自由组合；合法双改均为A+C、A+D、B+C、B+D、C+D，共五种。十武器合计四十项改造、五十种单武器双改；不增加第三/第四改造槽。

飞刀按最新确认改为四把独立实体刀持续等距环绕，不画整圈刀光、不做分段挥切。三级五把、六级六把，数量被动再增加；单刀基础伤害调整为8/10/10/10/13/13/16/16，避免把原两把刀伤害原样翻倍。每周每刀对每目标一次，转一周周期按等级1.6/1.4/1.2秒变化，持续属性不改变周速。没有敌人也保留刀阵，整周边界接入新数量/改造，不瞬间叠加两套。

幽灵仍是2→3→4在岗伙伴（3/6级增加），每任务有限追猎、两次接触爪击后回收；升级增加单爪伤害，4/8级缩短任务周期。群灵额外+2，猎手−1至少1；含数量被动最多8伙伴。旧任务读旧快照，新增伙伴在下一轮任务调度接入，不复制尚未回收的伙伴。

每项改造必须有自己的动作、轨迹、空间形状或节奏，颜色和图标只作辅助；两个改造组合必须同时保留各自行为。以下特效为当前代码实现，不等同于真人认可其质量。

| 坍缩 + 双核 | 两个核都提前坍缩，每核终结伤仍对同源重叠取最大值。 |
| 坍缩 + 反冲 | 提前终结采用加强空心环，中心无终结伤害规则不被高倍率绕过。 |
| 双核 + 反冲 | 两个核各自形成空心终结，交叠不变成双倍同源伤害。 |
