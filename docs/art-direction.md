# 关卡统一美术规范

更新：2026-10-20。现行方向为**统一矢量墨线风**：敌人、主角、法术和危险预警共享深色描边、三段明暗、边缘高光和关节化动作。落地细节、API、预算与新增流程见[美术开发手册](art-development-guide.md)。

## 统一表现

采用 Cocos 2D 程序绘制，不再为敌人/主角/药水创建 Sprite。角色以深色外轮廓、清晰色块、三段明暗和可读剪影表达；普通怪、特殊怪、精英和 Boss 必须靠轮廓、武器结构、肢体比例和动作区分，不能只放大或换色。世界绘制比例 48 像素/单位，角色以脚底/落地点对齐。

## 地图与信息层级

地图需要中央空间、侧路和外圈的可读区分；装饰降低亮度、饱和度与细节密度，不冒充危险区域。真实障碍读取碰撞配置，四关障碍不作为挡弹掩体。

敌方预警绘制在友方技能特效之上。虚线表示未生效路径，生效边界、箭头、先后序号、缺口及端点需清楚；不能仅用红绿区分。位置或方向锁定后不追踪改画，后续攻击重新完整预警。几何真值、legacy 类型和已知画/判定不一致见[美术开发手册](art-development-guide.md)第 7 节。

可破坏装置与无碰撞投影需要不同轮廓，装置显示血量、剩余时间及破坏反馈。Boss 保持固定顶部血条、名称和阶段；底部动作提示简短，不遮关键落点。

## 制作与验收

- 先白盒验证路线与伤害几何，再做轮廓、动作和细节。
- 使用共享 `ink` 缓存；禁止逐帧 `new Color`。固定容量与复用，禁止为火花/单个敌人创建节点。
- 省电模式可减少装饰粒子，不能隐藏危险边界、方向、缺口、序号、HP 条或出口信息。
- 普通杂兵预算 ≤15 次提交/≤240 顶点；特殊 ≤22/360；装置 ≤16/260；精英 ≤27/540；Boss ≤38/950。整帧目标 ≤45,000 顶点。
- 至少在 844×390 横屏检查：各敌人静态剪影、行走、蓄力、攻击、恢复、受控状态；当前武器槽位上限（当前四把）满配下预警；两危险并存；地图边缘与 HUD 遮挡。
- 浏览器/离线预览与 CPU 数据不能替代微信真机的触控、帧率和发热验收。

## 验证入口

```sh
npm test
npm run art:preview
npm run art:review
npm run art:builds
```

预览图输出到 `artifacts/art-preview/`；`budget.json` 记录每格提交/顶点数与超标项。当前环境无法启动 Cocos Creator 时，必须在文档和交付说明中明确“离线预览通过、真机待验收”。

四武器/双危险的844×390近似合成图与100敌人预算输出到 `artifacts/art-review/`。生成方法继续使用程序矢量Painter，不将预览PNG接回运行时。2026-10-19整改与验收证据见[复查及整改](art-review-2026-10-19.md)；Web构建成功仍不等于微信真机验收。

天降落雷继续使用深色外沿、金白雷芯与折线分叉，从可视区域上方落向原锁定点；仅“电弧连桥”改造显示明显地面连线。改造辨识优先靠形状和实际轨迹；拥挤时削减友方装饰，保留敌方预警与重要受击提示。100种配置的真实Armory采样图位于 `artifacts/art-builds/`，不等于完整游戏录像。

第九关断羽风廊：低亮蓝灰石面、风蚀砂白柱、暗铜接缝，主体为骨白空心陶鸟；四主力剪影分别低雏、长颈、单弧翎、菱形折翼，两精英分别孔哨冠、错翼长尾，Boss为圆面盘悬拱长翼。`enemies/WindArt.ts`独立绘制七种主体，`WindHazardArt.ts`以有限开口风带、粗箭头、完整曲线和折点停顿区分机制。见[造型与预算](stage-09-implementation.md)。

第十关缄页禁库使用暗灰蓝石面、赭褐书架、旧象牙纸、暗铜扣和灰紫索引条；四主力与两精英由LibraryArt独立绘制，Boss随三阶段展开封面。LibraryHazardArt将实心钤印、运动纸页、最终中缝与开口金色封签分别表现，签圈使用显式折线避免Creator/离线圆弧方向差异。预算和实际横屏见[第十关实现记录](stage-10-implementation.md)。
