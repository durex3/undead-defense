# 第11关：灰烬铸造厂

设计日期：2026-10-13。遵守[后续关卡设计规则](level-design-rules.md)。

## 体验与地图

第10关判断旧路，第11关判断正面的有限火线：从侧面离开，再切回反击，不能只往后退。四座方形冷却砧中心(±9,±9)，半宽/半高1.8；中央、四周和砧间均可换侧。考虑玩家半径，左右砧之间宽13.8、砧外侧至边界宽10.9。地图为暗铁地面、冷却砧与低对比导轨；导轨纯装饰。

## 三种敌人与Boss

- 推炉骨兵：普通生命1倍、速度1.5、接触8、经验1、上限12。先向进场时锁定的玩家位置推进2.2秒，再追击；不会不断更新堵截点。
- 熔线工（A）：生命1倍、速度1.2、经验2、威胁2、上限2。停在约5.5单位，锁定从自身朝玩家延伸的6单位熔线，半宽0.5，预警1.5秒、判定0.3秒、伤害10，恢复1.8秒。横移或绕端、近身打断。
- 落锤匠（B）：生命1.1倍、速度1.3、经验2、威胁2、上限2。玩家位置半径1.15落锤，预警1.5秒、判定0.3秒、伤害10，恢复1.8秒。离开落点后可贴近收割。

Boss「灰烬大铸师」循环：①锻炉贯线，锁定以玩家为中点长7、半宽0.65的线，预警1.6秒；②横砧锤击，第一阶段单条垂直来向的短线长5，第二阶段两条平行线、间距3，玩家可穿过中央间隙或绕端；③近身震锤，Boss当前位置半径2.2圆，预警1.5秒。各判定0.3秒、固定伤害18，恢复2.8/3.0/3.2秒。移动速度1.7，第二阶段不加速；唯一增强是横砧第二条线，完整预警与共用命中组，不叠伤。

关卡生命/精英/Boss/伤害/经验倍率：1.54/1.72/2.26/1.34/0.85；药水40击杀。初始Boss血量较第10关约增加1.8%，重点是横移而非磨血。

## 共享开发约束

状态：0.17.0已完成可玩实现与本地验证，真人平衡及微信真机待验收。通关前一关解锁；八分钟Boss、64级、六武器槽、随机开局和全收经验不变。经验沿用从1级严格递增的统一曲线。两分支与超武遵守当前规则，不要求特定武器才能伤害敌人。

活动区 x∈[-22,22]、y∈[-26,26]，出生(0,0)，基础速度4.2、玩家半径0.3。障碍实体、绘制、出生、导航和逃生检测共享几何；障碍不挡武器与地面攻击，选关提示明确标示。中央至少半径6保持开放；每个障碍均可绕行，边缘留通路，无永久伤害地板。

全场100敌人、两个危险槽。每条线/每个圆独占一槽；多区域同次施法须整体检查预算和逃生路线，失败不部分释放。线段为圆头胶囊，端点封口可见；圆与线的绘制和伤害使用同一几何。中心、方向在预警开始锁定，预警后不跟踪。每组攻击最多伤害一次。连续攻击两段各自完整预警；两段提前一起锁定时，第二段从开始就显示，不能突然补圈。

所有特殊怪先有1秒进场提示、首次可见1秒后才攻击，间隔至少6秒；近身1.5内或离开视野取消未生效施法。来源死亡清除危险；冻结暂停状态计时并推迟未生效预警，暂停不推进任何战斗计时。Boss转阶段1.5秒，清理旧危险、停补、不回血；Boss恢复至少2.8秒，不追击且无接触伤害。Boss援军沿用9秒补怪/5秒停补、进场提示和移动缺口，普通援军掉落正常怪50%的经验，不掉金币药水；技能召唤怪不掉经验（0.17.1调整）。

0–30秒普通怪；30–75秒教学本关普通变体；75–125秒仅教学特殊A；125–150秒仅新增特殊B。150–164秒普通收割、164–172秒停补；172–210秒精英段，特殊不新增、普通降频。210–250秒A配合普通变体；250–260秒拾取；260–300秒B配合普通变体；300–330秒普通收割；330–340秒拾取；340–380秒第二精英段。380–420秒A/B交替混合，每批只新增一种，存活特殊威胁预算6；420–460秒普通收割且每批至多新增一只特殊怪、同种存活上限1；460–468秒只补普通，468–480秒停补。已有怪不会因停补消失。精英和死亡短休息优先，跳过事件不补播。

三类路线均保留机会：贯穿/弹射清路可创造换侧空间；追踪/集中输出可在移动中处理后排但需补清群；近身/持续输出在敌人停步和Boss恢复时反击，须主动转移。冰环仍可冻结普通怪，但地面已锁定攻击需要看预警走位，不针对某武器新增免疫。

数值均为初始试验值。先做地图与单怪，再组合编排、Boss、解锁/最佳成绩/选关。使用相同种子、角色、升级和收取策略比较前后关，记录实际配装、成长、死亡时段与来源、Boss耗时；机器人战败保留，不为追求模拟通关率降低难度。程序异常、无预警伤害和无路可逃必须修复。至少覆盖清群、追踪、近身三类随机方向、实际完整组合和独立分支。另做站定测试、暂停/冻结/死亡/转阶段/重开、预算和存档迁移测试。浏览器与微信本地构建，真机帧耗时、触摸与真人平衡待验收；复用像素素材加程序标识不算专属美术完成。
