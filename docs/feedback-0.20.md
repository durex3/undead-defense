# 0.20.0 武器加强与倍速

本轮不增加角色，保留原有三个角色和解锁条件。

## 武器

- 灵魂枷锁：所有等级最大影响目标翻倍，1级4个、2级起6个；基础冷却4.5→2.25秒。专注分支同时束缚2个不同目标，单个敌人也可施放。
- 火焰锁链：所有等级最大影响目标翻倍，1级6个、2级起8个；基础冷却4→2秒。专注分支同时攻击2个不同目标。
- 圣光柱：各等级、各分支半径翻倍，并增加落剑动画。基础半径1.5→3，3级起1.875→3.75；裁决分支1.05→2.1。
- 灾厄陨石第二分支：主星半径1.8→5.4，碎陨半径1.4→2.8；主星附近半径6内随机散落4颗碎陨，可以重叠，地图边界内落地；落点间隔0.08秒。增加落球动画。
- 黑洞基础冷却减半：6→3秒，4级起4.8→2.4秒。角色和沙漏倍率继续相乘。
- 火球第一进化显示名改为豪火球术；内部ID保持meteor，兼容旧存档。
- 新武器搭配提示明确区分“可组合（未激活）”与“已激活”，持有伙伴不代表立即获得额外火伤。

目标数量为敌人足够、距离满足条件时的上限；实际范围为半径，并非面积倍数。链条池扩为48，满池延后施放，避免覆盖尚未结算伤害。

## 现有角色被动

|角色|加成|
|---|---|
|飞刀游侠|飞刀、镰刀、战斧伤害+15%|
|炼金术士|圣水、毒雾、黑洞伤害+15%；圣水、毒雾持续+20%|
|亡灵使者|幽灵伤害+20%；蝙蝠、图腾、魂链伤害+15%；幽灵、蝙蝠冷却-10%|

角色页和暂停技能详情均显示数值，伤害结算使用相同规则。未受专精覆盖的武器没有额外角色加成。

## 倍速

左上按钮与暂停键对称，循环1→1.5→2→3→1。战斗仍以1/60秒固定步长推进，移动、攻击、敌人、掉落和首领倒计时共同加速。暂停、升级和分支选择时不推进时间；新一局恢复1倍。落剑、落球使用现有绘制器，不增加贴图资源。

## 验证

391项测试通过，TypeScript检查通过。手机横屏网页检查了现有角色、倍速按钮及落剑/落球显示。实测现实1秒分别推进1、1.5、2、3秒战斗时间，暂停与升级时停止，新局重置。Web与微信构建通过。未进行真机发热测试，本次武器加强后的整关难度仍需真人试玩。
