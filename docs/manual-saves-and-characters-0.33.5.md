# 三个手动存档与角色重构

2026-10-21，版本0.33.5。本轮承接用户要求：手动存储与删除存档，最多3个；重构第一关小怪及主角外观。

## 存档管理

主菜单左上角「存档管理」，固定3个手动存档位。每个显示保存时间、已通关数量和金币，可保存当前账户、覆盖保存、读取、删除；所有操作先展示具体内容，再确认。读取以所选账户为准，不叠加金币。旧确认按钮在账户或存档已变化时拒绝执行。

保存包括通关、金币、购买武器、品阶、成就及原有挑战/结算记录；不保存战斗中途的角色位置、生命和敌人。自动保存与历史恢复独立，日常结算不会覆盖手动存档。当前设备的微信存储是唯一位置，未新增云存档或跨设备同步。

删除只删除所选手动存档，不能撤销；保留当前进度与其他两个存档位。单键写入删除标记，不把手动存档加入自动备份或恢复历史，因此不会重启后自动复活。标记内不保留被删除的账户内容。保存或删除写入失败时不报成功，原内容保留；读取失败时禁止无提示覆盖。可读但损坏的存档可经明确确认后覆盖或删除。

「存档检查」及「输入补回码」位于管理页底部，原有恢复功能继续保留。账户键与规则版本保持不变。
