# 第六关实现与验证记录

日期：2026-10-20。工作区开发版0.28.1，六关十二武器。功能已接入；难度递增尚未验收。Web/微信为本地构建，未上传微信后台。

## 运行时内容

- ID6「锈潮船坞」，通关第五关即可进入，不检查指定武器、金币或成就。胜利200账户金币，按runId去重，首通记录「潮间过客」。旧1～5成绩、钱包、购买及成就保留。
- TideMap提供四个真实货垛及导航；玩家、敌人、锚头、Boss移泊不能穿垛。飞叉和玩家攻击穿过货垛，选关明确提示。
- 独立的背篓潮佣、开闸背鳐、卷帆叉手、绞盘拖锚兽，以及双闸港监、断缆吊主；形体分别为背篓、宽鳐、折帆、低身绞盘、双闸和高脚吊架。沉锚船骸为带炮舷、桅帆、锚的横向船体。
- 潮墙固定24条横向带，共享首次截停距离、绘制及扫掠判伤；撞垛后不会在垛后重生。有限宽度无中央缺口，只有移动浪头伤害，已过区域不伤、不减速。
- 飞叉串行重新锁定，各有完整预警；拖锚先展示固定L形路径，每段单独预警，碰撞的是实体锚头，细绳不伤。撞垛取消后续锚段，吊主后续飞叉仍须独立安全检查。
- Boss有A潮墙后叉炮、B两段拖锚、C预锁定双潮墙。55%生命转阶段，不回血；二阶段C沿真实路线侧移4单位，身体持续可受伤、移动无接触伤害，第二面仍从预定地点启动。非法停泊点/未到位/不安全后段会取消，不瞬移、不补瞬发。
- 危险槽最多2，包含串行预约；精英至多1、特殊威胁6、全场100。特殊教学期同类至多1，常规特殊起手间隔至少3秒；精英期暂停其他普通特殊怪的新起手。Boss入场不删除活精英，精英死亡后至少3秒才起手。
- 第六关由StageStrategy分发；TideSystem包含独立导演与行为，TideGeometry独立处理几何和出口采样。美术由TideArt、TideHazardArt与MapArt分支负责，不在主循环堆六关判断。
- 成就图鉴改为容纳三项的紧凑纵向卡片；随机开局、升级池、金币重锤与成就飞轮获取方式不变。追猎刀、处决幽灵识别本关特殊敌人。

- 用户追加的厚蜡甲：普通20%、特殊35%、精英50%、Boss55%；裂甲每层减35个百分点、两层上限、3秒。精英恢复甲上限20%、Boss15%，保留承伤+25%且只应用一次。直接、持续、子攻击与弹体统一减伤；不限制武器或新增免疫。实体甲片、单/双裂纹及恢复开缝接入原船坞身体。[离线三态图](../artifacts/tide-stage/wax-states.png)展示完整、双裂甲、恢复暴露。

## 加甲后的难度对照：输出压力上升，真人尚待验收

[模拟原始记录](../artifacts/tide-stage/simulation.json)保留144个输出诊断：12种合法四武器双改配装×3种子×站定/围绕Boss移动×第五/第六关。两关使用同角色、满级装备与相同控制策略，生命提高仅隔离输出窗口，记录真实受伤量；180秒未结束的样本保留未完成状态，不能算作击杀。

|配装|第五关平均诊断秒数|第六关平均诊断秒数|
|---|---:|---:|
|追猎刀/火球/闪电/圣剑|102|114|
|寒霜/黑洞/圣剑/火球|116|122|
|重锤/火球/闪电/圣剑|52|55|
|飞轮/火球/闪电/圣剑|47|52|
|重锤/圣水/地雷/圣剑|91|115|
|重锤/飞轮/圣水/闪电|55|58|

无甲初版的144组记录保存在[加甲前快照](../artifacts/tide-stage/simulation-pre-wax.json)，不再用其结论描述当前版本。加入与第五关同档厚蜡甲后，基础示例102→114秒、重锤52→55秒、飞轮47→52秒；多数已完成配装的输出压力提高。表格只是固定高生命输出诊断，不是玩家胜率；两关均有180秒仍未击杀的配装，全部保留为未完成。

另有12个高生命随机成长收集器，以及12个正常生命、0.9秒有限前瞻的贪心避险/拾取机器人，覆盖四种账户。正常生命样本4胜、4次早期死亡、4个至600秒仍在战斗；死亡均为种子19、约64秒，四种账户在尚未抽到新武器前遭遇相同失败。两组基础池样本活至600秒仍未击杀，不能改判成功。所有12个高生命样本均在360秒前击杀两精英。对照表中的基础配装无需解锁武器也能击杀Boss，但这不代表任意随机成长都可轻松通关。

本轮已按用户要求追加厚蜡甲，没有再提高生命倍率、伤害、密度、缩短预警或赠送指定武器。下一轮真人重点复核初期收割、圣水开局、阵地覆盖和Boss追逐空档；不以机器人早死自动判定必须降难度，也不把延长战斗当作难度已经合理的证明。
