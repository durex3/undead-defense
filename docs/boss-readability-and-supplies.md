# Boss 预警、战斗时长与补给调整

2026-10-20，开发版0.33.1，基于用户试玩反馈。范围为全部十关，本地 Web 与微信包均已构建。微信上传遇到登录过期（code 10），等待用户扫码重新登录；尚未上传成功或正式发布。

## 技能辨识度

- 各关保留原技能形状、锁定目标、预警时长与碰撞，强化落点、通道、曲线、扇面等关键边缘与危险底色。第一关内外圈填充仅覆盖实际危险环，安全中心不填色。
- 十关共用 Boss 头顶感叹号和环形施法进度；未来尚未开始及已取消的预警不触发提示。释放后蓄力标记消失。
- HUD 优先显示正在施放的 Boss 招式、剩余秒数与本关躲避要点；无持续危险的收招窗口显示反击提示。
- Boss 有预警或持续技能时，友方地面与弹道特效进入已有的简化绘制模式。危险区域和 Boss 提示仍在特效上方绘制。

## 生命与战斗时长

共享 Boss 生命由 `2800 × 关卡倍率 × 8` 改为 `2800 × 关卡倍率 × 3`，所有关卡降低62.5%，关卡倍率、护甲与阶段行为不变。第一关54,880→20,580；其余关卡为22,260、24,024、24,360、24,864、26,040、30,240、30,240、30,240、26,880。

`node tools/check-four-weapon-boss.mjs` 已扩展到十关、三套合法满级四武器组合。固定种子、固定被动、无敌绕圈控制器，只检查输出窗口，不代表真实胜率或新手配装。三十组均在120秒内完成；第一关32～38秒，第九关62～107秒。完整结果见 `artifacts/four-weapon-boss.json`。旧关卡文档的历史模拟用旧生命池，不能直接当作当前时长。

## 血瓶和经验满后的物品

- 存活 Boss 血量首次降至75%、50%、25%时，各掉一瓶生命药水。位置在玩家侧面约2.2单位并进行地图碰撞修正，需走近拾取。沿用每瓶20生命、25秒失效、场上最多三瓶与满血不消耗规则。召唤物是否掉落不影响该补给。
- 升级不会自动回血。武器没有可继续学习或升级的选项后，若玩家受伤，升级卡保证包含「生命药剂」，仍保留合法的被动成长选项。选取后回复20生命，上限为最大生命；刷新不会回血。
- 玩家达到64级后，武器已完成时仍可消耗满条经验打开物品/剩余成长选择；等级维持64。所有成长已满且满血时沿用「继续战斗」。改造不触发额外回血。
