# 后续关卡设计规则

第二十关设计候选见[锁锚铸狱](stage-20-chainforge.md)，尚未开发或开放。实体武器撞场景物按武器半径扩张障碍求首接触，预告包络和装饰链不等同伤害。卡桩取消未来段与已释放短窗口的处理按真实事件时间定义；墙边裁切须在发布前完成，边界不冒充机制障碍，身体突进不能借此缩短路线。诱导可提供恢复收益，但保留纯躲通关路线；重复失效应真实换位或换招。反事实认证限定原已发布危险与玩家实际同时轨迹，影子验证无伤、有原窗口寿命，不能拿锁定瞬间站位或整条预告充数。旧挑战及存档保护沿现有规则。

更新：2026-10-22（核对至本地0.43.0，微信后台0.43.0）。依照[当前项目基线](current-baseline.md)与[四关统一美术规范](art-direction.md)，适用于第5关起的新设计。


## 第十七关实施补充（0.41.0）

- 历史追击只记录碰撞处理后的玩家实际坐标，最多回看3秒；连接段不计真实历史转角。公布后节点冻结，实体分腿移动，判伤做连续相对运动，不能用整条预警走廊代替身体伤害。
- 历史接入失败可真实寻路接近，但单次最多1.5秒，重试间隔3秒；不能传送或改已发布路线，没有真实历史的回退招式不计机制成就。
- 返程与到位横扫在真实到达后给完整2.4秒预警，重新检查合法范围及联合退路；整组预约一个危险槽。冻结停止身体及未来腿，已释放横扫只完成原窗口。
- 复活型战报通过生命周期接口返回形态、余命和总剩余预算，不在通用存档逻辑写死关卡编号；第一次归零不结算，最终奖励按单局去重。
- 可选挑战字段使用独立版本及严格键校验，坏字段不能清空账户；方向挑战同局只绑定一个方向，详情显示中文双改配方和左右进度。
- 旧行为快照冻结原内容范围，新关、新敌人、新成就另设回归；不能只更新快照掩盖旧行为变化。实施及证据见[第十七关记录](stage-17-implementation.md)。

## 关卡设计基础

- 每关明确一个新判断动作，采用独立阵营、四类主力小怪、至少两种精英、三轮出场和独立Boss的完整设计；招式不能只是前四关换色复用。
- 先单独教学，再组合两种已知威胁，最后由Boss检验；压力段与收割、回收段交替，不能持续堆满危险。
- 地图先白盒，按基础速度4.2、角色半径约0.3检验；至少两条可用通路，出生、碰撞、导航、绘制与逃生检查共享障碍数据。障碍是否挡攻击必须明确。
- 当前基础池为十武器，保留8级、4/8级专属改造、四武器四被动、玩家64级；现有十关及新关默认360秒进入Boss战，Boss战另算。编排需完整覆盖教学、精英各批次、成长与休整，不直接截断旧时间表，也不压缩技能预警。后续武器、金币与通关成就按实际关卡需求分批设计和开放，见[武器分批开放与关卡成长设计](weapon-unlocks-design.md)；不恢复旧配方或超武。
- 保留100敌人、两个特殊危险槽的上限，连续攻击预约容量；没有合法出口则延迟或取消，不补播积压攻击。
- 预警锁点锁方向，每段新锁定给完整预警；击杀或冻结对未发/已发攻击的作用需要逐项定义。普通血线转阶段不回血、不锁血，复活型按已确认的形态总预算处理，恢复期留出可利用的输出窗口。
- 清群、单体、近身持续三类配装都有收益和代价。后续难关体现整体装备成长，允许通过金币或成就解锁更强武器改善体验，但不强制指定武器入场；开局与升级保持随机，不必出或保底。按实际随机成长评估甲值、密度和输出窗口，避免把没抽到某武器直接设计成固定死局。不读取DPS临时反制，不以站定时长触发惩罚。
- 当前十一关不作为最终关卡，不预排最高成就。先设计下一批实际关卡，再决定必要的新武器和成就数量；不要求一次开发或开放全部规划内容。
- 难度主要增加路线、目标优先级和时序决策，数值明确写基础值、最终值及倍率应用位置，避免重复套用精英/远程强化。
- 新关需同步StageId、配置、解锁、存档校验、地图入口、结算与测试；不得只新增选关按钮。现有合法进度的处理必须写清，不能默认旧编号可迁移。

验收顺序：白盒路线 → 单怪 → 精英 → Boss → 完整成长 → 美术与横屏 → 压力及真机。做同配装、同种子的移动/站定成对检查，保留失败、死因和超时。机器人胜率不等于真人胜率；没有真人/真机结果就明确待验收。

## 精英数量与后续权限

现行三轮规则以[精英编排](elite-rounds.md)为准：第1～8关135/225/305秒三轮，同屏最多一名；前七关复用现有精英，第八关三种各一轮；所有精英初登场和返场均为生成时正常生命的100%，不叠轮次折扣或加成。第九关开始允许多个精英同时存在，初始按最多两名、错峰入场设计，仍共享两危险槽并做联合逃生检查，不自动允许Boss与双精英叠加。

普通追兵可共享追击与接触伤害基础行为，各关仍须有独立造型、动作和遭遇角色；特殊小怪不能仅换色、放大或改数值冒充新攻击。

## 第10～15关的Boss阶段规则

原三阶段规则于2026-10-20确认，2026-10-21追加调整为：**第10～15关Boss采用三个阶段**；第16关起按下文新规则逐关设计，不固定阶段数量。第1～9关按各自已有方案保留。每个阶段需有清晰、提前可读的招式组合与可利用的恢复窗口；阶段递进不能只涨血、加伤或整体缩短预警。血量门槛与越阶段处理需在各关设计中明确，过渡不回血、不锁血，未发与已发危险的处理分别定义，全部阶段继续遵守两危险槽与联合退路检查。

## 新关卡配套成长的主动设计规则

用户于2026-10-20确认：**以后设计或增加新关卡时，开发者应主动提出适合的成就、武器及进阶内容，不需要用户每次另行提醒。** 每次关卡设计都应包含配套成长评估，说明本批建议新增什么、获取方式、奖励价值及与关卡机制的关系。该规则要求主动提出与当前任务相符的方案，不要求每关固定新增武器，也不把所有候选自动列为当批已开放内容。

|评估项目|每次新关设计需要说明的内容|
|---|---|
|成就|是否增加通关章、机制掌握或配装探索挑战；给出明确条件、难度定位、可追踪进度和奖励。稀有及史诗奖励应有相应的掌握要求，不能只靠一次简单触发取得|
|新武器系列|是否存在现有系列无法覆盖的战斗职责；给出初始品阶、金币购买或成就解锁路线，评估新增系列对随机池的影响|
|已有武器进阶|是否适合补齐已有系列的新形态；沿普通、精良、稀有、史诗路线，从自身初始品阶逐阶进阶。每次更换名称、形态与攻击特效并提升伤害，保留系列特点；初始史诗无需升级|
|金币节奏|结合新关收入、已有余额用途和商品价格计算获取跨度；本批进阶按360、720、1,440逐阶翻倍。后续需说明是否沿用或调整，不机械地无限翻倍，也不靠反复刷同一关代替玩法目标|
|开放批次|区分本批实现、后续候选与暂未开放。允许逐步补齐进阶，不要求一次把所有武器做完；未完成内容不能购买、抽取或作为必要入场条件|

金币购买、成就解锁、金币进阶三条路线并存。进阶形态替换原形态，同系列在随机池始终只占一个位置，不重复增加抽取权重。武器图鉴列表保留武器简介，以升级小图标提示可进阶状态，目标品阶、价格和金币差额应能直接查看。

后续关卡与奖励应有明显提高的挑战跨度，围绕机制组合、时序、走位和配装掌握展开，同时保留完整预警与合法出口。当前十一关和史诗只是现阶段范围，不将其命名为全游戏终局，不预排所有未来关卡、武器和最高成就。

验证以机制、存档、消费及画面正确为必要条件，不以自动玩家完整通关作为门槛。机器人数据只辅助判断；真人难度、实际成长耗时及真机表现由试玩验证。当前实现及品阶配置见[十关成长设计](ten-stage-progression-design.md)和[开发记录](weapon-progression-implementation.md)。

### 新武器必须做品阶与职责平衡

用户于2026-10-21确认：后续新武器必须先定品阶数值范围，再根据单体、范围、控制、破甲与辅助特点分配预算，不能让某个系列无代价兼得所有优势。按[武器平衡规则](weapon-balance-0.33.6.md)执行：每系列登记`WeaponBalance.ts`，覆盖1/4/8级、所有可用进阶、合法双改、移动/群体/护甲场景；辅助额外比较四槽整队增量。基准遍历`ALL_WEAPONS`，不能再漏掉解锁系列。首锤等大数字可以保留，但追加连击、派生、破甲与品阶必须计入总收益；未完成横向对比与真实构建验证的武器不得开放购买或奖励。

## 更新时的存档保留规则

每次新增关卡、武器、品阶或成就，都必须兼容已有通关、金币、购买和结算去重记录。不得在启动时删除历史存档；不得因一个可选字段、未知成就或暂不支持的改造而丢弃整个账户。写回前保留原始副本，读取异常时阻止空档覆盖。恢复只能基于实际存在的存档或明确胜利记录，不补造奖励、通关或挑战。验证需要包含上个版本存档、局部字段异常、备份恢复、存储失败和重启读取。恢复设计见[存档保护与账户恢复](save-recovery-0.33.3.md)。

### 精英与Boss判伤验收

新增或修改技能时，绘制与判伤应共用真实路径、角度、宽度、锁定点及时钟；不得用直线长度作圆半径，移动攻击不得以整个预警包络判伤。空心区、装饰轨迹、预警前及结束后应安全。验证需包含旋转后的内外边界、持续伤害节拍、命中去重与真实Cocos画面，不能仅靠离线绘图库。十关复查记录见[伤害判定复查](damage-audit-0.33.4.md)。

### 手动存档约束

用户确认手动存档最多3个，自动保存不得覆盖手动位。保存、覆盖、读取与删除需展示内容并由玩家确认；删除仅针对所选手动位，当前账户及其他手动位保留。删除的数据不得从自动备份静默恢复；失败不报成功，旧确认按钮不得操作已改变的记录。必须测试重启、读写失败和删除不复活，见[三存档规则](manual-saves-and-characters-0.33.5.md)。

### 数值成长与关卡扩展

用户于2026-10-21确认按「参考有效输出 × 目标击杀时长」校准生命，见[0.33.7成长与策略规则](stage-growth-and-strategies-0.33.7.md)。普通、精英、Boss采用独立时间预算，装备输出与时间按平滑趋近曲线增长；当前装备封顶后不无限延续固定比例扩血。参数为固定关卡配置，不能读取玩家即时DPS反向抬血。新增关卡先评估可获得装备与输出，再设计阶段组合、敌群角色及恢复资源；新增品阶后重新校准参考输出。验收保留多配装、多种子的阶段时间和异常差距，不以机器人必须通关作为交付条件，也不把无敌诊断当真人难度。

### 通用被动的组合验收

按[0.33.8指环、烛台与裂骨规则](passive-and-bone-balance-0.33.8.md)，新增武器/被动必须测试数量、面积、持续与冷却组合，以及合法双改、派生快照、重叠伤害和控制覆盖；不能只用无被动单武器预算宣称均衡。圆形范围按面积预算换算半径；指环原有攻击保留，复制伤害/范围折减，派生继承一次。重锤/飞轮已有追加衰减不得再次折减。存档中的旧改造ID保留，显示名称和行为更新；不得因平衡重做清除进阶、成就或金币。

### 新关卡的边缘、接近和时序回归

第十一关实现经验见[0.33.9记录](stage-11-implementation.md)：完整计划可在发布前整体适配场地与HUD，保持长度、相对位置和时序，发布后不能追踪改线。须成对检查移动/站定与边缘站位，防止Boss永远接近不了或边角所有招永久失效；接近调整不得压缩预警或瞬移。冻结/击杀取消未来段，当前已发段按原时间结束后才进入完整恢复。新奖励必须完成真实展示、消费、去重与旧档冷重载，设计稿和开放范围明确区分。

## 后续精英与Boss机制创新（第13关起）

## 第十九关实施后的双体规则

多个真实Boss组成同一遭遇时，必须有独立的遭遇汇总，不能以第一只Boss的存在或死亡判断通关、血条、补给、战报和挑战；尸体移除后仍须保留稳定成员记录。先倒不结算，最终倒下才发一次奖励，同一世界帧双杀不得冒充先后顺序。总生命预算按公式分配，不给每个身体各一份整场生命。
