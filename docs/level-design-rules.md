# 后续关卡设计规则

更新：2026-10-19。依照[当前项目基线](current-baseline.md)与[四关统一美术规范](art-direction.md)，适用于第5关起的新设计。

- 每关明确一个新判断动作，采用独立阵营、四类主力小怪、两名精英和独立Boss的完整设计；招式不能只是前四关换色复用。
- 先单独教学，再组合两种已知威胁，最后由Boss检验；压力段与收割、回收段交替，不能持续堆满危险。
- 地图先白盒，按基础速度4.2、角色半径约0.3检验；至少两条可用通路，出生、碰撞、导航、绘制与逃生检查共享障碍数据。障碍是否挡攻击必须明确。
- 当前基础池为十武器，保留8级、4/8级专属改造、四武器四被动、玩家64级；现有四关及新关默认360秒进入Boss战，Boss战另算。编排需完整覆盖教学、两轮精英、成长与休整，不直接截断旧时间表，也不压缩技能预警。后续武器、金币与通关成就按实际关卡需求分批设计和开放，见[武器分批开放与关卡成长设计](weapon-unlocks-design.md)；不恢复旧配方或超武。
- 保留100敌人、两个特殊危险槽的上限，连续攻击预约容量；没有合法出口则延迟或取消，不补播积压攻击。
- 预警锁点锁方向，每段新锁定给完整预警；击杀或冻结对未发/已发攻击的作用需要逐项定义。Boss转阶段不回血、不锁血，恢复期留出可利用的输出窗口。
- 清群、单体、近身持续三类配装都有收益和代价。后续难关可以要求先取得更强或适配的武器；所需武器必须能通过较早关卡的成就或金币取得，并明确配装取得方式，避免解锁条件循环或完全依赖随机抽取。不读取DPS临时反制，不以站定时长触发惩罚。
- 当前第四关不作为最终关卡，不预排最高成就。先设计下一批实际关卡，再决定必要的新武器和成就数量；不要求一次开发或开放全部规划内容。
- 难度主要增加路线、目标优先级和时序决策，数值明确写基础值、最终值及倍率应用位置，避免重复套用精英/远程强化。
- 新关需同步StageId、配置、解锁、存档校验、地图入口、结算与测试；不得只新增选关按钮。现有合法进度的处理必须写清，不能默认旧编号可迁移。

验收顺序：白盒路线 → 单怪 → 精英 → Boss → 完整成长 → 美术与横屏 → 压力及真机。做同配装、同种子的移动/站定成对检查，保留失败、死因和超时。机器人胜率不等于真人胜率；没有真人/真机结果就明确待验收。
