# 后续关卡设计规则

记录日期：2026-10-13。依据：本轮与玩家确认的关卡方向；现有代码基线为 0.12.4。

## 范围与状态

从第8关开始强化专属敌人、地图利用和独立Boss节奏。前七关保留现有进程，只针对实际试玩暴露的问题修正，不在本轮重做。此文档是后续设计约束；第8关已在0.13.0完成可玩实现，方案与验证边界见 [骸潮港湾](stage-8-harbor.md)。

现有七关已有不同的特殊怪配置、环境攻击和Boss招式，但普通尸潮仍主要共用游荡骷髅，实际难度递进尚未完成同条件全关对比。不能把数值递增或若干次模拟通关写成已经证明的难度曲线。

## 保留的玩法

- 连续战斗八分钟后进入Boss战，等级上限64，六个武器位，开局武器三选一。
- 18把武器均有双分支；到10级自动弹出分支选择。配方双方满10级且均选择第一分支时自动激活超武，伙伴仍占武器槽；第二分支为独立进化，不参与组合。
- 升级经验从1级开始严格递增，后段增幅更大；新关沿用统一经验曲线，不另设更快升级通道。
- 保留暂停商店和现有角色能力；不增加关卡词缀、可选挑战、满级强化等新系统。
- 成型后的玩家仍有大量普通怪可以收割，Boss战也有持续尸潮。避免长时间跑图等怪。
- 不设置必须拥有某把武器、某条分支或唯一配方才能伤害敌人的规则。

## 每关必须回答的问题

1. 本关需要玩家学会哪一个新的判断或走位动作？
2. 哪些主力小怪有可辨识的行为差异，而不只是改名、换色或增加血量？
3. 地图怎样支持引怪、绕行、清路和反击？至少两条可用通路。
4. Boss的独立招式和战斗节奏是什么？玩家何时躲避、何时反击？
5. 清群、集中输出、近身持续伤害三类打法各有什么优势和代价？

## 难度递进

每一关先以少量敌人单独展示新行为，再让两种已学会的行为配合，最后在Boss战中检验。难度呈现压力段与收割/补给段交替的节奏。前一分钟不同时教学多个新攻击。

后续关卡优先增加站位、优先目标和敌人配合的复杂度。血量、伤害只小幅递增，不同时大幅增加血量、速度、数量和危险覆盖。不能用巨额Boss血量弥补招式缺少压力。

目标体验是：熟练玩家从上一关进入下一关，能理解更难在哪里；尝试不同组合后可以改善打法。不能以某次自动模拟的胜负强行校准所有随机种子，也不把模拟胜率视为真人胜率。

## 地形与安全边界

- 先做可玩的几何布局，再制作装饰。基础速度4.2单位/秒、玩家半径约0.3；危险距离和通道宽度都按这些指标计算。
- 视觉边界、玩家与敌人碰撞、出生位置、Boss冲锋和危险逃生检查共享同一份障碍数据。
- 无封闭口袋、必经单行死路或必须受伤才能通过的通道。边缘也要有绕行空间。
- 障碍是否阻挡投射物必须明示；没有实现遮挡就不能宣传为射击掩体。
- 现有逃生检查只是保守几何筛选，不能保证动态怪群中的绝对安全；仍需实机与真人验证。

## 尸潮与Boss

保留全场100只敌人上限。Boss尸潮沿用9秒密集补怪、5秒停刷循环；停刷不会清掉现存敌人。新波次在玩家附近留移动缺口，进场至少1秒提示，普通援军掉落正常怪50%的经验，不掉金币和药水；Boss技能召唤怪不掉经验。升级仍以上限64级为界。

Boss转阶段时暂停补怪、清理自身旧危险并提供完整提示。危险中心、方向在预警开始时锁定，连招第二段必须重新给完整预警。避险后必须存在能实际输出的恢复窗口，近身配装也能利用。

同屏危险沿用最多两个的预算；普通接触敌人不占攻击危险槽。新关敌人的远程攻击也应占用该预算。空间不足时延迟或取消攻击，不补播积压招式。

## 验证与发布

设计数值统一标注为初始试验值。上线前必须验证：

- 第7关和新关用相同种子、角色、开局规则、升级策略和配装方向做成对比较；记录实际是否成型、受伤、Boss耗时及超时，而不只记录胜负。
- 清群、追踪单体、近身持续三类路线都能通过有意义的走位通关；不能因固定机器人不适合某路线就认定该武器无法通关。
- 满级后站定测试用于发现站撸风险，移动测试用于发现封路与拖时；两者不能互相替代。
- 暂停、敌人死亡、阶段切换、旧存档迁移、解锁、结算、敌人/危险上限及实体池回收均通过。
- 浏览器画面与微信真机检查；记录帧耗时、预警可读性和触摸操作感受。没有真机结果就明确写“待验收”。

第8关已按“地图原型→单怪教学→完整节奏→Boss”完成可玩实现与本地验证；真人平衡校准、微信真机及发布验证仍待完成。后续关卡沿用此开发顺序。

第9关[白骨军械库](stage-9-arsenal.md)已在0.14.0完成可玩实现与本地验证，重点为支援目标和切入时机。成对模拟存在更多失败，不等于真人难度递进已校准；验收边界见关卡记录。

第10关[葬星观测台](stage-10-observatory.md)在0.15.0完成可玩实现，重点为历史路线星痕和锁定落点反击。主动技能改为全收经验，后续比较需保持相同收取策略；真人难度递进及微信真机仍待校准。

第11～13关在0.17.0完成本地可玩实现：[灰烬铸造厂](stage-11-forge.md)、[暮镜回廊](stage-12-prism.md)、[终焉渡口](stage-13-ferry.md)。保留两个危险槽与百怪上限，共享预警几何和生命周期，分别检验侧移、交叉空间、错时转移。36局对照与预置满级站定测试不能证明严格难度递进，真人与真机待验收。
