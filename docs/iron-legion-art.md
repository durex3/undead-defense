# 铁棘军团：程序像素造型

对应版本0.18.1，仅用于第14关。资源来源：项目内原创代码绘制，未引用外部图片；绘制入口为`assets/scripts/presentation/SiegePainter.ts`。沿用现有2D像素表现、世界单位48像素、脚底锚点，手机横屏844×390检查。

主体使用深色外轮廓、冷灰铁甲、暗红布料、淡金武器和护具。头盔为封闭横向目镜，避免继续表现为骷髅。普通兵主体宽约36、高63世界像素；战犬为低矮四足轮廓；旗官放大1.3倍、骑将1.25倍、督军1.65倍。实际显示随现有相机缩放，不改真实伤害碰撞尺寸。

旧贴图节点在第14关隐藏且停止逐帧换帧；其他关卡恢复原贴图。轮廓绘制在战斗Graphics层，地面预警最后绘制，防止武器特效盖住危险边界。颜色使用共享缓存，减少百怪时的颜色对象分配；没有新增纹理文件或额外图集。

已检查七种角色同屏的手机横屏预览。该实现是程序绘制的像素角色和程序动作，不包含手工逐帧动画贴图。桌面绘制耗时不代表微信真机帧率或发热，仍需真机体验反馈。
