# 第六关设计：锈潮船坞

现行三轮精英（0.30.1）：135、225、305秒，第三轮复用本关第一种精英，生命为正常值85%。下文精英攻击机制保留，旧出场时点由[三轮编排](elite-rounds.md)替代；同屏最多一名、Boss等待活精英。

日期：2026-10-20。状态：0.28.1功能已实现，当前可玩内容为六关十二武器；几何、回归、离线对照与本地构建见[实现记录](stage-06-implementation.md)。参数仍为试验值，难度递增与真人/真机尚未验收。

依据：[当前项目基线](current-baseline.md)、[关卡设计规则](level-design-rules.md)、[统一美术规范](art-direction.md)及[第五关实现记录](stage-05-implementation.md)。

## 1. 这关新增的判断

**看懂潮墙往哪里推进，侧移让过，再进入它经过后的空区；不要沿着危险前沿一直后退。**

第五关以「借障碍挡声浪、换位离蜡印、抓甲缝输出」为核心。第六关改为船坞拾荒异兽与活化船骸，主要考验移动危险经过前后的路线选择，以及潮墙之后的第二次截路。不会把第五关声浪改成蓝色，或把第三关电栅缺口换成水纹继续使用。

第六关的潮墙是有限宽度、单向推进的矩形浪头，**没有需要寻找的中央缺口**。玩家可以提前绕过左右端点，或在浪头经过后从侧面切进其后方。危险范围不是整个已淹区域，不能将无伤害的退潮水面画得比浪头更醒目。

难度增长来自潮墙、叉弹和拖锚的空间交接。普通怪保留收割收益，不能用持续堆血和全屏覆盖让玩家一直逃跑。

## 2. 进度、随机与本批范围

- 关卡ID为6，只要求通关第五关。没有指定武器、购买记录、金币余额或成就数门槛。
- 开局和升级继续从已开放且已解锁的武器池随机抽取；不指定、不必出、不保底。
- 本批不新增武器。先使用基础十武器、金币重锤和成就飞轮验证不同配装；两把解锁武器有更强的打击和空间收益，裂甲能降低本关厚蜡甲，其他武器可抓恢复期自然暴露输出。
- 四武器、四被动、武器8级、4/8级两次改造、玩家64级、360秒Boss不变。
- 按用户追加要求，本关沿用第五关厚蜡甲：普通20%、三类特殊35%、精英50%、Boss55%。每层裂甲降低35个百分点、最多两层、持续3秒；命中先裂甲再结算，本关恢复期自然暴露为精英20%/Boss15%甲上限，原承伤+25%只应用一次。所有武器都能造成伤害，不新增指定武器免疫。
- 胜利奖励为200账户金币，失败/退出仍不给，沿用结算去重。首通成就「潮间过客」只给图鉴标记，不临时绑定一把尚未实现的新武器，也不是最高成就。

选关提示：**「绕过浪头再切回；细绳不伤，避开锚头；船骸收舷时反击。」**

## 3. 地图白盒：错位货垛与潮间双环路

活动范围x±22、y±26，出生(0,-8)。中央半径6净空，不缩小现有可玩场地。

|实体障碍|中心|半宽|半高|空间作用|
|---|---|---:|---:|---|
|西北船材垛|(-10,9)|1.8|2.8|分开中央与西侧回廊，不能封闭两端|
|东南船材垛|(10,-9)|1.8|2.8|与西北错位，避免每次沿同一轴跑|
|南侧断栈基|(-6,-17)|3.0|1.2|提供外圈换侧参照，左右都可通过|
|北侧断栈基|(6,17)|3.0|1.2|与南侧形成错位入口|

路线参照点：(0,-8)、(0,0)、(-15,0)、(15,0)、(0,±12)。出生→中央→左右侧路→上下换线点→出生形成至少两条闭合回路。外圈无必须倒退退出的口袋。

障碍阻挡玩家、普通怪、拖锚的实体锚头及Boss船体移动。玩家攻击不被这些障碍阻挡；敌方叉弹也不被阻挡，选关和首次教学明确说明，不能将船材垛宣传为挡弹掩体。

本关潮墙经过障碍时，**被障碍挡住的那部分浪头消散，不在障碍后方重新长出来**。每个浪头横向细分为固定24条带，各带沿推进方向计算第一次撞障碍的距离；一旦到达即永久截停该带。玩家碰撞圆需与所有相邻有效条带的矩形面积检查交叠，不能只看脚底中心所在条带。绘制、判伤和未来路径检查共用截停距离，不能只做一次声源到玩家的遮挡判断来模拟推进水流。

这使障碍既能让追兵绕路，也能在特定角度留下窄的退潮空间。但不承诺薄垛能挡住其他方向来的叉弹；玩家必须观察攻击类型。

基础移速4.2、玩家半径0.3；实体碰撞读取同一份地图数据，使用现有小步分轴移动。对白盒必须做出生到所有参照点的连通检查，以及四面阻挡、沿边滑动、拐角、大步长和百怪绕行检查。

白盒[布局示意](../artifacts/tideworks-design/layout.svg)与[静态检查记录](../artifacts/tideworks-design/whitebox.json)已生成：0.5单位网格、0.05单位边采样下，半径0.3/0.7可到达全部参照点；三种首波宽度的开阔地侧移距离有余量。这不是动态怪群、两波交接或真人难度验收。

## 4. 潮墙的统一几何与公平规则

基础潮墙横向总宽5.6、前进厚度0.55、速度2.2、行程8。发布时锁定玩家当时位置P和推进方向D，起始浪头位于P−3D，朝P方向推进；不是在玩家身上生成有效伤害。

完整预警1.35秒，显示起始浪头、左右端点、推进箭头、最大行程与障碍截停位置。由当前镜头校验整段关键避险信息，若端点、交接路线被HUD遮住或超出可玩视野，先移动施法者、缩短合法行程或取消本次；不得预警后再平移端点追玩家。

浪头激活后，同一面潮墙对玩家最多伤害一次。浪头后方只有低对比退潮水迹，不减速、不扣血、不吸附玩家，也不改变友方弹体方向。省电模式能减少水滴，不能抹掉端点、真正的浪头、截停口或下一击提示。

一面潮墙占1个危险槽。其他截路攻击必须占另1槽。两面潮墙就是两槽，不能再同时安排叉弹或锚头。所有预约、发射与回收沿用统一容量接口，不能将三发独立攻击包装成一条记录绕开上限。

出口检查采用基础速度与0.35秒反应，考虑玩家半径、实际障碍、已存在危险及近侧怪物占位。组合不可达则延迟或取消后段，恢复窗口照常保留。采样是工程筛查，不宣称证明所有玩家或动态怪群中的绝对安全。

## 5. 四类独立主力小怪

|敌人/候选ID|轮廓与动作|基础生命系数/移速/最终接触伤害|上限/威胁|
|---|---|---|---|
|背篓潮佣 / brineporter|宽背藤篓、两只蹼足、前倾短臂，步行时篓架左右摆动；不使用骨兵身形|1.10 / 1.70 / 12|普通池内 / 0|
|开闸背鳐 / sluiceray|贴地宽鳍、阀门背甲与短尾，放潮时双鳍支地、背闸展开|1.85 / 1.15 / 14|2 / 2|
|卷帆叉手 / sailharpooner|瘦长身体、三角折帆肩架、单侧长投叉臂；投掷后有明显收手|1.65 / 1.30 / 12|2 / 2|
|绞盘拖锚兽 / winchbeast|低矮四足、圆筒绞盘背架、拖地重锚；侧行放缆、转角停顿后收缆|1.90 / 1.25 / 14|2 / 2|

背篓潮佣只接触追击。绕障碍形成两股追兵，从侧面切回时能用飞刀、火球、圣水等收割，不新增死亡爆炸、分裂或全局强化。

### 开闸背鳐：教会先让浪，再切后方

距离4～7、入镜至少1秒后发布一面基础潮墙，伤害20；完整预警1.35秒、速度2.2、行程8。只有实际浪头危险，背鳐本体施法中不扑击，不同时在其身后补第二道浪。

玩家既可绕端点，也可利用船材垛截停的浪段。潮墙结束后恢复1.8秒，随后冷却3秒。发射前死亡取消、冻结暂停完整预警；发射后施法者死亡不删除已出现的有限潮墙，剩余截停条带按原时间结束。

### 卷帆叉手：浪后还有一次新的瞄准

距离3～7锁定玩家当前点，标出短叉、细直路径和箭头。完整预警1.2秒后投出单枚叉弹，速度6、最大行程7、半宽0.22、伤害20，对玩家最多一次，占1槽。

叉弹结束0.35秒后，可以向玩家新位置再投一次，但必须重新锁定、重新给1.2秒完整预警；两次不同时在场，共预约1槽。击杀或冻结能取消/暂停未发部分，已飞出的叉弹正常结束。两投结束恢复1.8秒、冷却2.5秒；第二投无法合法发布则直接进入恢复。

不能在潮墙尚未发布时暗中预判玩家将选择哪侧；错开教学后，允许叉手瞄准玩家已实际进入的退潮位置。玩家再横移一次即可应对，不要求固定某个被动或角色。

### 绞盘拖锚兽：看锚头，不怕绳

锁定玩家当时点，在其侧前方布置一条两段L形锚路：每段长3，第一段和第二段互成90度。路径与顺序在首次起手全部展示，起点距玩家至少2.5；不得让第一段锚头直接出生在玩家身上。

第一段完整预警1.25秒，锚头沿路径以2.6速度移动，实际危险半径0.5，伤害20；到拐点停0.35秒，第二段再给完整1.1秒预警后启动。每段各最多命中一次，两段串行共预约1槽，不在拐点停顿时偷判伤害。

**细锚绳只表示连接，不伤害、不阻挡移动。** 锚头撞实体垛则停止，取消未发第二段，恢复2秒；不绕过障碍自动重画路径。锚头是身体武器，施法者死亡即移除，冻结时整段物理动作暂停并顺延；同一时刻不再追加接触伤害。

## 6. 两名专属精英

### 135秒：双闸港监 / twinlockwarden

轮廓为高背双闸板、两条粗支腿、外露铜管的半生物港监，不用第五关双钟袍形。移速1.25、最终接触20。生命基准系数10，再应用一次共享精英强化和本关精英倍率。

循环：沿第一方向开闸放潮 → 向另一侧重排第二道潮墙 → 收闸恢复。每面宽6.4、厚0.6、速度2.2、行程7、伤害24，完整预警各1.4秒。

两面不迎面相夹。第二面推进方向相对第一面转90度，在第一面**全部有效浪段结束后0.5秒**重新锁定和发布预警；不能玩家刚躲进第一面背后就瞬间被第二面扫中。第二面发布前验证端点路线与障碍截停空间，失败则取消第二面。

共预约两槽，不追加叉手；结束恢复3秒，身体接触关闭，承伤+25%。首次出现只配普通潮佣。

### 265秒：断缆吊主 / severedcrane

轮廓为倾斜门架、三根细长撑足、悬垂大吊钩与侧置绞盘，区别于低身拖锚兽及双闸港监。移速1.20、最终接触22。生命基准系数12，再应用一次精英强化和本关系数。

先进行放大的两段L形拖锚：每段3.5、锚头半径0.65、速度2.8、每段伤害24，分别完整预警1.3/1.2秒，中间停0.4秒；细绳仍不伤害。两段结束0.45秒后，由本体向玩家新锁定点投一枚长叉，完整预警1.25秒、速度6、行程7、伤害22。

整组最多预约两槽：拖锚1槽，后续叉弹1槽；串行执行，不将两段锚头与叉弹同时激活。锚头撞垛取消后续锚段，是否还能投叉必须重新检查出口和预警，不能撞墙触发无前摇补射。

结束恢复3.2秒，接触关闭、承伤+25%。玩家可引吊钩撞垛后绕到门架背面输出。

## 7. Boss：沉锚船骸 / drownedhulk

Boss是横向展开的活化船骸：船首为裂开的骨木撞角，腹部两层肋骨船舷、两侧独立炮门、后方破帆与粗锚链；以船底滑行或短支架拖行，不使用直立督军、六足虫皇、多臂机械、鹿形兽或倒悬铜钟剪影。

地表寻敌速度1.4，正常寻敌接触22。蓄力、技能移动、恢复与转阶段关闭接触；本体全程可受伤，无锁血、回血或必须拆掉才能伤害的护罩。

55%生命进入第二阶段，过渡1.5秒；取消自身未发攻击与预约，已发叉弹/潮墙按有限时钟继续，仍占危险槽。已经放出的实体锚头随收缆取消，并清楚播放回收反馈。

### A：倾舷冲潮——绕过浪头，再看侧舷

先向玩家起手位置发布一面宽7、厚0.6、速度2.4、行程8的潮墙，完整预警1.4秒，伤害26。潮墙全部结束0.45秒后，船侧炮门瞄准玩家新位置，发布单枚叉炮：完整预警1.25秒、速度6.5、行程8、半宽0.3、伤害24。

炮弹路径与潮墙是不同图形，不能用泛蓝整屏闪光掩盖真正危险。两段预约两槽，均最多一次伤害；若炮线无合法出口，取消炮击并正常恢复3秒，承伤+25%。

### B：断桅拖锚——船体不追，锚头过弯

船骸停驻，展示两段L形锚路，每段4、锚头半径0.7、速度2.8。第一段预警1.35秒，中间停0.4秒，第二段完整预警1.2秒；每段伤害26，单段最多一次。

锚路在首段预警前一次锁定，后段不改瞄。任一段撞船材垛则停止，立即进入收缆恢复。整组占1槽，不补第三段或在锚绳上判伤；其他特殊怪不能趁Boss收缆恢复期突然起手。恢复3.2秒、承伤+25%。

### C：双舷沉港——本关专属大招

Boss两侧炮门与桅架展开，先展示两道潮墙的方向、端点和编号。第一面宽8、速度2.3、行程7、完整预警1.5秒；第二面方向相对第一面转90度，等待第一面结束0.6秒后再给完整1.5秒预警，伤害各28。

第二面位置和方向在第一面预警发布前固定，第二次预警只确认其启动，不偷偷重瞄。两面没有相对夹击，不画成要求钻中央缺口的电墙。第一波经过后有稳定空区，玩家可选择先回空区，再绕第二面端点。

初次发布前按两段的实际到达时间验证连续可达路线。第一面发布后不得移动第二面的端点；若动态占位使第二面不再有合法出口，取消第二面。两面预约两槽，大招期间不发布普通特殊怪攻击，结束后恢复3.6秒、承伤+25%，不立刻补第三面潮墙抵消反击窗口。

### 第二阶段：沉港回航

第一阶段循环A→B→C，第二阶段循环C→A→B。保留全部预警和伤害参数，不把强度变化简化为全属性加速。

第二阶段C发生一次真实船体换位：在第一面潮墙发射前，虚线展示船骸将沿侧向滑行至4单位外的停泊点，以及第二面潮墙的固定起点。第一面放出后Boss按地图导航以2速度滑行，**身体无接触伤害，仍可被攻击**；到点后停驻，待第一面结束且至少0.6秒，再发第二面完整预警。

滑行路线或停泊点不合法则取消换位，预先显示的第二面也取消，保留完整恢复；不瞬移、不穿垛、不追赶到位而缩短预警。第一面浪头仍从原起点走完，不能跟船体一起平移。

船体换位会降低留地武器的常态覆盖，但3.6秒停驻恢复给圣水、地雷、圣剑重新布置与反击机会；不能持续移动让阵地流派没有输出窗口。

## 8. 六分钟遭遇编排

表中均为真实秒数，不再套480刻度压缩。暂停、升级与改造停止计时，恢复后不补播积压波次。

|时间|遭遇|教学与压力目的|
|---|---|---|

|30～65|首次单背鳐，只有普通怪辅助|完整教学潮墙端点与浪后空区；首次浪结束后至少4秒不叠其他特殊攻击|

|120～130|背鳐＋叉手错开至少3秒起手|先让潮，再应对新锁定叉弹|
|130～135|停止新增特殊怪|回收经验并准备精英|
|135～175|双闸港监，仅普通潮佣辅助|单独检验两次换侧，不叠拖锚|
|175～220|背鳐＋叉手、叉手＋拖锚两种组合轮换|练习浪后转线与锚头绕角，始终最多两槽|
|220～230|减压段|停止特殊新增，普通波减量|
|230～255|两侧潮佣＋两种特殊行为|成型配装清出退潮后的入口|
|255～265|精英前收束|停止新增背鳐/拖锚，留回收时间|
|265～305|断缆吊主，仅普通怪辅助|引吊钩撞垛，再观察收缆后的叉弹|
|305～340|背鳐＋叉手、背鳐＋拖锚交替|两个方向的动态交接，禁止第三种同时起手|
|340～350|收束|不新增精英，减少特殊补充|
|350～360|Boss前休整|停止新增特殊怪，保留已有有限攻击正常结束|
|360|沉锚船骸入场|检验潮墙、拖锚与第二阶段换位|

精英延迟规则：前一名存活不刷后一名；延迟至340秒仍未安排则取消第二次。精英死亡后至少6秒不新增特殊怪。Boss入场保留活精英；其死亡后至少3秒再允许Boss首招，不直接清场制造虚假出口。

Boss普通援军沿用9秒补/5秒停节奏，普通目标28～34、全局最多100。Boss每次恢复期间不新开特殊怪攻击，恢复结束至少0.5秒后才可重新竞争危险槽；已有特殊攻击仍按原有限时钟结束，发布Boss攻击前计入路径检查。

## 9. 十二武器在本关的收益与风险

|武器|实际收益|需要承担的风险|
|---|---|---|
|飞刀|切回浪后空区时清理贴身追兵；追猎可远拆背鳐|绕身刀不能挡潮墙或叉弹|
|火球|轰散端点附近的密集潮佣，重爆抓收舷停驻|前排可能提前引爆，落地火海覆盖会被Boss换位打断|
|圣水|把追兵引入浪头经过后的水区，经营换线入口|转场损失旧水区，需要在停驻窗口重铺|
|寒霜|控制普通围堵，争取绕端点的时间|不冻结Boss，不能让已发潮墙停住|
|闪电|处理分散叉手与背鳐，沿端点队列接力清路|基础多目标落雷并非最高单体输出|
|幽灵|离队追后排，追击时玩家仍可绕垛|伙伴回收有空档，不能替玩家挡叉或接触锚头|
|骨矛|利用回廊与浪后队列贯穿，清出稳定切入线|固定直线对侧向移动目标收益下降|
|地雷|在预计回切点布雷，撤退后引追兵踩中|无法靠地雷消除潮墙；一直跑外圈会浪费布阵|
|黑洞|将普通潮佣拢到端点外，为范围攻击创造密度|不拖走Boss、精英、飞叉或锚头|
|圣剑|抓叉手投后与Boss收舷恢复的固定位置|提前锁点后Boss滑行会使落剑落空|
|镇钟重锤|宽扇面重击清开端点近侧，震纹穿队列|先裂甲后结算，全配装受益；仍需承担近身风险|
|裂甲飞轮|去回贯穿两侧追兵，端点绞切封入口，侧弧回收贴合回切动作|去回命中可维持裂甲；转场后旧回收点可能不理想|

建议分别测移动清群、远程拆后排、阵地回切三类路线，各包含纯基础池、仅金币解锁、仅成就解锁、两者均解锁状态。固定配装隔离机制收益，随机成长评估抽取与成型；不把预置满级、无敌Boss击杀样本当成难度结论。

## 10. 数值与难度验收

初始候选倍率：普通生命1.98、精英2.25、Boss生命3.10、关卡接触伤害1.58、经验1.30、药水阈值42。全场100实体、特殊威胁预算6、危险槽2、精英最多1。共享精英生命/接触强化只应用一次，上文标明的攻击伤害均为最终值。

本关已加入与第五关同档的厚蜡甲，厚甲、裂甲和恢复暴露都走统一伤害入口，不能只比较生命倍率就宣称比第五关难。目标是普通尸潮收割不明显拖时，特殊怪与Boss通过新的路线交接产生更高操作压力；允许成型的新武器让战斗明显变快。

验收采用相同角色、种子、控制策略和解锁池，与第五关做对照，记录首次8级、双改成型、伤害来源、危险出手/取消、Boss输出时长、峰值敌人数、缺少目标武器或主动未选的情况。至少覆盖12种合理四武器配装×3种子，及完整随机成长，不只选择会输的配置。

站定/移动配对样本用于发现覆盖漏洞或无路可走；机器人失败不自动触发降难度。若多种正常成型配装都只能拖长战斗而不能改善处境，先查浪头截停、导航、第二段预警和恢复窗口，再调整数值，不靠抬高药水或送指定武器掩盖问题。

普通成长、两名精英与Boss都要真人复测；第六关比第五关更难属于待验收目标，不是本文已证明的事实。

## 11. 美术与专属特效

整体采用深描边、三段明暗、低饱和地面和清楚剪影，世界48像素/单位、脚底或船底锚点。配色为深青海水、锈橙铁件、灰褐湿木和少量灰白帆布；附着灰黄厚蜡甲片，但保留船坞生物与船骸的原剪影，不沿用第五关钟袍主体。

- 地图：货垛有明确实体立面与底部投影；退潮纹理贴地、低亮度，不伪装成减速区或不可走水面。
- 小怪：背篓、宽鳐、三角折帆、低身绞盘四种轮廓，在手机尺寸不能只靠颜色区分；不能复用军团兵、虫皇、机械蛛或月兽换装。
- 精英：高背双闸与高脚吊架，比例、步态、蓄力动作各自独立。
- Boss：长船体和肋骨炮舷、破帆展开、真实侧向滑行、锚头经过拐点的停顿，都读实际技能时钟，不播放与判定脱节的循环动画。
- 潮墙：立体浪头、泡沫断面与左右端点；已过水面明显退暗；被货垛截停的带段同时停止绘制与判伤。
- 飞叉：窄金属叉尖、短水尾；预警用直线箭头，和宽潮墙显著不同。
- 拖锚：厚重锚头有深色外沿，细绳低亮度，拐点显示先后编号；绳本身没有伤害，不能涂成整条红色危险带。
- 大招：船舷炮门分侧打开、两道浪头编号、第二阶段滑行虚线；不靠全屏闪白或震屏遮住第二面启动。

敌方预警始终在友方特效上层。省电减少水滴、帆布细纹和装饰泡沫，保留真实危险边界、端点、遮挡截停、锚头与顺序。沿用单体提交/顶点预算及整帧45,000近似顶点目标，离线通过不能替代微信真机GPU/温度检查。
