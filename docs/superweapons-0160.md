# 0.16.0：首批超武协同动作

分支仍决定单武器的攻击方式，组合双方均10级后自动激活协同动作，保留双方及所选分支。底部将组合双方合并显示为“超武名称 ∞”，实际武器槽计数不变；暂停页与结算仍展开原武器和分支。九组配方均采用合并名称显示，本轮只开发以下两组新动作。

## 水毒净化

圣水瓶＋毒雾尾迹 → 水毒净化。活跃水池与毒池交叠处生成最多三个净化法阵，每1.2秒共同爆发一轮，额外伤害归入圣水和水毒组合统计。取代原有逐目标水池伤害增加50%的机制，避免两套加成重复叠加。

法阵为同时内接于双方圆形区域的圆，半径不超过1.5，小于0.45的浅交叠不生成。每0.25秒搜索法阵，距离小于1.25的中心合并，整轮跨法阵对同一敌人只命中一次。每次伤害仍检查敌人位于两个来源区域之内。来源消失、回收或移动到无法完整包含法阵时清理旧法阵；不把已过期毒池或飞行中的圣水算作来源。

每次爆发基础伤害为攻击力×0.8，沿用圣水等级、分支、角色与敌人减伤规则。保留圣水基础伤害、毒伤/毒层和减速，兼容净化圣泉、随身圣潮、瘟疫行者、蚀骨剧毒。友方基础池只保留淡色边界与小图标，净化区域使用浅绿填充、菱形中心和周期环，减少重复铺花纹。

## 噬魂军势

幽灵伙伴＋噬魂蝙蝠 → 噬魂军势。蝙蝠命中留下两秒噬魂标记，保留原有幽灵对标记目标的噬魂追加击；标记有效期内目标死亡时，额外释放最多两枚实体追踪魂弹，寻找六单位内其他存活敌人，优先首领。

每0.25秒最多一批释放，全场最多十二枚魂弹。魂弹速度11、寿命两秒，目标死亡可重新寻找附近目标，无目标则消失。命中基础伤害为攻击力×0.55，归入幽灵及噬魂组合额外伤害统计。魂弹击杀不会继续生成魂弹，避免递归连锁。超时、暂停、来源回收与重开均遵守战斗生命周期；魂弹击杀首领后立即结束本帧战斗流程，防止胜利后被经验升级重新打开菜单。

幽魂军团与冥界双猎保留原有清群/单体分工，蝙蝠两分支均可提供标记。魂弹以浅蓝核心、紫色光环和短尾线绘制，不增加显示节点池。

## 验证与限制

268项自动测试、TypeScript检查和最终Web/微信构建通过。新增测试覆盖真实交叠几何、重复池和三法阵上限、四种水毒分支搭配、标记有效期、追踪命中、额外伤害归属、非递归击杀、频率/容量上限、暂停/回收、首领击杀胜利状态与底部合并名称。

第一/十关分别采用水毒、幽灵方向，各三个相同种子，真实开局牌、六槽、不锁目标、谨慎收集策略，720秒截止。第一关两方向均3/3通关，分别1/3和2/3形成预定组合；第十关水毒3/3通关、2/3成型，幽灵2/3通关、0/3成型，另一次228秒失败。未成型胜局不作为目标超武强度验证，机器人结果不代表真人胜率。报告：`temp/superweapons-0160/report.json`。模拟中“首次组合”已改为实际联动就绪，避免误把独立分支选择当作组合成型。
