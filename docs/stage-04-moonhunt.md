# 第四关设计：苍棘猎原

现行设计基线更新：2026-10-19。编号、成长、存档与验收状态以[当前项目基线](current-baseline.md)为准；美术遵循[四关统一美术规范](art-direction.md)。本文招式参数属于设计参考，实际行为以当前代码为准。

## 1. 核心体验

**看清去程和回程，临时换向，绕过猎兽的扫掠面，在收招时反击。**

前三关分别强调拆阵、清群折返、拆电极与穿缺口。第四关采用新的月蚀兽群：低身群兽、双镰螳猎、长尾跃兽、宽角巡兽；精英为回锋猎酋与巡角巨灵，Boss为大型四足鹿形怪物「蚀月角王」。全部采用独立轮廓、动作和攻击流程。

第三关主要判断固定危险的位置；第四关主要判断危险在时间中的运动。原地站定会受到回刃、落点和扫掠威胁；一直沿同一圆圈跑，也需要观察回程、换向和切入时机。成功躲过后有明确反击窗口，强配装能够缩短战斗并清出路线。

目标难度高于第三关，主要增加运动路径与连段判断。第三关尚未完成真人难度验证，不能把机器人失败率当成第四关继续大幅加数值的理由。

采用6分钟进入Boss战、64级上限、四武器、四被动、武器4/8级专属改造和Boss战经验。不新增角色、成就或武器规则。

## 2. 地图：中央草甸与双弧林径

边界x±22、y±26，出生点(0,-8)。中央半径6净空，两侧各有三个固定残木基座，形成错位弧形林径；中央、侧路与外圈互相连通。

|基座中心|碰撞半宽/半高|
|---|---|
|(-11,-13)、(-13,0)、(-9,13)|1.1 / 1.4|
|(9,-13)、(13,0)、(11,13)|1.1 / 1.4|

基座使用矩形碰撞和明确的石根底座轮廓，树冠不能遮住角色。基座阻挡地面移动，不挡玩家攻击和敌方回刃；跃扑路线也须绕开基座，不以飞行动画偷渡碰撞。草、花、月纹和林径仅作方向地标，无隐藏减速、视野遮蔽或周期性地面伤害。

```text
                  北侧回路
        [残木]                 [残木]
             \               /
    [残木] —— 中央草甸 —— [残木]
             /               \
        [残木]                 [残木]
                  出生
```

以移速4.2、半径0.3、反应余量0.35秒校验出口；主要通路净宽至少3.6。验证玩家及Boss体型从出生点到中央、两侧及外圈都可达。不得依赖鞋子、游侠加速或特定武器清出必经通道。

远程起手必须让完整危险路径出现在可玩视野内，避开顶部HUD和底部操作区；不合规时调整起手位置或取消本轮，预警发布后不追踪修改路线。地图边缘不额外惩罚停留，也不能成为敌人永远无法出招的位置。

## 4. 四类专属小怪

|敌人 / 候选ID|轮廓|基础血量 / 移速 / 普通接触基值|威胁|
|---|---|---|---:|
|棘背群兽 / thornrunner|短腿低背、三排长棘、宽鼻；主要经验来源|1.1 / 1.75 / 8|0|
|回刃螳猎 / crescentmantis|高身双镰、窄腹，蓄力时举起一侧月刃|1.6 / 1.2 / 10|2|
|跃枝猞猁 / vaultlynx|四足长尾、前爪宽大，起跳前明显压低身体|1.45 / 1.8 / 10|2|
|摆角巡兽 / antlerprowler|宽扁角冠、厚肩，挥角前侧身站定|1.9 / 1.3 / 12|2|

特殊单位出生距玩家至少6，入镜并完成至少1秒展示才可起手。技能不推拉玩家、不禁足、不封技能、不反伤。

### 棘背群兽：两翼汇入，保持清群收益

75%直接追击；其余每波最多6只，生成时锁定玩家侧方3单位的合法集结点，沿一侧绕行最多1.8秒后追击。侧向目标不随玩家每帧重算，波次左右交替。

没有正面护甲、死亡爆炸、分裂或远程技能。玩家可以用骨矛贯阵、圣水引流、火海和地雷经营路线。高输出清场后保留回收经验的空档，不立即贴脸补怪抵消收益。

### 回刃螳猎：去程躲过后，仍要看回程

在距玩家3～8时锁定当前位置与方向，投出一枚月刃。去程直线最长5，弹体碰撞半径0.28，速度4，完整预警1.15秒，伤害20，每段最多命中一次。

到去程终点后悬停，显示0.95秒完整回程预警，再返回起手点侧方1.8单位的固定落点，速度4、伤害20。回程落点由种子和轮次左右交替，在最初起手时即展示为虚线；回程确认后不再更改，不跟随施法者或玩家。

整枚回刃占一槽；悬停期间无接触伤害。地形不挡回刃，整条路线和端点都需可见。玩家可侧移、绕过端点或切到两条路线之外；不能要求只能靠高速穿过弹体。

发射前击杀取消；发射后击杀保留这枚有限回刃及其回程预警。冻结暂停尚未发射的起手，不暂停已飞出的回刃。完成后恢复1.8秒、冷却3秒；场上最多保留一枚自身回刃。

### 跃枝猞猁：落地后还有一爪

距玩家3～7时锁定当前落点，原地伏身1.25秒，再沿可见弧线跃进，飞行0.45秒。落点半径0.9，伤害20，最早起手1.70秒后结算。起跳后不追踪落点，路径遇基座不合法则取消起跳。

落地后0.4秒，朝玩家当时方向锁定一次100度、半径2.3的爪击，另给1.1秒完整扇形预警，伤害20；不在挥爪过程中转向。结束恢复2秒、冷却2.8秒。

伏身、跃进、落地等待、爪击和恢复均无身体接触伤害，避免一次落点叠加身体与爪击。全程可受攻击，空中只是视觉高度变化，不隐藏或无敌。冻结可延后起跳前预警；已起跳按现有冲刺控制规则完成，不中途停在空中。击杀取消尚未落地的本体攻击；已结算的落地冲击不回滚。

玩家可以先离开落点，再绕背或退出爪击距离。追踪武器可在移动中持续压血，圣光和重爆可抓落地后的停顿。

### 摆角巡兽：扇区表示扫过范围，真实危险是移动角刃

距玩家2～5时站定，锁定朝向。地面显示100度、半径3.4的扫掠路径、起点和旋转箭头；预警1.25秒后，角刃从一侧扫到另一侧，历时0.9秒。左右方向按轮次交替，启动后不追踪玩家。

真实碰撞为从身体外0.6单位到3.4单位的一条旋转径向刃，半宽0.22；不是整个扇区同时伤害。伤害18，同次扫掠最多一次。可退出半径、绕到背面，或在有余量时穿过已经扫过的一侧；不要求玩家必须贴身穿刃。

结束恢复1.8秒、冷却3.2秒。蓄势冻结延后整段预警；扫掠启动后按已提交攻击完成，冻结不让刃跳角。击杀本体立即取消剩余近战扫掠。蓄势、挥角和恢复均无身体接触伤害。

## 5. 两名精英

### 138.75秒：回锋猎酋 / moonreaver

双足高镰兽，肩部两枚巨大月刃，尾部有月纹骨片。血量基础系数10，再应用一次精英×2和本关倍率；移速1.4，最终接触20。

循环：先后投出两枚回刃 → 各自悬停预警后折返 → 恢复。

- 两枚去程路径在起手时全部锁定，从猎酋两侧发射，长度最多5.5，速度4.2、半径0.3、伤害22，各占一槽。
- 第一枚预警1.25秒；第一枚发射0.5秒后，第二枚开始自己的1.25秒完整预警。第二枚去程从最初就有虚线和编号提示。
- 每枚到达终点后悬停1.05秒，单独显示完整回程预警，再返回各自固定落点，伤害22。四段都不重瞄玩家。
- 两条回程不得形成封闭包围；必须验证玩家可在0.35秒反应后以4.2速度避开整个时序，而非只验证第一枚。
- 两枚结束后恢复2.8秒，无接触伤害，受伤+25%；本体一直可以被攻击。

斩首可取消未发射部分，已发射月刃有限结束。首次出现只有普通群兽辅助。若两刃序列没有合法路线，起手前降为单刃；单刃也不合法则移动至合法位置，不无限蓄力。

### 266.25秒：巡角巨灵 / hornwarden

宽肩四足巨兽，角冠展开成弧形，脚下有明显的巡猎步印。血量基础系数12，再应用一次精英×2和本关倍率；移速1.4，最终接触22。

循环：沿固定短路移动扫角 → 停步 → 原地反向扫角 → 恢复。

- 起手锁定一段长2.4的合法步行路线；完整预警1.4秒，同时显示机体路线和角刃旋转方向。
- 第一段历时2秒，机体速度1.2，角刃半径3.8、半宽0.25，旋转100度，伤害24、最多一次；起点、终点、旋转角度均不追踪玩家。
- 第一段结束0.4秒后，在实际终点锁定反向扫角；完整预警1.2秒，再用1秒扫过100度，伤害24、最多一次。
- 两段预约两槽，但顺序执行，不同时夹击；两段均结束后恢复3秒、无接触、受伤+25%。

移动扫角必须共享一个动作时钟，机体、刃和预警不能因冻结或掉帧脱节。启动前冻结可延后预警；启动后作为已提交移动动作完成，不临时跳角。机体撞基座立即停步并取消未发生的后段，保留完整恢复。击杀取消剩余本体扫角，不能留下隐形近战刃。

## 6. Boss：蚀月角王 / eclipsehart

大型四足鹿形猎王：宽胸、后仰分叉角冠、长尾月环、蓄跃时前肢压低，扫角时角冠横展。普通群兽、精英和Boss都不复用骨兵、虫皇或机械轮廓换色。

生命沿用Boss计算，关卡倍率2.90；追击速度1.7，最终接触24。起手前近至玩家4.5单位以内；蓄势、移动攻击、布势、恢复和阶段过渡均无身体接触伤害，本体全程可受伤。

55%生命转第二阶段，过渡1.5秒，不回血或锁血。清理尚未发射的自身计划，已飞出的月刃按原路线有限结束；第二阶段等待旧危险结束后再预约。

### A：双月折返

投出两枚沿弧形去程飞行的离体月刃，再沿不同弧形返回固定落点。每枚去程时长1.3秒、回程时长1.3秒，半径0.32、每段伤害26、每段最多一次。弧线横向弯曲不超过1.6，路径总长不超过6；碰撞沿真实曲线采样，不能用整条弧线同时判伤。

第一枚完整预警1.3秒。第一枚发射0.6秒后发布第二枚的完整1.3秒预警；首次起手就显示两枚去程/回程的固定路线、箭头和编号。每枚转向前悬停1.05秒，重新强调该枚回程路径，悬停无伤害。

两枚共占两槽，不产生其他追踪月刃。去程和回程的位置、控制点在首次起手前锁定，不读取玩家后续方向，不追施法者。最后一枚结束后恢复3秒、受伤+25%。

破解：先侧移离开去程，再观察回程箭头，沿两条路径外侧换道；不能只绕Boss保持固定半径。有限弹体路线始终留出口，不制造完整封环。

### B：踏月换位

连续两次锁点跃扑，每次伏身预警1.3秒、飞行0.45秒、落点半径1.1，伤害28、只结算一次。第一击结束0.5秒后才锁定第二落点，第二击有独立完整预警；不把两次落点叠为一段追踪跳跃。

第二次落地后0.45秒，锁定一段120度、半径4.2的角刃横扫，完整预警1.2秒，扫掠1秒，半宽0.28、伤害26、最多一次。结束后恢复3.2秒、受伤+25%。

最多预约两槽，三个阶段按顺序执行；第二落点或扫掠没有可达出口则取消该段，恢复窗口仍从最后有效危险结束后完整计算。整个跃扑过程可受伤，无身体接触伤害，不通过离地逃避玩家攻击。

破解：躲第一落点后准备再次换向；第二落地后绕背或留在横扫半径之外，最后切入反击。

### C：追月长扫

锁定一段长2.8的地面路线和120度角刃扫掠，起手完整预警1.5秒。随后Boss用2秒移动至路线终点，刃半径4.5、半宽0.28，从一侧连续扫向另一侧，伤害28、最多一次。机体和刃共用动作时钟，不追踪玩家。

结束0.4秒后，在终点发布一个80度反向回扫，完整预警1.25秒、扫掠0.9秒，半径4.5、伤害26、最多一次；不在扫掠中改向。两段占位预约最多两槽，先后执行，结束恢复3.2秒、受伤+25%。

破解：走到扫掠面之外、绕背或沿扫过的一侧换位；第一次绕开后仍要留意反向箭头。长扫不覆盖360度，不要求整张地图奔跑，也不阻断两个唯一出口。

### 第二阶段

第一阶段A→B→C，第二阶段C→A→B。预警、伤害和恢复时间保持。

- A两枚月刃左右出手顺序交换，曲线仍在第一次预警前固定。
- B第二次落地后的扫角方向交换；第二落点仍在第一击结束后重新锁定并完整预警。
- C去程扫角方向反转，回扫方向随之反转；不增加第三条危险。
- 每完成两次技能，恢复结束后尝试补1只回刃螳猎或跃枝猞猁，轮次交替。已有特殊援兵时跳过，受威胁6和两危险槽限制；不得偷走反击窗口。

Boss普通援兵目标28～34只。每次技能结束后至少3秒不补普通波；援兵经验沿现有50%规则，无药水/金币。没有按玩家DPS加血、按配装禁用技能、无敌回血、伤害反射或强制武器配方。

|266.25～303.75秒|巡角巨灵＋普通群兽，学习移动扫角和反向收尾|
|303.75～345秒|回刃＋跃扑、回刃＋摆角交替，两槽危险，不出现第三类追击|
|345～354秒|停止新增精英和跃扑单位，收束遭遇|
|354～360秒|停止新增特殊单位，普通波减量，准备Boss|
|360秒|Boss入场；存活精英不删除，待其击败并休整至少3秒后才开启第一招|

精英击杀后至少6秒不新增特殊怪。前一精英未死时延迟第二名；到345秒仍未安排则取消第二次，不积压到Boss前连刷。教学和休整期间只暂停尚未起手的特殊动作，不删除存活怪、冻结已经发射的弹体或回滚伤害。

升级、改造、暂停停止全部战斗计时；1.5/2/3倍速使用固定模拟子步，不改变预警在游戏时间中的比例，也不一次补刷跳过的波次。

## 8. 十武器的不同收益

|武器|本关收益|实际取舍|
|---|---|---|
|飞刀|追猎先处理回刃后排；往返刃利用群兽队列|环绕近身流需要等待跃兽落地，不能挡敌方月刃|
|火球|重爆抓落地、恢复，连珠处理两侧普通群兽|提前锁点的重爆可能被跃扑移出，不能每次都追上|
|圣水|将群兽引过侧林径，圣泉经营反击区；奔流便于持续转向|长期站在一处会被回程和落点逼迁，但原有水区不会被清除|
|冰环|解开普通围堵，为换向留空间，碎冰强化清群|不冻结Boss或已提交跃扑/移动攻击，不取消已飞回刃|
|闪电|接力处理分散后排，连桥利用侧路聚集|单独Boss收益依然取决于具体改造，不赠送额外传导目标|
|幽灵|猎手在换向时追后排，归途切割追兵|出击回收仍有空档；Boss飞行过程可以受伤，不能依赖永久召唤驻场|
|骨矛|把侧路群兽整理成射线，重矛穿过精英和普通队列|窄重矛要主动整理角度，扇骨更适合换道清群|
|地雷|在预定退路和落地后反击区布设，诱导群兽踩雷|不能消除月刃或角刃；持续转场会舍弃部分旧雷覆盖|
|黑洞|聚普通群兽，配合贯穿或爆破；漂移涡心帮助换道|不牵引精英/Boss，不吸走敌方弹体|
|圣光|剑雨处理分散敌群，重剑抓停驻和收招|落剑锁点后不追跳跃目标，完整恢复窗口给其稳定输出机会|

至少验证拆后排爆发、持续区经营、移动清群三类打法，每类两套四武器/四被动合法配装。多种合理打法都应能以走位通关，不设“这一关必须冰环”或“没有追猎就不能打”的隐性门槛。

## 9. 特效与信息

- 场景为暗青草甸、灰白残木与月纹，敌方危险用橙红/暖白边界；己方技能保持各自颜色。特效必须足够明显，不能只给旧怪换色。
- 去程实心箭头，回程双箭头；尚未生效的路径为虚线，生效弹体有实体月牙和短尾迹，不能用整条亮线冒充弹体真实碰撞。
- 扫掠预警显示扇区边界、起始刃和旋转箭头；生效时只强化真实旋转刃，扫过区域随即变暗，不把整个扇形画成持续伤害区。
- 跃扑有伏身、起跳、可见弧线、落点收缩环和落地顿挫；空中影子、索敌位置和地面实际位置一致，不发生假隐身。
- 危险路径、箭头、落点和当前刃始终在玩家武器特效上层。省电模式减少草、残影和火花，不能移除攻击方向或改变碰撞。
- 顶部固定Boss名称/血条/阶段。底部每次只提示当前动作，如“去程之后还有回程”“落地后绕背”“留意反向扫角”。不持续铺满长说明。

## 10. 文件、存档与验收

第四关ID为4，通关ID3解锁，当前列表为[1,2,3,4]。存档按当前ProgressStore的合法ID校验；当前实现不新增成就，不改变角色解锁。第四关不是最终关卡，不绑定最高成就；后续内容按[武器与关卡成长规划](weapon-unlocks-design.md)分批安排。

建议按地图、运动危险几何、敌人导演/状态、绘制四部分实现，避免把角刃和回刃当成旧圆形伤害换动画。第一阶段先验证可玩白盒与碰撞，再制作完整特效。

### 必须验证的工程行为

1. 出生、中央、侧路、外圈对玩家/Boss体型连通，基座不产生卡位或跨墙跃扑。
2. 回刃沿真实曲线/线段运动，去回程各一次命中，转向有完整预警，不返回施法者新位置。
3. 旋转刃与移动机体共用时钟，使用扫过路径检测，3倍速和掉帧不穿透玩家；不能把整个预警扇区同时判伤。
4. 跃扑落点锁定、全程可受伤、无身体伤害叠加，爪击/横扫另有完整预警。
5. 击杀、冻结、阶段转换分别遵守离体弹体和本体近战取消规则；死亡后无隐形扫角，已飞月刃不会突然消失。
6. 预约与实际独立危险合计不超过两槽；无隐形第三击。失败投放取消/恢复，不无限蓄力，恢复从最后有效危险结束后完整计算。
7. 休整、特殊起手间隔、精英延迟、Boss援兵和经验规则有回归测试；暂停/升级不追赶补波。
8. 主备恢复、损坏回退和写入重试覆盖ID4，合法前三关记录保持。

### 路径公平与难度验证

每个多段序列在首次预警前用基础速度、0.35秒反应、真实半径、基座、附近敌人和现存危险做时间路径检查。运动危险必须按未来时刻的位置检测；至少包含直行、先移后停和一次转向路径，不能只靠第三关的直线采样器宣称所有弧线可躲。

如果双刃序列不可达，预警发布前改成单刃或换起手位置；如果后段变得不合法，取消该段，保留完整恢复。预警已发布后不得偷偷移动回程落点、增加安全区、加玩家免疫或临时改碰撞。

六套合法配装各做3位置×3种子、站定/移动成对Boss检查，保留失败、超时、伤害来源、出手次数和余血。同配装同位置站定胜2/3则登记并检查实际技能循环、射程和恢复占比；不只挑会输的配装。成长阶段另做0～180秒与300秒后样本，并补完整移动成长局。

第三/第四关用相同配装、控制器与种子对照；机器人失败不自动降难度，也不等于玩家必输。所有合理配装都失败时先排查路线、取消规则、命中和窗口，再由真人确认强度。设计目标“更难”需要真人和对照证据，不能仅凭倍率宣布已达到。

真机重点检查四武器、双回刃、运动角刃、群兽、3倍速和省电模式。保持100敌人/两危险容量，回刃与残影复用有限对象，不用大量独立节点绘制草与尾迹。桌面模拟和浏览器无异常不代表手机不会发热。
