# 0.33.2 武器试玩反馈调整

2026-10-20～21。保留现有武器和改造形态，按用户反馈改善命中、升级收益与动画；同版新增[单关轮播选关](stage-carousel-0.33.2.md)。

## 火球与骨矛

主火球弹速7→22单位/秒，碎焰7→12；骨矛仍18，保留0.2秒蓄力，重爆保留0.35秒蓄力和原攻击周期。提高火球到达速度，保持两者伤害分工。高速火球按穿过敌人的第一个接触点爆炸，避免低帧率下穿过敌人却在远处爆炸。

固定6单位、同轮发射、高生命目标诊断：旧火球首次伤害约0.767秒，骨矛约0.508秒；新火球约0.242秒，骨矛约0.508秒。不是所有配装/起手时机都保证火球先命中。

## 圣水

回涌取消持续时间−15%。后半程仍锁定玩家当时的位置，空地以3.8单位/秒回收；覆盖敌人后按其基础速度和减速/冻结状态降速，范围0.6～1.6，避免把追兵甩出水区。回收点不追踪，原落点不再固定封路；同源重叠仍取最大伤害，水爆仍只在整秒结算。

等级1～8每跳基础伤害改为7/9/9/10/12/13/15/16，第8级周期2.4→2.2秒；第4、6、8级也有直接可见的伤害收益。

单水区、高生命追兵、相同伤害参数、5秒诊断：1.5～1.55移速时，固定池88、旧回流176、新回流193.6伤害；1.7～1.75移速时，固定池70.4、旧/新回流均158.4。该场景显示回流可以保持有效伤害，不代表所有地图、移动方式和配装都优于固定水区。

## 落雷

玩家界面「连锁闪电」改为「天降落雷」；「远距接力」改为「扩域落雷」，描述为每轮落雷数量+2、相邻可选落点间距3.5→5.5。「三重雷暴」改为「范围雷暴」，明确基础小范围同时落雷与0.18秒分批大范围落雷的差别。武器详情与升级选项明确显示「落雷数量上限」；目标不足时不凭空增加命中，不把落雷写成跳跃子弹。内部ID不变，兼容存档。

等级1～8基础伤害30/38/38/40/48/52/60/66，周期2.3/2.3/2.3/2/2/2/2/1.6秒。保留每轮主击同敌人一次、回击和连桥不递归的规则。

## 飞刀

保留追猎飞刀。碎刃沿最终飞行方向分叉，而非发射时旧方向；环绕终结沿切线散出。主刀和碎刃共用实体刀剪影，取消碎刃菱形以及刀尖前方的额外箭头，拖尾记录真实路径。两枚碎刃从同一帧开始移动，避免对象池复用与追加顺序造成错拍。仍每轮最多散出两把，碎刃不递归。
