# 精英配合与Boss选招 0.40.2

本轮优化等待精英的站位、第十四/十五关Boss发布前选招，并修复第十关精英在边缘反复放置失败的问题。承接0.40.0与0.40.1，仍为16关、14武器系列；已提交并推送远程，微信开发版本0.40.2已上传，包大小3,123,053字节，未提审或正式发布；见[交付记录](release-0.40.2.md)。

## 精英配合

`ElitePositioning` 只给等待者提供移动意图，原关卡继续管理招式、轮换、预警、冷却和两个危险槽。已有同伴在发布危险，且自身还在冷却或两个槽都被占用时，等待者可换位；空出槽且准备好的精英交回原控制器出招。

敌人配置可声明 `elitePosition: anchor | flank`：已配置的主压制者偏好4.6距离，其余精英默认侧翼3.8距离。从同伴方向的±75°、±90°、±120°及180°候选中，选择地形允许、对玩家有通路且自身路线较短的位置。无法放置时至少0.6秒后重试；目标缓存随同伴或玩家位置变化失效。

一次换位意图最长1.5秒，然后至少0.8秒交回关卡控制器；玩家移动不会刷新同一次意图的最长时限。冻结、埋地、自身活动危险链、蓄力、冲刺和收招不被战术层移动。不增加精英数量、生命、速度或攻击伤害。

## 第十四、十五关Boss

`BossPlanChoice` 在发布前评估A/B/C三类完整方案，每类最多8个方向。候选必须满足原关卡的完整几何合法性和实际逃生检查，最多两个危险实体。优先使用当前阶段尚未发布过的可用招式，再比较是否能覆盖玩家当前位置、是否与上一招重复及原设计顺序。

选招结果携带经过验证的实际危险快照，直接交给原 `begin` 校验与发布，不重新计算一个不同方向。只有实际发布后才消耗轮换记录；阶段变化重新记账。没有可用候选时保留原关卡的拒绝/换位路径。第十六关仍沿用0.40.0的距离/旧骨痕条件选招，其他关卡未统一替换选招器。

这是对招式有效性和多样性的判断，不读取玩家将来输入，不在预警发布后追踪改向。原A/B/C形态、伤害、预警、速度、阶段机制和反击窗口保持。

## 第十关边缘修复

双精英移动诊断复现：封签精英的固定横向钤印在靠右边缘放不下，夹页精英进入后续方向后也可能持续拒绝。

仅在原精英方案失败时，尝试完整方案的其他原有方向；双招钤印可在发布前改为竖向，巡裁行页保留原长度和从实体出发的运动。若仍需换位，优先选择能容纳下一完整招式的位置。封签范围、间距、可见性和“踩签/纯躲避”两条可达性检查全部继续执行。没有缩短或拆掉招式来绕过检查。

## 验证与边界

- 699项回归：698通过、1项历史跳过；类型、内容审计、架构行为/武器数值对照通过。
- `tools/check-elite-coordination.mjs`：第9～16关原有双精英，中央、持续移动和边缘3场景，每组90秒，24组均两者出招、无寻敌实体穿入障碍、无超过两个危险实体。报告 `artifacts/ai-0.40.2/elites.json`。
- `tools/check-boss-stationary.mjs --sweep --all-states`：1,371组各阶段中央/边角压力记录均出现实际判伤，报告 `artifacts/ai-0.40.2/stationary.json`。这不代表穷举所有站位或胜率。
- `tools/check-boss-plans.mjs`：比较第14/15关各阶段、站位和来向的288组快照：35组改选招式，61组在原始首选方向非法或不能覆盖时选出可覆盖的合法方案；30组没有候选，交回原拒绝/换位逻辑。报告 `artifacts/ai-0.40.2/boss-plans.json`。
- 实际Cocos：第14/15关各三阶段各运行120秒，均发布A/B/C且不超过两个槽；第10/16关双精英持续移动90秒均能出招。实际浏览器无运行异常，本地Web/微信构建通过。
- 完整验证：`npm run verify -- --full`。独立诊断前先运行 `node tools/test-build.mjs`；报告见 `artifacts/verification/full.json` 与 `artifacts/architecture-refactor/browser/browser-report.json`。

未将所有Boss改成同一种选招逻辑，未以静态样本推断真人通关率或真机帧率。后续按朋友反馈的具体关卡、阶段、站位、配装继续补机制专属场景。

## 后续接入规则

精英站位配置须属于精英，侧翼换位必须有时限；准备出招时保留原调度权，不能通过移动重置冷却。Boss选招预览不得修改实体、消耗轮换记录或直接发布危险；必须用实际判伤几何评估候选，并在发布时保留原逃生与反击机制。轮换公平性在合法候选之间实现，不能强行发布放不下的招式。每次扩展到新关卡都补该关机制回归，尤其包括边缘与障碍附近。
