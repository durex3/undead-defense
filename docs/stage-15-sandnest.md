# 第15关：赤砂虫巢

设计日期：2026-10-14。状态：0.19.0本地实现，本地验证完成，已上传微信后台开发版本。以第14关铁棘军团重做版0.18.1为对照，不沿用旧版第14关的站定测试结论。

## 核心体验

第14关考验拆盾弩阵型、清后排和连续换位。第15关更进一步：清群后要处理分裂幼虫，躲开第一段后还要识别折返、出土后的追击方向。以真实怪物行为制造压力，不检测玩家挂机时长，也不因玩家伤害高而临时加血。

新阵营为沙地甲虫与掘地异兽，全部重新制作轮廓和动作，不用骷髅、哥布林、军团士兵换颜色。8分钟进入Boss战、64级、6武器位、现有升级经验曲线保持。第1～14关不跟随修改。

## 场地、数值与预算

活动区x±22、y±26，出生点(0,-8)。三个岩岛中心(-10,0)、(10,0)、(0,15)；前两个半宽2.5/半高3，第三个半宽3/半高2。中央横向通路净宽15，绕岛通道宽度充足；没有必须穿过的狭窄门，也没有无预警流沙地形。岩岛阻挡移动与翻滚，不挡远程攻击，选关提示说明。

玩家基础移速4.2、半径0.3。危险预警、出生检查、实体碰撞、导航与逃生校验共用岩岛数据。地面提示永远绘制在武器特效上层。

初始试验倍率：普通血量1.72、精英1.95、Boss血量2.65、关卡伤害1.46、经验0.85、药水每42次有效普通击杀。相对第14关仅小幅提升属性，主要增加连续决策。沿用现有精英/远程强化基线，新怪配置须标清是否已包含×2，禁止重复倍增；下文技能伤害均为最终固定值。

总量100（包括幼虫）、威胁6、危险槽2、精英最多1。分裂幼虫最多20、滚甲虫3、喷砂囊虫2、潜沙猎虫2。召唤、分裂和Boss援兵共享上限，不另开隐藏怪池。连续招式预约槽位，预约期间不能插入第三个危险攻击。

普通血量初始系数分别1.05、2.1、1.8、1.3；地表移速分别1.65、1.4、1.1、2.0；普通接触伤害分别8、10、12、10（未乘关卡倍率）。幼虫血量系数0.25、速度2.2、接触4，不能再次分裂。

### 工虫分裂：保留清群收益，制造第二次判断

工虫与两只幼虫合计只提供一份普通怪经验：母体0.5、幼虫各0.25，继续乘关卡经验倍率。若受总量/幼虫上限/地形限制无法出生，缺少的份额直接变成母体经验掉落，不能让玩家因上限丢经验，也不能无限刷经验。幼虫无金币、药水或额外分裂。

幼虫出生点在死亡点两侧0.7单位，必须是合法地面；出壳0.65秒后才可移动和接触伤害。若死亡点贴近玩家，警告仍完整，玩家可清掉或离开。分裂不附带爆炸，不额外占危险槽；出壳期间可被攻击，不能用无敌出生挡刀。

### 裂甲滚虫：两段翻滚，破甲窗口

距离2.5～7时锁定第一段长度5、半宽0.55的路线，预警1.0秒，速度6、伤害20，只能命中玩家一次。第一段结束后，在原地展示第二段方向，完整预警0.9秒，再滚4单位；方向为事先选定的左/右60度，不能临时转向追踪玩家。第一次起手就用淡色虚线展示折向，第二次蓄力实线确认。

撞岩岛提前停止，取消尚未开始的第二段，展开硬直2.5秒；正常两段结束硬直1.7秒。硬直期间无接触伤害、受到伤害+25%，然后至少休息1秒。整个连滚共用一次命中标记，不用两段叠伤秒杀玩家。首次教学只出现一只滚虫，不叠远程喷砂。

### 喷砂囊虫：扇面扫描

入镜至少1秒、距离2～7时开始攻击。第一扇面射程7、角度40度，朝向在起手时锁定，预警0.95秒、有效0.15秒、伤害16。后续两段各向事先选定的一侧偏转35度，分别给完整0.8秒预警；每段结束间隔0.15秒。三段完毕恢复1.8秒，冷却2秒。

起手时浅色显示全部三段范围，当前段加亮；未发动段仍可被击杀或冻结打断，已经喷出的砂浪只持续原0.15秒。一次连喷预约1个槽，其他敌人最多使用另1个；后段若无合法出口则取消，不偷偷换方向。贴身小于2单位时最多每4秒后撤一次、距离1.5，不能永久倒退风筝。

### 潜沙猎虫：地表追击变为锁点出土

从完整可见的地表状态起手，先蓄力0.45秒，可被攻击、冻结打断。锁定玩家当前点（不预判），最大潜行距离6；超距时只锁向玩家方向6单位处。地面圆圈半径1.6自起手就出现，落点不再追踪。

潜行速度5、最长1.2秒，有连续沙脊显示路线，不瞬移、不穿岩；落点攻击时间至少距起手1.65秒，保证离开圈的机会。出土伤害22、仅一次，之后地表虚弱2秒、受到伤害+25%，再普通追击；距离合适且冷却6秒才可再次潜行。

仅完全潜入地面期间不被新弹体/近战命中，持续灼烧/毒仍结算；不能通过潜行回血或清除负面效果。已有持续伤害杀死其时取消出土攻击。潜行与出土整体占1个危险槽，预算不足时保持地表追击。玩家可以先打断，也可躲落点后反击。

## 两名专属精英

不复用通用刽子手或铁蹄统领。各自血量与掉落以第14关对应精英最终配置为起点，再应用本关精英倍率；不追加一次×2。精英威胁3，带队总威胁不超过6。

### 175秒：孵巢监母 / broodelite

造型为高耸卵囊、四条支撑长足、前方两只短钳；速度1.3、接触18固定。

循环“孵卵 → 护巢喷射 → 虚弱”：在自身周围4单位内生成最多3个卵，各有独立血条，血量为普通工虫的一半，孵化计时3.2秒；可直接打碎。存活卵最终各孵出1只工虫，最多同时3个卵、6只由其孵出的工虫；受总怪量限制则取消，不补刷。精英死亡时卵破裂，幼体不再生成。

生成卵时锁定一条指向玩家的地面砂线：长度7、半宽0.55、预警1.1秒、伤害22，发射后持续0.2秒。砂线结束0.5秒后对一枚存活卵所在圆区发出一次孵巢震动，半径1.6、完整预警1秒、伤害18。没有存活卵就跳过震动。两段后虚弱2.4秒，无接触伤害。

先拆卵能减少围堵并取消第二段威胁；高单体也可直接杀监母。不会强迫特定武器或锁血等拆卵。

### 345秒：裂地暴君 / breakerelite

造型为直立巨颚甲兽、两只巨大前肢、背部裂甲；速度1.6、接触20固定。

先锁定玩家坐标半径1.7震地点，预警1.1秒、伤害24；结束后0.35秒，向玩家新位置锁定长度5.5、半宽0.65的地表扑进，完整预警1秒、速度6.5、伤害26、仅一次。扑进撞岩硬直3秒并受伤+25%，正常结束硬直2秒。

它不会每帧修正方向，也不能潜地无敌。两段预约2个槽；形势不允许时只发震地，之后给1.8秒恢复，统计降级原因。引扑撞岩是主要反击方式。

## Boss：赤砂巢皇 / sandemperor

造型为横向宽大的六足虫皇、巨型双钳、发光尾囊与分层背甲，明显区别于第14关直立重甲督军。地表速度2.0、接触20固定；普通恢复和转阶段无接触伤害。55%生命进入第二阶段，过渡1.4秒，不回血、不锁血。

### 第一阶段：出土追击 → 双钳交剪 → 尾囊撒播

**出土追击**：地表蓄力0.45秒，标记玩家当前坐标半径1.8，最长6单位潜行、速度5、时长上限1.2秒，出土伤害28。预警至少1.65秒，不追踪，不穿岩；潜地只暂时不可被新弹体命中，持续伤害有效。出土后0.3秒锁定玩家的新方向，发出射程5、75度扇面钳击，完整预警1秒、伤害24。之后恢复2.4秒。玩家躲落点后还需向钳击侧后方移动。

**双钳交剪**：第一条斜线穿过玩家锁定坐标，长度6、半宽0.55，预警1.1秒、伤害24；有效0.15秒后间隔0.35秒，在玩家新坐标锁定相反斜向的第二条线，完整预警1秒、伤害24。两段预约2槽，先后生效，交点不再是永久安全位。首段起手显示其朝向，后段重新显示新锁定位置，不在旧预警里偷偷换中心。结束恢复2.2秒。

**尾囊撒播**：发射3枚可见抛物线砂卵，落点圆半径1.4、每枚伤害20。第一枚起手锁当前玩家位置，预警1.1秒；第二枚在0.6秒后重新锁定，预警1.05秒；第一枚危险结束后再等待0.1秒才锁第三枚，完整预警1.05秒。每个落点有效0.15秒后消失，不残留；最多同时2枚在预警或生效。卵弹发射0.25秒后成为独立实体，杀死/冻结Boss不能让已飞出的卵消失。第三枚结束恢复2秒。

三招都要求离开当前坐标或再次变向，保留短暂输出窗口；不会用每次都安全的固定中央通道帮助玩家站撸。

### 第二阶段：改变衔接与回收路线

顺序变为“交剪 → 出土追击 → 撒播”，预警不缩短。

- 交剪第二条线留下1.2秒沙裂，宽度沿用0.55，每0.6秒6伤害，继续占原槽。必须先离开旧线，再找下一次输出位置。
- 出土追击之后的钳击恢复缩至2.0秒，其余恢复不变；不额外增加无预警第三击。
- 每一完整轮结束尝试一组援兵，交替为1只潜沙猎虫、1只喷砂囊虫；最多同时保留一组，仍受威胁6与危险2限制。援兵出生距离至少6、进场预警1秒，半经验、无药水金币。
- 分裂幼虫仍可能出现，但Boss自身不再额外召唤工虫潮；普通Boss援军沿用9秒刷怪/5秒暂歇，避免把所有系统同时叠满。

转阶段取消Boss尚未发射的技能与预约，保留已飞出的砂卵及其他怪已经生效的攻击。若潜行中触发转阶段，沿已显示沙脊到最近合法地表点显形，再执行1.4秒过渡，不能无预警瞬移贴脸。

## 让第15关高于第14关的具体变化

1. 清掉大怪不等于清空脚下，分裂幼虫改变经验回收路线。
2. 第14关战犬只有一次突刺；这里滚虫有可预读折向，躲完第一段仍要检查第二段。
3. 潜沙制造短暂目标切换窗口，迫使玩家清外围、准备在出土后反击；不能全程对同一目标输出。
4. 两名精英分别引入可拆除的孵化目标、震地接扑进，要求优先级与连续侧移。
5. Boss更早进入第二阶段，三招均有连续锁定，第二阶段旧线会短暂占路；不靠缩短预警到看不清来提高难度。

## 实施与验收

开发顺序：共享地图白盒 → 分裂与经验守恒 → 翻滚/喷砂/潜沙生命周期 → 两种精英 → 巢皇三招与阶段 → 独立造型动作 → 手机验证。

新的状态必须明确区分蓄力、已发射、潜行、地表虚弱和恢复；只有物理潜地那一小段不可新命中，不能给整段技能或阶段套无敌。射程、受击范围、地下沙脊、真实位置与碰撞共用数据。

单元测试覆盖分裂上限与经验守恒、卵可拆且不能复活、潜行距离/时间/墙体、持续伤害可杀地下目标、冻结前后区别、已射卵不消失、翻滚命中去重、两槽预约释放、逐段完整预警、转阶段合法显形、恢复期接触安全。

与第14关用相同角色、种子、配装策略和模拟控制器做36场正常成长对照（三方向×六种子×两关）；六种互不相同的满级配装×三位置×三种子×站定/移动×两关，共216场Boss对照，并分别测试1分钟/4分钟后停止移动。保存每段施放/命中/打断/降级与实际配装，不把模拟超时记成战败。

验收目标：站定不能稳定通关；相同配装、相同位置三种子胜两场就作为漏洞检查。移动策略应能在多种配装下找到通关样本；第15关在至少两个配装方向体现更大压力，再结合真人反馈确认，不能仅凭血量倍率宣布更难。机器人战败不自动降难度。

边界：出口校验采用逐段重新锁定时的地图/危险/附近怪物保守采样，不能声称已经证明所有未来路径可达。完整连招需要白盒真人验证、受压变向样本和手机实际操作检查。性能预算沿用百怪与两危险槽，潜行沙脊、分裂提示与卵弹必须有数量上限和共享对象；不能每帧给百怪运行全图寻路。

## 0.19.0 实施与调整

代码分为SandMap（共享岩岛几何）、SandSystem（虫群行为、孵化、分裂与危险预约）、SandPainter（原创建模式像素绘制）。四类主小兵、幼虫、可拆虫卵、两名精英与两阶段巢皇均接入；第14关通关后解锁，第15关出生点(0,-8)。保存格式兼容旧存档。

虫卵孵化调整为3.2秒，使“砂线结束后0.5秒→1秒震动预警”能在孵化之前结束，玩家可以实际拆卵取消第二击。保留所有完整预警，不通过缩短反应时间提升压力。潜沙期间不接新攻击，仅结算此前挂上的灼烧和毒；已发射砂卵在施法者冻结、转阶段或死亡后继续飞行。分裂经验不足配额时回到母虫掉落，幼虫与召唤怪不掉药水/金币。

### 最终本地验证
