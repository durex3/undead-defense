# 升级与技能详情界面

升级三选一突出本次选择：武器等级变化、最多三行属性变化、一行配方搭配提示。伤害使用实际 rankDamage 的“伤害倍率”，不冒充单次命中伤害。低级展示数量、范围、持续或间隔变化；10级提示随后的分支选择。生命药剂按当前生命与上限展示实际回复；被动展示升级前后百分比。

顶部按武器槽数量展示所有已装备武器、等级、◇ 第一分支 / ◆ 独立分支 / ∞ 超武标识。超武双方显示相同超武名称，保留各自槽位。空位显示空武器位。卡片显示“已拥有伙伴 → 超武”或“搭配伙伴 → 超武”；任一伙伴为独立路线时明确不参与组合。

暂停菜单点击任意已装备武器进入详情，展示用途、当前形态、伤害倍率、配方双方与达成条件。返回暂停菜单或继续冒险均可；Esc 从详情返回暂停菜单。查看详情不会选择升级、消耗资源或推进战斗。
