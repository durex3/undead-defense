# Pixel art sources

Current characters, floor tiles, column, sword and potion: **0x72**, DungeonTileset II v1.7.
Source page: https://0x72.itch.io/dungeontileset-ii
Imported from the user's local `resouce/0x72_DungeonTilesetII_v1.7/frames` directory.
Changes: repacked into a shared atlas; floor tiles assembled, desaturated and tinted; nearest-neighbor scaling.
The local README describes tileset usage but does not include a license statement. Archive the source license and purchase/download provenance before commercial release.

Combat audio is procedurally generated by the project's `tools/generate_audio.py`.
The previous 3D defense resources and icon credits are retained under `archive/defense` and `licenses`, and are no longer loaded by the active game.

Boar animation and companion ghost: original procedural pixel artwork generated by `tools/custom_pixel.mjs` for this project. Shield, weapon accessories, skill glyphs and combat effects are drawn by project code.

Expansion slime, banshee and lantern-wisp animations: original procedural pixel artwork generated by `tools/custom_pixel.mjs`. Archer, drummer and summoner reuse the credited 0x72 actors with code-drawn bow, drum and shovel accessories. New skill glyphs and effects are project code in `ExpansionPainter.ts`.

Garden paths, grass marks, grave markers, dead trees and fence: original static Graphics drawing in `GardenPainter.ts`. Character variants reuse the existing credited wizard animation with tint; the gravekeeper reuses the credited necromancer animation with shovel attachment.
