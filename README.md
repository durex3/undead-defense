# 余烬幸存者

Cocos Creator 3.8.8，横屏 2D 像素生存小游戏。当前入口是 `assets/scenes/Main.scene`，旧守线原型归档在 `archive/defense`。

玩法：WASD / 方向键或触摸拖动移动，三选一武器开局，十八种武器可学习和进化，捡绿色经验升级，1–3 选择技能，空格全收场上经验，Esc 暂停。八分钟出现首领，等级上限64，开局开放六武器槽。

```sh
npm test
npx tsc --noEmit
node tools/build.mjs web-mobile
python3 -m http.server 8128 --directory build/web-mobile
node tools/build.mjs wechatgame
```

美术处理脚本 `tools/prepare_pixel.mjs` 需要 Node 20+，并使用该电脑的本地资源路径。构建脚本内的 Creator 路径适用于当前 macOS 环境。Cocos 成功构建退出码 36 已在脚本中归一化。

微信产物位于 `build/wechatgame`，已指定横屏和 release 构建。已配置 AppID `wx941ec18966484d46`，构建脚本会保留；正式发布前仍需真机验收。Web 调试构建有 `__undead` 测试入口，微信 release 中不暴露。
